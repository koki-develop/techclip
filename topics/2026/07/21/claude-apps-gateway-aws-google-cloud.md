# Anthropic、企業向け「Claude Apps Gateway for AWS/Google Cloud」を発表、SSOとコスト管理を実現
Tags: Cloud, AI

- 「Claude Apps Gateway for AWS/Google Cloud」が登場、Claude Codeの組織全体でのシングルサインオンとコスト管理を実現 (2026-07-21)
  https://www.publickey1.jp/blog/26/claude_codeclaude_apps_gateway_for_awsgoogle_cloud.html

AnthropicがAWSおよびGoogle Cloud向けの自己ホスト型ゲートウェイ「Claude Apps Gateway」を発表した。OIDC対応のシングルサインオンやロールベースアクセス制御、組織単位での利用状況・コスト上限管理など、企業がClaude Codeを大規模に導入するための機能を提供する。

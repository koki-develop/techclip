# AIコーディングエージェント8体が並列作業でPostgreSQLをRustに書き直し、回帰テスト全件に合格
Tags: OSS, Programming Languages

- Postgres rewritten in Rust, now passing 100% of the Postgres regression tests (pgrust) (2026-07-09)
  https://malisper.me/pgrust-passes-100-of-postgresqls-regression-tests/
- PgRust: AI-Coded Rust Rewrite of PostgreSQL Passes 100% of Tests (2026-07-10)
  https://www.linuxcompatible.org/story/pgrust-aicoded-rust-rewrite-of-postgresql-passes-of-tests/

元HeapのCEOが個人プロジェクトとして、AIコーディングエージェント8体を並列稼働させてPostgreSQLをRustで書き直した「pgrust」が、PostgreSQL 18.3の回帰テスト46,000件全てにパスしたことを発表した。Hacker Newsで740ポイント超・620件超のコメントを集めるなど大きな反響を呼び、AIエージェントによる大規模ソフトウェアの書き換えがどこまで実用的かを示す事例として注目されている。

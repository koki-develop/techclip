# Git 2.55リリース、Rustサポートがデフォルト化され「git history fixup」コマンドも追加
Tags: OSS, Programming Languages

- Git 2.55 Released With Rust Support Enabled By Default, git history fixup (2026-06-29)
  https://www.phoronix.com/news/Git-2.55-Released
- Highlights from Git 2.55 (2026-06-29)
  https://github.blog/open-source/git/highlights-from-git-2-55/

Git 2.55がリリースされ、Rustサポートがデフォルトでビルドされるようになった。過去コミットへの変更適用を簡略化する`git history fixup`コマンドや並列フック実行、Linuxのinotifyサブシステムをベースにしたファイルシステムモニターによる`git status`高速化など、開発者体験を向上させる多数の新機能が100名以上のコントリビューターによって追加されている。

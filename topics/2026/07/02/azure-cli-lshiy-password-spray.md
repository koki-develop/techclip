# Azure CLIを標的にした大規模パスワードスプレー攻撃「LSHIY」が8,100万回以上のログイン試行で78アカウントを侵害
Tags: Security

- Azure CLI Password Spray Hits at Least 78 Microsoft Accounts in 81M+ Attempts (2026-07-01)
  https://thehackernews.com/2026/07/azure-cli-password-spray-hits-at-least.html
- Massive Password Spray Campaign Targeting Azure CLI (2026-07-01)
  https://www.securityweek.com/massive-password-spray-campaign-targeting-azure-cli/

Azure CLIを標的にした大規模パスワードスプレー攻撃「LSHIYキャンペーン」が確認され、6月12日〜26日の間に8,100万回以上のログイン試行が行われた。64組織にわたる78アカウントが侵害されており、廃止済みのOAuthフロー「ROPC」を悪用してMFAを回避する手法が用いられている。企業はAzure CLIを含む全クラウドアプリへのMFA適用を早急に見直すよう勧告されている。

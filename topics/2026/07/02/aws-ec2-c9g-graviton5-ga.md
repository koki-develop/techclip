# AWSがGraviton5搭載のコンピュート最適化インスタンス「EC2 C9g/C9gd」を一般提供開始
Tags: Cloud

- Amazon EC2 C9g and C9gd instances powered by AWS Graviton5 processors are now available (2026-06-30)
  https://aws.amazon.com/blogs/aws/amazon-ec2-c9g-and-c9gd-instances-powered-by-aws-graviton5-processors-are-now-available/
- New instances bring AWS' Graviton5 CPUs to high-performance cloud workloads (2026-06-30)
  https://siliconangle.com/2026/06/30/new-instances-bring-aws-graviton5-cpus-high-performance-cloud-workloads/

AWSがGraviton5プロセッサ搭載のコンピュート最適化インスタンス「C9g・C9gd」を一般提供開始した。前世代C8g比でvCPUあたり最大25%の性能向上を実現し、DDR5 8800MT/sメモリと5倍のL3キャッシュを搭載。AIエージェントやバッチ処理、動画エンコードなどの高負荷ワークロード向けに最適化されており、ローカルNVMe SSD搭載のC9gdバリアントも用意されている。

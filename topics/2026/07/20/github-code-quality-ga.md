# GitHubの新機能「Code Quality」が正式提供開始、コミッター単位の有料サブスクリプションに
Tags: OSS

- GitHub Code Quality generally available July 20, 2026 (2026-07-20)
  https://github.blog/changelog/2026-06-16-github-code-quality-generally-available-july-20-2026/

GitHubの新機能「Code Quality」がパブリックプレビューから正式提供（GA）へ移行した。アクティブコミッター1人あたり月10ドルの有料製品として提供され、コードベースの品質分析機能をGitHub上で直接利用できるようになる。

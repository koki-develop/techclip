# Anthropic、最新モデル「Claude Opus 5」を発表、GitHub Copilotでも即日利用可能に
Tags: AI, OSS

- Anthropic launches Opus 5 (2026-07-24)
  https://techcrunch.com/2026/07/24/anthropic-launches-opus-5/
- Claude Opus 5 is now available in GitHub Copilot (2026-07-24)
  https://github.blog/changelog/2026-07-24-claude-opus-5-is-now-available-in-github-copilot/

AnthropicはClaudeシリーズの最上位モデル「Opus 5」を発表した。より大型のFable 5を一部ベンチマークで上回る性能を持ちながら、安全性フィルターの作動頻度が約85%少なく、安全トリガー時に自動で軽量モデルへフォールバックする新機能も搭載する。発表と同日にGitHub Copilotでも利用可能となり、複雑で長時間にわたるコーディングタスクにおける高度な推論やツール利用への活用が期待されている。

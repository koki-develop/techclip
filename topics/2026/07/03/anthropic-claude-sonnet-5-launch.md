# AnthropicがClaude Sonnet 5をリリース、エージェント向け低コストモデルとして7月1日からデフォルト提供開始
Tags: AI

- Anthropic launches Claude Sonnet 5 as a cheaper way to run agents (2026-06-30)
  https://techcrunch.com/2026/06/30/anthropic-launches-claude-sonnet-5-as-a-cheaper-way-to-run-agents/
- Claude Sonnet 5 is generally available for GitHub Copilot (2026-06-30)
  https://github.blog/changelog/2026-06-30-claude-sonnet-5-is-generally-available-for-github-copilot/

AnthropicがClaude Sonnet 5を正式リリースした。Opus 4.8に近い性能をより低コスト（入力100万トークン2ドル、出力10ドル）で提供し、ブラウザやターミナルなどのツールを使った自律的なエージェント動作に最適化されている。7月1日からFree・Proプランのデフォルトモデルとなり、GitHub CopilotでもGA提供が開始された。

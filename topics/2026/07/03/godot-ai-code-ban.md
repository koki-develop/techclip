# GodotエンジンがAI生成コードのコントリビューション受付を禁止、「開発者自身がコードを理解できない」を理由に
Tags: Programming Languages, OSS

- Godot will no longer accept AI-authored code contributions (2026-06-30)
  https://godotengine.org/article/contribution-policy-2026/
- Godot says bye bye AI, bans vibe-coded contributions (2026-07-01)
  https://www.theregister.com/ai-and-ml/2026/07/01/godot-says-bye-bye-ai-bans-vibe-coded-contributions/5265344

オープンソースゲームエンジンGodotは、AIが自律的に生成したコードのコントリビューションを禁止する方針を発表した。「AIを多用する開発者は自分のコードを十分に理解できず、提出後のバグ修正にも対応できない」として、実質的にすべてのAI生成コードのPRを拒否するポリシーに変更された。開発者コミュニティでは賛否両論を呼んでおり、AI活用と責任あるコード品質管理のあり方について議論が活発化している。

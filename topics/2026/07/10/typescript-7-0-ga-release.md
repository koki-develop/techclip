# TypeScript 7.0が正式リリース、Goによるコンパイラ書き換えで最大12倍高速化
Tags: Programming Languages, OSS

- Announcing TypeScript 7.0 (2026-07-08)
  https://devblogs.microsoft.com/typescript/announcing-typescript-7-0/
- Go-based TypeScript 7.0 reaches release candidate stage (2026-07-05)
  https://www.infoworld.com/article/4191918/typescript-7-0-reaches-release-candidate-stage.html

MicrosoftがコンパイラをGoで書き直したTypeScript 7.0を正式リリースした。ネイティブコード実行と並列処理により、フルビルドが従来のTypeScript 6.0比で8〜12倍高速化されており、既存の型チェックやコマンドライン動作との互換性も維持されている。

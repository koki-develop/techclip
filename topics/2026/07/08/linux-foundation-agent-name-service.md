# Linux Foundation、AIエージェント向けの信頼できる名前基盤「Agent Name Service(ANS)」立ち上げを発表
Tags: OSS, AI

- Linux Foundation、AIエージェント向け信頼できる名前基盤「Agent Name Service(ANS)」立ち上げを発表 (2026-07-02)
  https://www.publickey1.jp/blog/26/dnsaiagent_name_serviceanslinux_foundation.html

Linux Foundationが、既存のDNSインフラを拡張してインターネット上で活動するAIエージェントに信頼できる識別子と名前を与える新しいオープンソース標準「Agent Name Service(ANS)」の立ち上げ意向を発表した。中央集権的でない形でAIエージェントの認証・信頼・ガバナンス・相互運用性の課題解決を目指す。

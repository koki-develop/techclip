# TypeScript 7.0がリリース候補段階に到達、Go実装への書き直しで最大10倍の速度向上を実現
Tags: Programming Languages

- TypeScript 7.0 reaches release candidate stage (2026-07-01)
  https://www.infoworld.com/article/4191918/typescript-7-0-reaches-release-candidate-stage.html

MicrosoftがGoで書き直したTypeScript 7.0のリリース候補（RC）を公開した。TypeScript 6.0と比較して最大10倍の速度向上を達成しており、VS Codeのビルド時間が77秒から7秒に短縮されるなど実用的な改善が確認されている。安定版のGA（一般提供）はRCから約1か月以内を予定している。

# GitHub Copilotがブラウザ操作・画像認識・初のオープンウェイトモデルをGA提供開始
Tags: OSS, AI

- Browser tools for GitHub Copilot in VS Code are generally available (2026-07-01)
  https://github.blog/changelog/2026-07-01-browser-tools-for-github-copilot-in-vs-code-are-generally-available/
- Copilot vision is generally available (2026-07-01)
  https://github.blog/changelog/2026-07-01-copilot-vision-is-generally-available/
- Kimi K2.7 Code is generally available in GitHub Copilot (2026-07-01)
  https://github.blog/changelog/2026-07-01-kimi-k2-7-is-now-available-in-github-copilot/

GitHub Copilotが7月1日に複数の機能を一斉GA提供した。VS Code向けのブラウザツールによりAIエージェントが実際のブラウザを操作してWebアプリを検証できるようになり、Copilot visionで画像・PDFをチャットに添付してAIが推論できるようになった。また、Kimi K2.7 CodeがCopilot初のオープンウェイトモデルとしてモデルピッカーに追加された。

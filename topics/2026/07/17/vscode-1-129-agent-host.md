# VS Code 1.129リリース、エージェント専用プロセス化とチャットからのターミナル操作に対応
Tags: OSS, Programming Languages

- Visual Studio Code 1.129 (2026-07-15)
  https://code.visualstudio.com/updates/v1_129

VS Codeの最新版がリリースされ、エージェントセッションを専用プロセスで実行する「Agent Host」アーキテクチャや、複数ウィンドウから同一セッションに接続できる機能、チャットからのターミナルコマンド実行（`!`プレフィックス）などが追加された。

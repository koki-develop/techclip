# 中国メモリー大手CXMT、サムスン・SKハイニックスに挑む43億ドル規模のIPOを計画
Tags: Other

- China's CXMT Chipmaker Eyes IPO to Challenge Samsung, SK Hynix, Micron (2026-07-09)
  https://www.bloomberg.com/news/features/2026-07-09/china-s-cxmt-chipmaker-eyes-ipo-to-challenge-samsung-sk-hynix-micron

中国最大手のDRAMメーカーChangXin Memory Technologies（CXMT）が、上海STAR市場で約43億ドル規模のIPOを実施すると発表した。7月16日に申込を開始する予定で、2026年のA株最大級の新規上場となる見通し。サムスン電子やSKハイニックス、マイクロンといったメモリー市場の既存大手に挑む構えを見せている。

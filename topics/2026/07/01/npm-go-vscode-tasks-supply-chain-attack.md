# 乗っ取られたnpm・GoパッケージがVS Codeタスクとブロックチェーンを悪用してPython製情報窃取マルウェアを展開
Tags: Security

- Hijacked npm and Go Packages Use VS Code Tasks to Deploy Python Infostealer (2026-06-29)
  https://thehackernews.com/2026/06/hijacked-npm-and-go-packages-use-vs.html
- Hijacked npm Packages Use Novel VSCode Autorun and Blockchain Dead Drops to Deploy a Credential/Crypto Stealer (2026-06-29)
  https://research.jfrog.com/post/hijacked-npm-vscode-tasks-blockchain/

乗っ取られた複数のnpmパッケージとGoパッケージが、VS Codeの「tasks.json」自動実行機能とブロックチェーンのデッドドロップを組み合わせてPython製情報窃取マルウェアを展開するサプライチェーン攻撃が発見された。ブラウザ認証情報・暗号資産ウォレット・開発者APIキーなど幅広い情報を窃取し、JFrogが詳細な技術分析を公開している。

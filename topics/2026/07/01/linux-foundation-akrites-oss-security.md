# Linux FoundationがAI時代のOSSセキュリティ組織「Akrites」を設立、大手テック20社が参加
Tags: OSS, Security

Linux Foundationが主導し、AWS・Anthropic・Google・Microsoft・OpenAIなど約20組織が参加するオープンソース脆弱性対応組織「Akrites」を設立した。AIが脆弱性発見と悪用を加速させる現代の脅威環境に対応するため、業界横断の共有セキュリティインシデント対応チーム（SIRT）と標準化された脆弱性協調開示（CVD）プロセスを構築する。

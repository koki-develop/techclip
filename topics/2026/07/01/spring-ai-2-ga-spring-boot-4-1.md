# Spring AI 2.0が正式リリース（GA）、JavaエコシステムにAIアプリ開発の成熟した基盤を提供
Tags: Programming Languages

- This Week in Spring - June 30th, 2026 (2026-06-30)
  https://spring.io/blog/2026/06/30/this-week-in-spring-june-30-2026/
- Spring AI 2.0 Goes GA, Giving Java Developers a More Mature AI App Stack (2026-06-29)
  https://visualstudiomagazine.com/articles/2026/06/29/spring-ai-2-0-goes-ga-giving-java-developers-a-more-mature-ai-app-stack.aspx

Spring AI 2.0が正式リリース（GA）され、Javaエコシステム向けのAIアプリケーション開発基盤が大幅に成熟した。Spring Boot 4.1も多数の新機能とCVEパッチを含む正式リリースが発表されており、gRPC自動設定・SSRF対策・Kotlin 2.3サポートなどが追加されている。

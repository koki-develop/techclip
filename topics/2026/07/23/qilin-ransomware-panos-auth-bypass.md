# Qilinランサムウェア集団、Palo Alto PAN-OSの認証バイパス脆弱性を悪用し侵入
Tags: Security

- Qilin Ransomware Attackers Exploit PAN-OS Authentication Bypass for Initial Access (2026-07-21)
  https://thehackernews.com/2026/07/qilin-ransomware-attackers-exploit-pan.html

Qilinランサムウェアグループが、Palo Alto NetworksのPAN-OS GlobalProtectにおける認証バイパスの脆弱性CVE-2026-0257(CVSS 7.8)を悪用し、企業ネットワークへ侵入していることをArctic Wolfが報告した。侵入後は資格情報窃取や横展開を経てダブルエクストーションを行うケースも確認されている。

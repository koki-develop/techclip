# VS Code 1.127リリース、ブラウザ操作機能のGA化やターミナルのサンドボックス実行などAIエージェント機能を強化
Tags: Programming Languages, OSS

- Visual Studio Code 1.127 released (2026-07-01)
  https://code.visualstudio.com/updates/v1_127

VS Code 1.127がリリースされ、エージェントがブラウザでWebアプリをビルド・テストできる機能が正式版となったほか、サイトごとのブラウザ権限設定、macOS/Linux向けターミナルコマンドのサンドボックス実行、複数チャットセッションの整理機能などAIエージェント関連の開発体験が大幅に強化された。

# DeepSeek製AIが生成したマルウェアがChromiumのファイルシステムAPIを悪用、ブラウザ完結型ランサムウェアを実現
Tags: Security, AI

- AI-Generated Browser Ransomware Abuses Chromium API on Windows, Linux, macOS, Android (2026-07-01)
  https://thehackernews.com/2026/07/ai-generated-browser-ransomware-abuses.html

DeepSeekを使って生成されたマルウェアが、ブラウザのファイルシステムアクセスAPIを悪用し、マルウェアのインストールなしにブラウザ内だけでファイルを暗号化する新たなランサムウェア手法を実現した。理論上のリスクとされてきたブラウザ完結型ランサムウェアを、AIが実用的な攻撃チェーンへと橋渡しした初の事例とされる。

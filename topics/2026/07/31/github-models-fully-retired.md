# GitHub、AIモデル実験プラットフォーム「GitHub Models」を7月30日付で完全終了
Tags: OSS, AI

- GitHub Models is being fully retired on July 30, 2026 (2026-07-30)
  https://github.blog/changelog/2026-07-01-github-models-is-being-fully-retired-on-july-30-2026/

GitHubはAIモデルの実験用プレイグラウンドおよび推論APIを提供していた「GitHub Models」を7月30日付で完全に終了した。プレイグラウンド、モデルカタログ、推論API、BYOKエンドポイントが全ユーザー向けに利用不可となり、開発者は他のAIサービスへの移行が必要となる。

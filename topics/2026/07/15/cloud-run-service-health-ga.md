# Google Cloud Run、リージョン間自動フェイルオーバーの「Service Health」機能が一般提供開始
Tags: Cloud

- Cloud Run's Service Health reaches General Availability (2026-07-10)
  https://cloud.google.com/blog/topics/inside-google-cloud/whats-new-google-cloud

Google CloudのCloud Runにおいて、リージョン間の自動フェイルオーバーを実現する「Service Health」機能が正式提供(GA)となった。readiness probeによるインスタンス単位のヘルスチェックを活用し、簡単な設定で高可用性なマルチリージョン構成を構築できるようになった。

# npm 12がインストール時スクリプトをデフォルトで無効化、サプライチェーン攻撃対策を強化
Tags: OSS, Security

- npm 12 Disables Install Scripts by Default to Reduce Supply Chain Risk (2026-07-08)
  https://thehackernews.com/2026/07/npm-12-disables-install-scripts-by.html

npm v12.0.0が正式リリースされ、依存パッケージのpreinstall/install/postinstallスクリプトやGit・リモートURL依存の解決がデフォルトで無効化された。相次ぐサプライチェーン攻撃を受けた大きな方針転換で、数百万のnpmユーザーに影響する。

# Googleが200万台規模の住宅用プロキシネットワーク「NetNut」を破壊
Tags: Security

- Google Disrupts NetNut Residential Proxy Network Spanning 2 Million Home Devices (2026-07-02)
  https://thehackernews.com/2026/07/google-disrupts-netnut-residential.html

GoogleとFBI、Lumenなどが連携し、世界で200万台以上のホームデバイスを組み込んだ住宅用プロキシネットワーク「NetNut」(別名Popa)を破壊した。サイバー犯罪やスパイ活動のインフラとして悪用されていたとされ、関連ドメインの差し押さえも実施された。

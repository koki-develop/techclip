# Oracle、ShinyHuntersが100以上の組織侵害に悪用したPeopleSoftの脆弱性を7月定例パッチで修正
Tags: Security

- PeopleSoft Exploit Behind 100+ Breaches Gets Patched in Oracle's Record July CPU (2026-07-21)
  https://www.techtimes.com/articles/321140/20260721/peoplesoft-exploit-behind-100-breaches-gets-patched-oracles-record-july-cpu.htm
- Oracle July 2026 Critical Patch Update: 5 CRITICAL and 12+ HIGH Severity Vulnerabilities Across WebLogic, PeopleSoft, Identity Manager, and WebCenter (2026-07-21)
  https://threat-modeling.com/oracle-july-2026-critical-patch-update/

Oracleが2026年7月の四半期定例パッチ(CPU)を公開し、ShinyHuntersが100以上の組織(主に大学)から300台以上のサーバーを侵害するために悪用したPeopleSoft PeopleToolsの認証前RCE脆弱性(CVE-2026-35278、CVSS 9.8)を修正した。今回のCPUではWebLogicやIdentity Manager、WebCenterなどを含む5件の緊急・12件以上の重要な脆弱性も併せて対処されている。

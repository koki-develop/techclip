# IntelliJ IDEA 2026.2がリリース、GitHub Copilotをネイティブ統合
Tags: OSS, Programming Languages

- IntelliJ IDEA 2026.2 Released With Native GitHub Copilot Integration (2026-07-17)
  https://ubuntuhandbook.org/index.php/2026/07/intellij-idea-2026-2-released-with-native-github-copilot-integration/

JetBrainsはIntelliJ IDEA 2026.2をリリースし、GitHub Copilotを標準搭載してAIチャットのエージェントピッカーからOAuth認証だけで利用できるようにした。あわせてJava・Kotlin・TypeScriptの新しい言語サポートも追加され、AI機能と言語対応の両面で強化が図られている。

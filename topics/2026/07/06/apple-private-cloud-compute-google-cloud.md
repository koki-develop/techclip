# AppleがPrivate Cloud Computeを初めて自社データセンター外(Google Cloud)で稼働
Tags: Cloud

- Apple Extends Private Cloud Compute to Google Cloud for the First Time (2026-07-02)
  https://www.infoq.com/news/2026/07/apple-pcc-google-cloud/

AppleはWWDC26で発表した計画に基づき、自社データセンター以外で初めてPrivate Cloud ComputeをGoogle Cloud上で稼働させることを明らかにした。NVIDIA Blackwell GPU、Intel TDX、GoogleのTitanチップを組み合わせた検証可能なセキュリティ構成を採用し、ライバル企業のインフラを利用する異例の提携となる。

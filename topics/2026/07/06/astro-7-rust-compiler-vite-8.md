# 静的サイトジェネレータ「Astro 7.0」正式リリース、コアコンパイラをRustに刷新しビルドを大幅高速化
Tags: Programming Languages, OSS

- 静的サイトジェネレータ「Astro 7.0」正式リリース、ビルドシステムがVite 8/Rolldownに、Rust製コンパイラ採用で高速化 (2026-07-02)
  https://www.publickey1.jp/blog/26/astro_70vite_8rolldownrust.html

Astro 7.0が正式リリースされ、コアコンパイラがGo/WebAssemblyからRust製に刷新されて15〜61%の高速化を達成した。ビルドシステムもRust製バンドラRolldownを採用したVite 8へ移行し、Cloudflare傘下となったAstroとViteの連携強化が進んでいる。

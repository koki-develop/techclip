# GitHub CopilotがAIクレジット制の従量課金モデルに移行、2026年6月1日より全機能が対象
Tags: OSS

- GitHub Copilot is moving to usage-based billing (2026-06-01)
  https://github.blog/news-insights/company-news/github-copilot-is-moving-to-usage-based-billing/

GitHub Copilotが2026年6月1日よりAIクレジットを使った従量課金制（Usage-Based Billing）に移行し、コードレビュー・Copilot Chat・エージェント機能など全ての利用がAIクレジットとして計上される新課金モデルが正式稼働を開始した。

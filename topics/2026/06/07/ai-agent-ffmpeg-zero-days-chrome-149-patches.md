# AIエージェントがFFmpegの脆弱性21件を発見、Chrome 149は過去最多の429件を修正
Tags: Security, AI

- AI Agent Uncovers 21 Zero-Days in FFmpeg; Chrome Patches Record 429 Bugs (2026-06-06)
  https://thehackernews.com/2026/06/ai-agent-uncovers-21-zero-days-in.html
- Chrome 149 Patches 429 Vulnerabilities (2026-06-06)
  https://www.securityweek.com/chrome-149-patches-429-vulnerabilities/
- Chrome 149 fixes 429 security flaws, the most ever in one update (2026-06-06)
  https://www.pcworld.com/article/3158038/chrome-149-fixes-429-security-flaws-the-most-ever-in-one-update.html

自律型AIセキュリティエージェントがFFmpegに21件のゼロデイ脆弱性を約1,000ドルのコストで発見し、一部は20年以上前から潜在していた。同日、GoogleはChrome 149で過去最多となる429件の脆弱性をパッチし、CVSS 9.6のサンドボックスエスケープを含む多数のCritical/High脆弱性を修正した。

# Node.js 26.3.0リリース、npm 11.16.0へ更新しBufferプールサイズを64KiBに拡大
Tags: Programming Languages

- Node.js 26.3.0 (Current) release (2026-06-01)
  https://github.com/nodejs/node/releases/tag/v26.3.0

Node.js 26.3.0が2026年6月1日にリリースされた。npm 11.16.0へのアップグレード、Buffer.poolSizeのデフォルト値を64KiBへ引き上げ、WebCryptoのプロトタイプ汚染対策強化、SQLiteのアップデートなど複数の改善が含まれる。

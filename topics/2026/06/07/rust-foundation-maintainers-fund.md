# Rust FoundationがMaintainers Fundを正式ローンチ、コアメンテナーへの継続的な資金支援を開始
Tags: OSS, Programming Languages

- Launching the Rust Foundation Maintainers Fund (2026-06-02)
  https://blog.rust-lang.org/2026/06/02/launching-the-rust-foundation-maintainers-fund/

Rust Foundationがメンテナー支援のための「Maintainers Fund」を正式ローンチした。RFC #3931で承認された「Funding team」と「Maintainer in Residence」プログラムを通じ、Rustプロジェクトのコアメンテナーへの継続的サポートと報酬を実現する取り組みで、オープンソースサステナビリティの新たなモデルとして注目されている。

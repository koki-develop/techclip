# GitHub Copilotデスクトップアプリが正式リリース（GA）、macOS・Windows・Linux向けに提供開始

Tags: OSS, AI

- GitHub Copilot app generally available (2026-06-17)
  https://github.blog/changelog/2026-06-17-github-copilot-app-generally-available/

テクニカルプレビューを経て、GitHub CopilotのスタンドアロンデスクトップアプリがmacOS・Windows・Linux向けに正式リリース（GA）された。IssueやPRを起点にエージェントセッションを並列実行でき、Canvasを通じてエージェントの進捗をリアルタイムで確認・操作できる機能を提供する。

# Windows DefenderのRoguePlanetゼロデイ脆弱性でSYSTEM権限昇格が可能、Microsoftが修正パッチ開発中

Tags: Security

- Microsoft working on Defender patch for RoguePlanet zero-day (2026-06-17)
  https://www.bleepingcomputer.com/news/microsoft/microsoft-working-on-defender-patch-for-rogueplanet-zero-day/

完全にパッチ適用済みのWindows 10/11端末でも、Microsoft DefenderのレースコンディションによりSYSTEM権限のコマンドプロンプトを起動できる「RoguePlanet」脆弱性が研究者により公開された。MicrosoftはPatch Tuesday外の緊急修正パッチを開発中と発表しており、現時点での軽減策として一時的にリアルタイム保護の設定変更が示されている。

# Node.jsが2026年6月のセキュリティリリースを公開、複数のサポートバージョンに影響する脆弱性を修正
Tags: Security, Programming Languages

- Node.js — Wednesday, June 17, 2026 Security Releases (2026-06-17)
  https://nodejs.org/en/blog/vulnerability/june-2026-security-releases

Node.jsが2026年6月17日（水）に複数のサポート対象バージョン向けセキュリティリリースを公開した。複数の脆弱性が修正対象となっており、Node.jsチームはすべてのユーザーに対して早急なアップデートを推奨している。

# GitHub Copilot for JiraがGA、Jiraチケット内でコーディングエージェントをリアルタイム監視・指示
Tags: OSS

- GitHub Copilot for Jira is now generally available (2026-06-25)
  https://github.blog/changelog/2026-06-25-github-copilot-for-jira-is-now-generally-available/

GitHub Copilot for Jiraが正式リリース（GA）となり、Jiraのチケット内でコーディングエージェントの進捗をリアルタイム監視したり、フォローアップ指示をチャットパネルから直接送信できるようになった。モデル選択やConfluenceのMCPコンテキスト活用なども新機能として追加されており、開発・プロジェクト管理ワークフローの統合が深化する。

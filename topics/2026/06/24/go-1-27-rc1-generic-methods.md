# Go 1.27 Release Candidate 1公開、ジェネリックメソッドの追加が目玉
Tags: Programming Languages

- Go 1.27 Release Candidate 1 is released (2026-06-18)
  https://groups.google.com/g/golang-announce/c/Cu9HkstbtpA/m/NfBgswyTBgAJ
- Go 1.27 Release Notes (2026-06-18)
  https://go.dev/doc/go1.27

Go 1.27の最初のリリース候補が公開され、メソッドに独自の型パラメータを宣言できる「ジェネリックメソッド」が主要な新機能として追加された。開発チームは本番環境や単体テストでの検証とフィードバックを呼びかけており、安定版のリリースは数週間後に予定されている。

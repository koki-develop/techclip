# Claude CodeのGitHub Actionに脆弱性、悪意あるIssue1件でリポジトリの乗っ取りが可能に
Tags: OSS, Security

- Claude Code GitHub Action Flaw Let One Malicious Issue Hijack Repositories (2026-06-26)
  https://thehackernews.com/2026/06/claude-code-github-action-flaw-let-one-malicious-issue-hijack-repositories.html

AnthropicのClaude CodeをGitHub Actionsに統合した際の脆弱性が公開され、悪意あるIssueを1件投稿するだけでリポジトリ全体を乗っ取れることが明らかになった。オープンソースのCI/CDパイプラインにAIコーディングツールを統合する際のセキュリティリスクを浮き彫りにし、プロンプトインジェクション対策の重要性と実装の安全性が改めて問われている。

# AWSがAIエージェント・ユーザー生成コード向けの新サーバーレス実行環境「Lambda MicroVMs」を発表
Tags: Cloud

- Run isolated sandboxes with full lifecycle control — AWS Lambda introduces MicroVMs (2026-06-22)
  https://aws.amazon.com/blogs/aws/run-isolated-sandboxes-with-full-lifecycle-control-aws-lambda-introduces-microvms/
- AWS introduces Lambda MicroVMs for isolated execution of user and AI-generated code (2026-06-22)
  https://aws.amazon.com/about-aws/whats-new/2026/06/aws-lambda-microvms/
- AWS debuts Lambda MicroVMs with up to 8 hours runtime (2026-06-23)
  https://www.theregister.com/devops/2026/06/23/aws-debuts-lambda-microvms-with-up-to-8-hours-runtime/5260035

AWSはVMレベルの分離と最大8時間の状態保持を実現する新しいサーバーレス実行環境「Lambda MicroVMs」を発表した。AIエージェントやユーザー生成コードの安全な実行環境として設計されており、管理するインフラを必要とせずに高速な起動・一時停止・再開が可能で、FirecrackerベースのマイクロVM技術を活用してコンテナと比較して強固な分離性を提供する。

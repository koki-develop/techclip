# FBIとCISAがロシア系ハッカーによるSignalバックアップリカバリーキー窃取攻撃を警告
Tags: Security

- FBI: Russian hackers now target Signal backup recovery keys (2026-06-26)
  https://www.bleepingcomputer.com/news/security/fbi-russian-hackers-now-target-signal-backup-recovery-keys/
- FBI Warns Russian Intelligence Hackers Target Signal Backup Recovery Keys (2026-06-26)
  https://thehackernews.com/2026/06/fbi-warns-russian-intelligence-hackers.html

FBIとCISAは、ロシア情報機関に関連するハッカーグループがSignalユーザーを標的とするフィッシングキャンペーンを進化させ、バックアップリカバリーキーを窃取してメッセージ履歴へのアクセスを維持する手口を採用していると警告した。リカバリーキーが盗まれると、端末や電話番号を変えても攻撃者がアカウントにアクセスし続けられる危険性があり、ユーザーはリカバリーキーの保護と定期的な更新が推奨される。

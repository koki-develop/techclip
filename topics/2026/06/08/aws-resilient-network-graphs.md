# AWSがランダムグラフ理論ベースのネットワーク「RNG」をデータセンターに標準採用、ルーター69%削減を実現

AWSがほとんどの新規非GPUデータセンターで従来のファットツリー構成を廃止し、ランダムグラフ理論に基づく「Resilient Network Graphs (RNG)」を標準採用。ネットワーク機器を69%削減しながらスループットを最大33%向上・消費電力を約40%削減することに成功し、クラウドインフラの大規模な設計転換として注目されている。

# GitHub CLIがリモートリポジトリ読み取りをサポート、PR数制限やNode 24デフォルト化など開発者ツール強化
Tags: OSS

- Read remote repository content with GitHub CLI (2026-06-17)
  https://github.blog/changelog/2026-06-17-read-remote-repository-content-with-github-cli/
- Limit open pull requests for users without write access (2026-06-17)
  https://github.blog/changelog/2026-06-17-limit-open-pull-requests-for-users-without-write-access/
- GitHub Actions: Node 24 is now the default on GitHub-hosted runners (2026-06-16)
  https://github.blog/changelog/month/06-2026/

GitHub CLI v2.95.0に`gh repo read-file`と`gh repo read-dir`コマンドが追加され、クローンなしでリモートリポジトリのファイルを直接読み取れるようになった。同時に、書き込み権限のないユーザーのオープンPR数に上限を設ける機能や、GitHub ActionsランナーにおけるデフォルトNode.jsバージョンのNode 24への移行も発表された。

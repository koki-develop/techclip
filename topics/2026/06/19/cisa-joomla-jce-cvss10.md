# CISA、Joomla JCEプラグインのCVSS 10.0脆弱性が積極的に悪用されていると警告
Tags: Security

- CISA Warns of Actively Exploited Joomla JCE Flaw Allowing PHP Code Execution (2026-06-17)
  https://thehackernews.com/2026/06/cisa-warns-of-actively-exploited-joomla.html

CISAはJoomlaのContent Editor（JCE）拡張機能に存在するCVE-2026-48907（CVSS 10.0）を既知の悪用済み脆弱性カタログ（KEV）に追加した。この脆弱性は未認証ユーザーが悪意あるPHPコードをアップロードして実行できる最大深刻度の欠陥であり、JCEバージョン2.9.99.5以降へのアップデートが強く推奨されている。

# GitHub Copilot SDKが一般提供開始、6言語に対応しアプリへのエージェント機能組み込みが可能に
Tags: OSS, AI

- Copilot SDK is now generally available (2026-06-02)
  https://github.blog/changelog/2026-06-02-copilot-sdk-is-now-generally-available/

GitHubがCopilot SDKの一般提供（GA）を発表し、Node.js/TypeScript・Python・Go・.NET・Rust・Javaの6言語に対応した安定版APIを提供開始した。これにより開発者は自前のアプリケーションにGitHub Copilotのプランニング・ツール呼び出し・ファイル編集・ストリーミングといったエージェントランタイム機能を組み込めるようになった。

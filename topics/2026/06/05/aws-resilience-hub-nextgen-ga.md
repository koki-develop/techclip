# AWS Resilience Hub次世代版が一般提供開始、アプリのレジリエンス評価・テスト機能を強化
Tags: Cloud

- AWS announces next-gen AWS Resilience Hub (2026-05-29)
  https://aws.amazon.com/about-aws/whats-new/2026/05/aws-announces-next-gen-aws-resilience-hub/

AWSが次世代AWS Resilience Hubの一般提供（GA）を発表し、アプリケーションの耐障害性評価・テスト・改善をより高度に自動化する機能が追加された。エンタープライズ規模のクラウドワークロードに対して可用性目標（RTO/RPO）の達成状況を継続的に監視・改善できる基盤として強化されている。

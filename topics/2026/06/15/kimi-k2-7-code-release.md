# Moonshot AIがコーディング特化モデル「Kimi K2.7-Code」をオープンウェイトでリリース、ベンチマークで前世代比21.8%向上
Tags: AI

- Moonshot AI Releases Kimi K2.7-Code: a Coding Model Reporting +21.8% on Kimi Code Bench v2 Over K2.6 (2026-06-12)
  https://www.marktechpost.com/2026/06/12/moonshot-ai-releases-kimi-k2-7-code-a-coding-model-reporting-21-8-on-kimi-code-bench-v2-over-k2-6/
- Kimi K2.7-Code: Moonshot's coding-first open-source release (2026-06-12)
  https://www.digitalapplied.com/blog/kimi-k2-7-code-release-open-source-coding-model

Moonshot AIが1兆パラメータのMoEアーキテクチャを採用したコーディング特化モデル「Kimi K2.7-Code」をオープンウェイトでリリース。前バージョンKimi K2.6と比較してコーディングベンチマーク（Kimi Code Bench v2）で21.8%の性能向上を達成しつつ、推論トークン使用量を約30%削減した。256Kトークンのコンテキストウィンドウを持ち、長期的・自律的なソフトウェアエンジニアリングタスクをターゲットとするエージェント型コーディングモデルである。

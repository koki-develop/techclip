# .NET 10.0.9・9.0.17・8.0.28リリース、2件のCVEに対処するセキュリティアップデートを提供
Tags: Programming Languages

- .NET and .NET Framework June 2026 servicing releases updates (2026-06-09)
  https://devblogs.microsoft.com/dotnet/dotnet-and-dotnet-framework-june-2026-servicing-updates/

Microsoftは.NET 10.0.9、9.0.17、8.0.28を含む2026年6月のサービスアップデートをリリースした。CVE-2026-45491とCVE-2026-45490の2件のセキュリティ脆弱性が修正されており、.NET Framework向けのパッチも含まれている。

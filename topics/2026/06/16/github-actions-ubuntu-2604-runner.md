# GitHub ActionsにUbuntu 26.04とWindows 11 ARM64の新ランナーイメージがパブリックプレビューで登場

Tags: OSS

- New runner images in public preview (2026-06-11)
  https://github.blog/changelog/2026-06-11-new-runner-images-in-public-preview/

GitHub Actionsのホステッドランナーとして、Ubuntu 26.04（x64・arm64）とWindows 11 ARM64（Visual Studio 2026搭載）の新イメージがパブリックプレビューとして追加された。ワークフロー定義に`runs-on: ubuntu-26.04`と記述するだけで利用可能で、最新OSに対応したCI/CD環境の構築が容易になる。

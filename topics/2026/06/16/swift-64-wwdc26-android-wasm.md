# WWDC26でSwift 6.4がリリース、Android公式サポート・WebAssembly高速化・Swift Buildのデフォルト化など開発者向け機能が大幅強化

Tags: Programming Languages

- WWDC 2026 - What's New in Swift (2026-06-12)

WWDC 2026（6月8〜12日）にてSwift 6.4が正式リリースされ、AndroidへのSwift SDK公式サポート、WebAssembly経由のJavaScriptブリッジの高速化、`@C`属性によるC言語へのSwift関数エクスポート、Swift PackageManagerのデフォルトバックエンドとしてSwift Buildの採用など多数の改善が発表された。

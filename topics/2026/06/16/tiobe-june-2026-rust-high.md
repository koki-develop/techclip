# TIOBE 2026年6月版でRustが史上最高の12位に浮上、PythonはシェアがTIOBE史上最高水準から低下

Tags: Programming Languages

- TIOBE Index June 2026: Rust Hits New High as Python Slips (2026-06-16)
  https://www.techrepublic.com/article/news-tiobe-june-2026-rust-hits-new-high/

2026年6月のTIOBEプログラミング言語人気指数が公開され、Rustが同指数史上最高位となる12位に到達した。一方でPythonは19%を下回るシェアにまで後退し、C++がJavaを再び上回るなど、システムプログラミング言語の復権が鮮明になっている。

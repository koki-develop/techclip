# AlibabaがAIエージェント向け言語世界モデル「Qwen-AgentWorld」を公開、GPT-5.4やClaude Opus 4.8を上回る性能
Tags: AI

- Qwen-AgentWorld: Language World Models for General Agents (2026-06-24)
  https://arxiv.org/abs/2606.24597
- Alibaba's model never trained as an agent — and improved agent performance across seven benchmarks (2026-06-24)
  https://venturebeat.com/technology/alibabas-model-never-trained-as-an-agent-and-improved-agent-performance-across-seven-benchmarks
- Qwen-AgentWorld: Language World Models for General Agents (2026-06-24)
  https://www.alibabacloud.com/blog/qwen-agentworld-language-world-models-for-general-agents_603304

Alibaba Qwenチームが、AIエージェントが行動した後の環境状態を予測する「言語世界モデル（LWM）」Qwen-AgentWorldをオープンソースで公開した。MCP・Search・Terminal・SWE・Web・OS・Androidの7ドメインをカバーし、AgentWorldBenchにおいてGPT-5.4やClaude Opus 4.8を上回る性能を示している。

# F5がNGINX Open Sourceの重大なRCE脆弱性2件にパッチ公開、CVSS 9.2のHTTP/3・HTTP/2バグ

Tags: Security

- F5 Patches Two Critical NGINX Open Source Flaws Enabling Remote Code Execution (2026-06-18)
  https://thehackernews.com/2026/06/f5-patches-two-critical-nginx-open.html

F5がNGINX Open Sourceに存在する2件の重大な脆弱性（CVE-2026-42530およびCVE-2026-42055、CVSS 9.2）にパッチを公開した。HTTP/3 QUICモジュールのuse-after-free欠陥とHTTP/2プロキシのヒープバッファオーバーフローで、いずれも認証不要でリモートコード実行が可能な深刻な問題となっており、速やかなアップデートが推奨されている。

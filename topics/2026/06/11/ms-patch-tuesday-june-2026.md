# Microsoft 2026年6月Patch Tuesdayで200件の脆弱性と6件のゼロデイを修正、公開直後に新ゼロデイ「RoguePlanet」も発覚
Tags: Security

  https://www.bleepingcomputer.com/news/microsoft/microsoft-june-2026-patch-tuesday-fixes-6-zero-days-200-flaws/
- Microsoft patches YellowKey, GreenPlasma, MiniPlasma zero-days (2026-06-10)
  https://www.bleepingcomputer.com/news/microsoft/microsoft-patches-yellowkey-greenplasma-miniplasma-zero-days/
- Microsoft Defender 'RoguePlanet' zero-day grants SYSTEM privileges (2026-06-09)
  https://www.bleepingcomputer.com/news/microsoft/microsoft-defender-rogueplanet-zero-day-grants-system-privileges/

Microsoftの2026年6月Patch Tuesdayでは過去最多規模となる200件の脆弱性が修正され、BitLockerバイパス（YellowKey）やSYSTEM権限取得（GreenPlasma・MiniPlasma）を含む6件のゼロデイが含まれた。修正公開の直後、研究者がDefenderの新たなゼロデイ「RoguePlanet」を公開し、完全にパッチ済みのWindows 10/11環境でもSYSTEM権限のシェルを取得できることが明らかになった。

# Node.jsが年間メジャーリリースを2回から1回に変更、Node 27からすべてのリリースがLTS対応へ
Tags: OSS, Programming Languages

- Node.js Moves to One Major Release Per Year, Starting with Node 27 (2026-06-09)
  https://www.infoq.com/news/2026/06/nodejs-release-changes/
- Node.js is changing its release schedule and version numbers (2026-06-04)
  https://nodejsdesignpatterns.com/blog/nodejs-release-schedule-changes/

Node.jsプロジェクトが2026年10月より年間メジャーリリースを2回から1回に削減すると発表した。これまでの奇数・偶数バージョンの区別が廃止され、すべてのリリースがLTS（長期サポート）対応となる新スケジュールに移行する。Node 27が最初の新方式リリースとなり、エコシステム全体のアップグレードサイクルが簡素化される。

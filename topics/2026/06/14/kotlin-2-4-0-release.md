# Kotlin 2.4.0リリース、Java 26サポートやWebAssembly Component ModelなどKMP強化が目玉
Tags: Programming Languages

- Kotlin 2.4.0 Released (2026-06-10)
  https://blog.jetbrains.com/kotlin/2026/06/kotlin-2-4-0-released/
- Java Annotated Monthly – June 2026 (2026-06-10)
  https://blog.jetbrains.com/idea/2026/06/java-annotated-monthly-june-2026/

JetBrainsがKotlin 2.4.0を正式リリースした。Java 26のサポート、Swift Packagesの依存関係サポート、Kotlin/NativeでのCMS GCのデフォルト有効化、Kotlin/WasmでのWebAssembly Component Modelサポートなど、Kotlin Multiplatform（KMP）の強化を中心に多数の新機能が追加されている。

# Rust 1.96.0リリース、コピー可能なレンジ型とassert_matches!マクロが安定化
Tags: Programming Languages

- Announcing Rust 1.96.0 (2026-05-28)
  https://blog.rust-lang.org/2026/05/28/Rust-1.96.0/

Rust 1.96.0が正式リリースされ、RFC 3550に基づくコピー可能なレンジ型（Copy range types）の安定化、`assert_matches!`マクロの追加、WebAssemblyビルド時の未定義シンボルリンクのデフォルト禁止などの改善が含まれた。また、サードパーティクレートレジストリ利用者に影響するセキュリティ脆弱性2件（CVE-2026-5223、CVE-2026-5222）の修正も合わせて行われた。

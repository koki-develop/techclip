# GitHub CopilotのJetBrains IDE向け更新でClaudeをエージェントプロバイダーとして利用可能に（プレビュー）
Tags: OSS, AI

- New features and Claude as agent provider preview in JetBrains IDEs (2026-06-22)
  https://github.blog/changelog/2026-06-22-new-features-and-claude-as-agent-provider-preview-in-jetbrains-ides/

GitHub CopilotのJetBrains IDE向けアップデートで、ClaudeをCopilotのエージェントプロバイダーとして利用できるプレビュー機能が追加された。開発者はIntelliJやWebStormなどJetBrains製品内でClaude Sonnetを活用したコーディング支援を試せるようになり、VS Code以外の環境へのAIエージェント統合が拡大している。

# GitHubがエージェントネイティブのデスクトップアプリ「GitHub Copilot app」をテクニカルプレビューで公開
Tags: OSS, AI

- GitHub Copilot app: The agent-native desktop experience (2026-06-02)
  https://github.blog/news-insights/product-news/github-copilot-app-the-agent-native-desktop-experience/
- GitHub Copilot app launches as desktop home for AI coding agents (2026-06-08)
  https://www.helpnetsecurity.com/2026/06/08/github-copilot-app-ai-coding-agents/

GitHubは複数のAIエージェントを並列管理できるスタンドアロンデスクトップアプリ「GitHub Copilot app」をテクニカルプレビューとして公開した。複数リポジトリにまたがる作業を一元管理する「My Work」ビューや、人間とAIエージェントが共同作業できる「キャンバス」機能を備え、従来のエディタ拡張を超えた「エージェントネイティブ」なワークフロー環境を提供する。

# MicrosoftとDellがAzure Localで規制産業向けソブリンAIプライベートクラウドを推進、コスト64%削減を訴求
Tags: Cloud

- Azure Local deployments deliver digital sovereignty (2026-05-27)
  https://siliconangle.com/2026/05/27/azure-local-deployments-deliver-digital-sovereignty-delltechworld/

Dell Technologies World 2026にてMicrosoftとDellが規制産業向けのソブリンAI対応プライベートクラウドとしてAzure LocalとDellの分離型インフラの組み合わせを発表した。パブリッククラウドに依存せずデータ主権とAI推論を両立できるとして、ハイパーコンバージドインフラと比較して約64%のコスト削減を実現するとした。

# GoogleがAndroid 6月セキュリティパッチを公開、実際に悪用されたゼロデイ含む124件の脆弱性を修正

Googleは2026年6月のAndroidセキュリティパッチを公開し、合計124件の脆弱性を修正した。このうちAndroid Frameworkに存在するゼロデイ脆弱性（CVE-2025-48595）は標的型攻撃で実際に悪用されており、Android 14以降のデバイスが影響を受けるため早急なアップデートが推奨される。

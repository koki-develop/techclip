# GitHub Agentic Workflowsがパブリックプレビューへ移行、Actions内でAIエージェントによる自動化が可能に
Tags: OSS, AI

- GitHub Agentic Workflows is now in public preview (2026-06-11)
  https://github.blog/changelog/2026-06-11-github-agentic-workflows-is-now-in-public-preview/
- Agentic workflows no longer need a personal access token (2026-06-11)
  https://github.blog/changelog/2026-06-11-agentic-workflows-no-longer-need-a-personal-access-token/

GitHub Agentic Workflowsがパブリックプレビューへとステータスを昇格し、IssueトリアージやCI失敗分析などの推論ベースのタスクをGitHub Actions内のAIコーディングエージェントで自動化できるようになった。ワークフローをMarkdownで自然言語定義でき、個人アクセストークン（PAT）も不要になったことで、セキュアかつシンプルな運用が実現している。

# 1Passwordがハッキングを受け、従業員GitHubアカウント侵害で顧客データとソースコードが流出

パスワード管理サービスの1Passwordは、従業員のGitHubアカウントが11月19日に不正アクセスを受けたと発表した。攻撃者はバックエンドシステムへの侵入に成功し、顧客の氏名・メールアドレス・アカウント識別子やアカウント招待用トークン、一部のソースコードを窃取したという。パスワードボールトや復旧キーなど暗号化されたデータ自体には影響がないとしており、同社はGitHub・CI/CD・エンドポイントの管理強化や認証情報のローテーションなどの対応を実施した。

# FBIの犯罪情報データベース(NCIC)が不正アクセスを受けたと報道
Tags: Security

- FBI reportedly hacked again, this time targeting nationwide police database (2026-11-21)
  https://www.bleepingcomputer.com/news/security/fbi-reportedly-hacked-again-this-time-targeting-nationwide-police-database/
- FBI crime database reportedly hacked (2026-11-23)
  https://www.malwarebytes.com/blog/data-breaches/2026/11/fbi-crime-database-reportedly-hacked

FBIが運営する全米犯罪情報センター(NCIC、約1930万件のレコードを保有)が不正アクセスを受けたと報じられた。NCICは警察が令状確認や行方不明者捜索などに利用する重要システムであり、FBIにとって短期間で2件目の侵害報道となったことから懸念が広がっている。FBIは調査を進めている。

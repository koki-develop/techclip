# Visual Studio Code 1.148がリリース、AIエージェント実行中のアイドルスリープ防止などを追加
Tags: OSS

- Visual Studio Code 1.148 (2026-11-25)
  https://code.visualstudio.com/updates/v1_148

Visual Studio Code 1.148がリリースされた。AIエージェントの実行中にシステムがアイドルスリープに入ることを防ぐ機能、Git worktreeの自動クリーンアップ、実験的なサンドボックスプロファイルなどが追加され、エージェントチャットの応答速度も改善された。

# Microsoft Entra Connect Healthの脆弱性が悪用され、テナントの管理者情報が流出
Tags: Security, Cloud

- Microsoft Entra Connect Health flaw exploited to steal tenant data (2026-11-21)
  https://www.bleepingcomputer.com/news/security/microsoft-entra-connect-health-flaw-exploited-to-steal-tenant-data/
- After outage, Microsoft confirms another July bug that led to Entra data breach (2026-11-21)
  https://www.neowin.net/news/after-outage-microsoft-confirms-another-july-bug-that-led-to-entra-data-breach/
- Hackers Exploit Microsoft Entra Connect Health Flaw to Access Admin Emails and Organization Data (2026-11-22)
  https://cybersecuritynews.com/microsoft-entra-connect-health-flaw/

Microsoft Entra Connect HealthのAPIに存在した脆弱性が悪用され、管理者や技術担当者のメールアドレス、テナントID、ライセンス階層、ディレクトリ同期状況などのメタデータが読み取り専用で不正に取得された。脆弱性は7月23日に導入され11月9日に発見、Microsoftは11月19日にサーバー側の修正を適用し翌日調査を完了したと説明している。パスワードや認証トークン、暗号鍵への影響はないとされる。

# Rust 1.100がリリース、約10年越しの「never型」が正式採用
Tags: Programming Languages, OSS

- ついに「Rust 1.100」リリース、約10年越しの新機能が正式採用されパッケージの安全対策も強化 (2026-11-16)
  https://gigazine.net/news/20261116-rust-1-100/

Rustの新バージョン1.100がリリースされ、約10年の開発期間を経て「never型」が正式に安定化された。あわせてCargoに、依存パッケージが公開された直後の利用を避ける「min-publish-age」機能が追加され、サプライチェーン攻撃への対策も強化された。

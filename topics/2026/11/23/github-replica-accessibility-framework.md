# GitHubがAIプロトタイピングツール「Replica」とOSSアクセシビリティ推進の新フレームワークを公開
Tags: OSS

- The best things in open source are built together (2026-11-19)
  https://github.blog/open-source/maintainers/the-best-things-in-open-source-are-built-together/

GitHubはAIを活用したプロトタイピングツール「Replica」と、オープンソースプロジェクトのアクセシビリティ対応を段階的に進めるための「Open Source Accessibility Framework」をオープンソースで公開した。あわせて、2026年のパブリックコントリビューションが25億件に達したことも報告している。

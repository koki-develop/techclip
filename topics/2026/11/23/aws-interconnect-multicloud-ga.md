# AWSがAzureなど他クラウドとのプライベート接続サービス「AWS Interconnect」を正式提供開始
Tags: Cloud

- AWS announces AWS Interconnect, a managed multicloud connectivity service (2026-11-17)
  https://aws.amazon.com/about-aws/whats-new/2026/11/aws-announces-AWS-interconnect-multicloud-azure-ga/

AWSはMicrosoft Azure(将来的にはGoogle Cloud、Oracle Cloud Infrastructureにも対応予定)との間でマネージドなプライベート接続を迅速にプロビジョニングできる新サービス「AWS Interconnect」の一般提供を開始した。企業がマルチクラウド構成を組む際の接続構築の手間を大幅に簡素化する。

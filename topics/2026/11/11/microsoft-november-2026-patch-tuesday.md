# Microsoftが2026年11月のPatch Tuesdayで過去最多規模の脆弱性を修正、悪用済みのOutlookゼロデイも含む
Tags: Security

- Microsoft November 2026 Patch Tuesday fixes 1,235 flaws, Outlook zero-day (2026-11-10)
  https://www.bleepingcomputer.com/news/microsoft/microsoft-november-2026-patch-tuesday-fixes-1-235-flaws-outlook-zero-day/
- Exploited Outlook Zero-Day Among 1,094 Flaws Patched by Microsoft (2026-11-10)
  https://www.securityweek.com/exploited-outlook-zero-day-among-1094-flaws-patched-by-microsoft/
- Microsoft fixes over 1,000 vulnerabilities in November Patch Tuesday (2026-11-10)
  https://cyberscoop.com/microsoft-patch-tuesday-november-2026/

Microsoftは11月の月例セキュリティ更新で1,000件を超える脆弱性(報道によって1,094〜1,235件)を修正した。中にはNTLMv2ハッシュの窃取に悪用されていたOutlookのゼロデイ脆弱性(CVE-2026-124194)が含まれ、既に実際の攻撃で使われていたことから、CISAは既知の悪用脆弱性カタログに追加し、連邦機関に11月24日までの対応を求めた。

# N-ableのRMMツール「N-central」に30件超のゼロデイ、クラウド版を緊急停止
Tags: Security

- N-able takes cloud platform offline after 30+ "zero-days" published (2026-11-09)
  https://www.bleepingcomputer.com/news/security/n-able-takes-n-central-cloud-offline-after-30-plus-zero-days-published/
- N-able Takes N-central Cloud Offline After Researcher Discloses 33 Zero-Days with PoC Exploits (2026-11-09)
  https://thehackernews.com/2026/11/n-able-takes-hosted-n-central-offline.html

研究者が「Able2Shell」と称し、N-ableのリモート監視管理(RMM)ツール「N-central」に存在する33件の未修正脆弱性とPoC(概念実証)コードを公開した。これを受けてN-ableは、世界中でホストしているN-centralクラウドサービスを緊急停止した。セキュリティ企業Huntressによれば、複数の脆弱性を組み合わせることで遠隔コード実行や権限昇格が可能になるという。N-centralは多数の企業がIT管理に利用するRMMツールであり、影響範囲の大きさが懸念されている。

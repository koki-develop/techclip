# JetBrains、Kotlin Toolchain 0.14をリリース、エージェント型開発支援とiOS公開のワンコマンド化に対応
Tags: Programming Languages

- Kotlin Toolchain 0.14: Agentic Development and iOS Publishing (2026-11-17)
  https://blog.jetbrains.com/kotlin/2026/11/kotlin-toolchain-0-14-agentic-development-and-ios-publishing/

JetBrainsがKotlin Toolchain 0.14を公開した。TestFlightへのiOSアプリ公開をコマンド一つで行えるようになり、AIエージェントによる開発を支援する新しいスキル機能も追加され、Kotlin Multiplatformでの開発体験向上を図っている。

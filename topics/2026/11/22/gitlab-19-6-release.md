# GitLab 19.6がリリース、エージェント型の脆弱性修正機能などを追加、直後に緊急パッチも公開
Tags: OSS, Security

- GitLab 19.6 released (2026-11-19)
  https://docs.gitlab.com/releases/19/gitlab-19-6-released/
- GitLab Critical Patch Release: 19.6.1, 19.5.8, 19.4.10 (2026-11-20)
  https://docs.gitlab.com/releases/patches/patch-release-gitlab-19-6-1-released/

GitLab 19.6が正式リリースされ、脆弱性対応を自動化するエージェント型リメディエーションやシークレット検出時のトークン自動失効・再発行(ベータ)などAI活用機能が追加された。しかし公開直後に新たな脆弱性が発見され、翌日には19.6.1・19.5.8・19.4.10を含む緊急パッチリリースが公開される事態となった。

# PHPが緊急セキュリティリリース、17件の脆弱性を修正(重大7件、最高CVSS9.2)
Tags: Security

- PHP Fixes 7 Critical Flaws, Including Bugs That Could Allow Remote Code Execution (2026-11-19)
  https://thehackernews.com/2026/11/php-fixes-7-critical-flaws-including.html
- PHP: News Archive - 2026 (2026-11-19)
  https://www.php.net/archive/2026.php

PHP Foundationは、PHP 8.2.36、8.3.37、8.4.28、8.5.13を対象とする緊急セキュリティリリースを公開し、エンジンのuse-after-free、PHP-FPM、セッション処理、date拡張などに関する計17件の脆弱性を修正した。このうち7件は重大(Critical)判定で、最高CVSSスコアは9.2に達し、遠隔コード実行につながる欠陥も含まれている。同日にはメジャーバージョンのPHP 8.6.0も正式リリースされている。

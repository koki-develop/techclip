# Atlassianが2026年11月セキュリティ更新を公開、Jira・Confluence・Bitbucketなど複数製品で318件の脆弱性を修正

- Atlassian Patches 318 Security Vulnerabilities Across Jira, Confluence, Bitbucket and Other Products (2026-11-18)
  https://cybersecuritynews.com/atlassian-patches-318-security-vulnerabilities/
- Atlassian Patches 318 Security Vulnerabilities Affecting Jira, Confluence and Bitbucket (2026-11-18)
  https://cyberpress.org/atlassian-patches-318-security-vulnerabilities/

Atlassianが、Jira、Confluence、Bitbucket、Bamboo、Crowdなど複数のエンタープライズ製品を対象に2026年11月のセキュリティ更新を公開した。重大度「重大」52件、「高」266件を含む計318件の脆弱性が修正され、Lodash由来の遠隔コード実行欠陥(CVE-2026-4800)やパストラバーサルなど、サードパーティ依存ライブラリに起因する問題も多数含まれている。

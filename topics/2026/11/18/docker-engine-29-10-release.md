# Docker Engine 29.10.0リリース、Engine APIをOpenAPI 3.2形式へ移行
Tags: OSS

- Docker Engine 29.10.0 release notes (2026-11-16)
  https://docs.docker.com/engine/release-notes/29/

Docker Engine 29.10.0が公開された。Engine APIの仕様がOpenAPI 3.2形式に移行し、`/etc/docker/containerd.d/`による組み込みcontainerdのカスタマイズに対応。あわせていくつかのバグ修正も行われた。

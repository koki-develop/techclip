Tags: OSS, Security

- GitLab、XSSや認可不備など34件のCVEを修正するパッチリリース (19.5.6/19.4.8/19.3.9) (2026-11-16)
  https://docs.gitlab.com/releases/patches/patch-release-gitlab-19-5-6-released/
- GitLab Patches 37 Security Vulnerabilities Affecting CI/CD Pipelines, GitLab Pages, and MCP Server (2026-11-17)
  https://gbhackers.com/gitlab-patches-37-security-vulnerabilities/
- GitLab Patches 37 Security Flaws, Including High-Severity CI/CD and XSS Vulnerabilities (2026-11-16)
  https://cyberpress.org/gitlab-patches-37-security-bugs/

GitLabがCommunity Edition/Enterprise Editionの19.5.6・19.4.8・19.3.9をリリースし、Wiki関連のXSSやCI/CDパイプラインジョブの認可不備、GitLab Pagesの脆弱性など、CVSS 8.7相当を含む30件超のセキュリティ脆弱性を修正した。

# ハッカーが4,800件のGitHubアカウントを侵害し6万超のリポジトリからクラウド認証情報を窃取
Tags: Security

- Attacker Targets 60,000 GitHub Repositories in Credential Theft Campaign (2026-11-12)
  https://www.securityweek.com/attacker-targets-60000-github-repositories-in-credential-theft-campaign/
- GitHub Actions Attack Hits 1,835 Repos With Secret Stealer (2026-11-12)
  https://techaeris.com/2026/11/12/github-actions-attack-hits-1835-repos/

「wfx-loot」と呼ばれる攻撃キャンペーンにより、4,837件の侵害されたGitHubアカウントを踏み台として6万件超のリポジトリが標的にされ、悪意あるワークフローを含むプルリクエストが送信された。1,800件超のリポジトリでシークレット窃取マルウェアが実際に実行され、GitHub Actionsのシークレットやクラウド認証情報が窃取された。被害にはFortune100企業や米政府機関も含まれる。

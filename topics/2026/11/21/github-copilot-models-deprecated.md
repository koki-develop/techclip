# GitHub Copilot、Claude Opus 4.8/5やGPT-5.6 Terraなど旧モデルを非推奨化
Tags: OSS, AI

- GitHub Copilot models deprecated on November 16, 2026 (2026-11-16)
  https://github.blog/changelog/2026-11-16-github-copilot-models-deprecated-on-november-16-2026/

GitHub Copilotのチャット、インラインエディット、エージェントモード、コード補完機能などで、Claude Opus 4.8/5やGPT-5.6 Terraといった旧モデルが非推奨となった。代替としてClaude Opus 5.5やGPT-6.1 Sol、GPT-6 Lunaなどの利用が推奨されており、開発者は該当モデルを利用している統合設定の見直しが必要となる。

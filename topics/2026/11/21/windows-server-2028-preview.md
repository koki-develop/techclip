# MicrosoftがWindows Server 2028のパブリックプレビューを公開、AI推論基盤とポスト量子暗号に対応
Tags: Cloud

- Windows Server 2028: A trusted foundation for an evolving enterprise (2026-11-17)
  https://techcommunity.microsoft.com/blog/windowsservernewsandbestpractices/windows-server-2028-a-trusted-foundation-for-an-evolving-enterprise/4574112

Microsoftは Ignite 2026で次期サーバーOS「Windows Server 2028」のパブリックプレビューを公開した。Microsoft Foundryと連携したオンプレミスAI推論基盤や、ポスト量子暗号への対応、NVMeをデフォルトストレージとする強化などエンタープライズ向け機能を多数導入している。

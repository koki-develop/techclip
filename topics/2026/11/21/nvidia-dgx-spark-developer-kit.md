# NVIDIAが4台連結で512GBメモリを実現する「DGX Spark Developer Kit」をSC26で発表
Tags: Other, AI

- NVIDIAが小型AIスパコンDGX Sparkを4台つなげてメモリ容量512GBを実現する「DGX Spark Developer Kit」を発表、最大700Bのモデルを実行可能 (2026-11-17)
  https://gigazine.net/news/20261117-dgx-spark-developer-kit

NVIDIAはスーパーコンピューティング学会「SC26」にて、小型AIコンピュータ「DGX Spark」を4台連結し、メモリ容量512GB・最大700Bパラメータのモデルを実行可能にする開発者キット「DGX Spark Developer Kit」を発表した。専用のネットワーク機材を増設することなく、大規模言語モデルの開発・検証を手元の環境で行えるようにする狙いがある。

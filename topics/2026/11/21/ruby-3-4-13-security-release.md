# Ruby 3.4.13がリリース、正規表現エンジンの複数のRCE脆弱性を修正
Tags: Programming Languages, Security

- Ruby 3.4.13 Released (2026-11-18)
  https://www.ruby-lang.org/en/news/2026/11/18/ruby-3-4-13-released/

正規表現エンジンと文字列の大文字小文字変換処理に発見された7件の脆弱性(うち6件は遠隔コード実行につながる恐れがある)を修正したRuby 3.4.13がリリースされた。同時に3.3.14や4.0.10など他の対応バージョンも公開されており、利用者には早急なアップグレードが推奨されている。

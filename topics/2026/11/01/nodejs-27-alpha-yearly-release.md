# Node.js、年次メジャーリリースモデルへ移行する第一弾としてv27.0.0-alphaを公開
Tags: Programming Languages, OSS

- Node.js 27.0.0-alpha.0.0.0 (2026-10-29)
  https://nodejs.org/en/blog/release/v27.0.0-alpha.0.0.0

Node.jsプロジェクトが、リリーススケジュールを奇数/偶数バージョンによるLTS分割方式から年次メジャーリリース方式へ切り替える第一歩として、v27.0.0-alpha.0.0.0を公開した。V8エンジンをバージョン15.6に更新しており、新方式ではこれまでの隔バージョンごとのLTS移行とは異なる運用になる見込み。

# GitHub Octoverse 2026、プルリクエストの40%以上がAIエージェントの初稿から開始と判明
Tags: AI, OSS

- Octoverse: Commits, pushes, reach new highs in 2026 as developers build with agents (2026-10-28)
  https://github.blog/news-insights/octoverse/octoverse-commits-pushes-reach-new-highs-in-2026-as-developers-build-with-agents/

GitHubが公開した年次レポート「Octoverse」によると、2026年9月時点でプルリクエストの40%以上がAIエージェントによる最初のドラフトから始まっており、3月時点の17%から大幅に増加した。コミット数やプッシュ数も過去最高を記録し、開発者がAIエージェントを活用したワークフローへ急速に移行している実態が明らかになった。

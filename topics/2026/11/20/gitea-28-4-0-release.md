# Gitea 28.4.0がリリース、リポジトリ初期化時のコマンド実行など21件のCVEを修正
Tags: OSS, Security

- Gitea 28.4.0 is released (2026-11-15)
  https://blog.gitea.com/release-of-28.4.0/

自前でホストできるGitサービスGiteaの28.4.0が公開され、リポジトリ初期化中のコマンド実行脆弱性やTOTP総当たり攻撃、パスワードハッシュ漏洩など19件の自社コード由来の脆弱性を含む計21件のCVEが修正された。影響の大きさから全利用者に即時アップグレードが強く推奨されている。

# JavaScriptフレームワーク「Solid 2.0」が安定版リリース、非同期処理をリアクティブグラフに統合
Tags: Programming Languages

- Solid 2.0 - The Long Hold (2026-11-16)
  https://www.solidjs.com/blog/solid-2-0-the-long-hold/

JavaScript UIフレームワーク「Solid」のバージョン2.0が安定版としてリリースされた。非同期処理がリアクティブグラフに直接組み込まれ、サーバー関数や楽観的更新(optimistic updates)などの機能が新たに追加された。

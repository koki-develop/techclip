# PostgreSQL向けオープンソースベクトル検索拡張「pg_vectorsearch」が公開
Tags: OSS

- Open Source pg_vectorsearch Brings More Scalable Vector Search to PostgreSQL (2026-11-07)
  https://www.infoq.com/news/2026/11/postgresql-vector-search/

Tiger DataがPostgreSQL向けのオープンソースベクトル検索拡張機能「pg_vectorsearch」を公開した。グラフベースのHNSWとは異なるPRISMインデックス方式を採用し、大規模データセットでのメモリ効率とインデックス構築速度を大幅に改善している。

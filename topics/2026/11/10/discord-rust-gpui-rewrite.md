# Discordがデスクトップ・モバイルアプリをRustとGPUIで再構築、ElectronとReact Nativeから移行
Tags: Programming Languages

- Discord is rebuilding in Rust, leaving React and Electron behind (2026-11-06)
  https://www.heise.de/en/news/Discord-is-rebuilding-in-Rust-leaving-React-and-Electron-behind-11516113.html
- Discord is killing its Electron app that can eat 4GB of RAM on Windows 11, and the Rust rebuild uses just 290MB (2026-11-05)
  https://www.windowslatest.com/2026/11/05/discord-is-killing-its-electron-app-that-can-eat-4gb-of-ram-on-windows-11-and-the-rust-rebuild-uses-just-290mb/
- Discord Is Rebuilding Its Desktop App in Rust, With the New Client Using 290 MB of RAM (2026-11-06)
  https://www.ghacks.net/2026/11/06/discord-is-rebuilding-its-desktop-app-in-rust-with-the-new-client-using-290-mb-of-ram/

Discordのデスクトップ・モバイルクライアントがElectron/React NativeからRustとZed開発のGPUIフレームワークへ移行することが明らかになった。CTOのStanislav Vishnevskiy氏によると、早期ビルド「Discord Phoenix」のメモリ使用量は約290MBに抑えられており、従来のElectron版がWindows 11で最大4GBのRAMを消費していた問題の解消を狙う。正式なリリース時期は未定。

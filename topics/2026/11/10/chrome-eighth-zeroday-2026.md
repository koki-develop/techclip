# Google、Chromeで2026年8件目の悪用済みゼロデイ脆弱性を修正
Tags: Security

- Google Issues Chrome Security Update for Eighth Actively Exploited Zero-Day of 2026 (2026-11-10)
  https://thehackernews.com/2026/11/google-issues-chrome-security-update.html
- Google patches eighth Chrome zero-day exploited in attacks this year (2026-11-10)
  https://www.bleepingcomputer.com/news/security/google-patches-eighth-chrome-zero-day-exploited-in-attacks-this-year/
- Chrome Update Patches Exploited XML Zero-Day, Eighth This Year (2026-11-10)
  https://www.securityweek.com/chrome-update-patches-exploited-xml-zero-day-eighth-this-year/

GoogleはChrome 157.0.8103.50/.51をリリースし、XMLコンポーネントに存在する実際に悪用されているUse-After-Free脆弱性(CVE-2026-125350)を含む9件の脆弱性を修正した。この脆弱性は11月6日に匿名の研究者から報告されたもので、2026年に入ってChromeで修正された悪用済みゼロデイとしては8件目となる。Googleは攻撃の詳細な手法については公開していない。

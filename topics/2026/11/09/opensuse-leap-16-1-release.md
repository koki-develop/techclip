# 「openSUSE Leap 16.1」がリリース、イミュータブルサーバーモードを統合
Tags: OSS

- openSUSE Leap 16.1 Released With Immutable Server Integration (2026-11-03)
  https://www.phoronix.com/news/openSUSE-Leap-16.1

openSUSEプロジェクトは「openSUSE Leap 16.1」をリリースした。SUSE Linux Enterprise Server 16.1と同じソースからビルドされている点に加え、イミュータブルサーバーモードが統合され、KDE Plasma 6.6やLinuxカーネル6.12 LTSを採用している。

# Ruby on Railsが「8.0.5.2」「8.1.4.1」をリリース、ImageMagick処理の重大な脆弱性含む21件を修正
Tags: Programming Languages, Security

- Rails security releases: 8.0.5.2 and 8.1.4.1 (2026-11-04)
  https://discuss.rubyonrails.org/t/rails-security-releases-8-0-5-2-and-8-1-4-1/91802

Ruby on Railsコアチームは、セキュリティリリース「8.0.5.2」と「8.1.4.1」を公開した。Active StorageがImageMagickで画像を処理する際に任意のファイルを読み書きできてしまう重大な脆弱性をはじめ、合計21件のセキュリティ問題が修正されている。影響を受けるアプリケーションの運用者には、速やかなアップデートが推奨されている。

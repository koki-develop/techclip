# AWS、Equinixのデータセンターと直結する新サービス「Interconnect - last mile」をプレビュー公開
Tags: Cloud

- AWS announces AWS Interconnect - last mile preview with Equinix (2026-11-04)
  https://aws.amazon.com/about-aws/whats-new/2026/11/interconnect-last-mile-preview-equinix/

AWSは、Equinixの282拠点のデータセンターとAWSを数クリックで接続できる新サービス「AWS Interconnect - last mile」のプレビューを発表した。4重冗長構成と99.99%の可用性SLA、MACsecによる暗号化を標準で提供し、オンプレミス環境とAWSとの低遅延・高信頼な接続を容易にする。

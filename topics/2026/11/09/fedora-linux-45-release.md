# 「Fedora Linux 45」が正式リリース、GNOME 51やRPM署名検証の強制化などを追加
Tags: OSS

- Fedora Linux 45 リリース (2026-11-03)
  https://www.techbarrista.com/fedora-linux-45-release/

Fedora Linux 45が正式リリースされた。デスクトップ環境はGNOME 51とKDE Plasma 6.8.1を採用し、Linuxカーネルは7.2系にアップデートされている。セキュリティ面ではRPMパッケージの署名検証がデフォルトで強制化されるなど、サプライチェーンの安全性強化に向けた変更が導入された。

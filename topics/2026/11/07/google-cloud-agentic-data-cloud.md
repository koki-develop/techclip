# Google Cloud、マルチクラウド対応の「Agentic Data Cloud」を拡張、IcebergベースのクロスクラウドレイクハウスをGA化
Tags: Cloud, AI

- What's new across Google's Agentic Data Cloud (2026-11-04)
  https://cloud.google.com/blog/products/databases/whats-new-across-googles-agentic-data-cloud

Google Cloudが「Agentic Data Cloud」構想を拡張し、AWSやAzure上のデータにエグレス料金なしでクエリできるApache Iceberg基盤のクロスクラウド・レイクハウス機能を一般提供した。同時に軽量なPostgres互換サービス「AlloyDB Express」や、メタデータを統合管理する強化版「Knowledge Catalog」も発表し、AIエージェントがマルチクラウド環境のデータを扱いやすくする狙いがある。

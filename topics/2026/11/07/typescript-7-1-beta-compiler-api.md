# TypeScript 7.1ベータ公開、7.0で失われたコンパイラAPIを復活させVue/Svelteの型チェックにも対応
Tags: Programming Languages

- TypeScript 7.1 Beta: Restores the Compiler API and Makes Vue and Svelte First-Class (2026-11-06)
  https://www.infoq.com/news/2026/11/typescript-7-1-beta/

MicrosoftがTypeScript 7.1のベータ版を公開した。Go言語で書き直されたTypeScript 7.0で失われていたコンパイラAPI(`typescript/sync`など新しいエントリポイント)を復活させ、新機能「content mappers」によりVueやSvelteのような非標準ファイルの型チェックが可能になった。Directusのアプリでは型チェック速度が最大4.6倍向上したと報告されている。

# Go 1.27.4/1.26.11がリリース、cgoフラグ注入など12件の脆弱性を修正
Tags: Programming Languages, Security

- Go 1.27.4 and 1.26.11 are now available (2026-11-10)
  https://devcenter.heroku.com/changelog-items/3909

Go言語の1.27.4および1.26.11がリリースされた。標準ライブラリとツールチェインに影響する12件のセキュリティ脆弱性が修正され、cmd/goにおけるcgoフラグ注入やHTTP/1サーバーのクラッシュにつながる問題などが対処された、必須のセキュリティメンテナンスリリースとなる。

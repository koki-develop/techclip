# DeepSeekが自律型コーディングエージェント「Super-Agent」をオープンソース化
Tags: AI, OSS

- DeepSeek open-sources Super-Agent, a coding agent that reads team chats (2026-11-01)
  https://thenextweb.com/news/deepseek-super-agent-open-source-coding-agent

DeepSeekが、GitHubリポジトリや社内チャットを監視しながら人間の手を極力介さずに開発タスクを処理する自律型コーディングエージェント「Super-Agent」のプロトタイプをオープンソースで公開した。研究目的のプロトタイプと位置づけられており、チームのコミュニケーションを読み取って作業に反映する点が特徴とされている。

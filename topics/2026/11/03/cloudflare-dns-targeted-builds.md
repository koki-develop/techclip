# Cloudflareが「ターゲット型ビルド」でDNSのビルド遅延を半減、メモリ使用量を85%削減
Tags: Cloud

- How we halved DNS build delay and cut memory use by 85% (2026-11-02)
  https://blog.cloudflare.com/dns-targeted-zone-builds/

Cloudflareは、DNSゾーンの設定変更時に全体を再構築せず変更箇所に限定して再構築する「ターゲット型ビルドプランナー」を開発したと発表した。これによりフルビルドの発生数を40%削減し、ピーク時のメモリ使用量を85%、ビルド完了までの遅延を半減させたとしている。

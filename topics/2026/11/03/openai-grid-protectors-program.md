# OpenAI、AIデータセンターの電力網負荷を緩和する「Grid Protectors Program」を開始
Tags: AI, Other

- OpenAI Launches Grid Protectors Program for Compute Campuses (2026-11-02)
  https://www.securities.io/openai-launches-grid-protectors-program-with-planned-georgia-pilot/

OpenAIは、AIデータセンター(同社が「コンピュートキャンパス」と呼ぶ施設)が電力網のピーク負荷時に使用量を自主的に削減する「Grid Protectors Program」を開始したと発表した。最初の試験導入先としてジョージア州の3.2ギガワット規模のキャンパスを予定しており、AI需要拡大に伴う電力網への負荷増大への対応策として、地域の電力供給安定化への協力を打ち出す。

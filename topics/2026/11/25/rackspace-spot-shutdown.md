# Rackspace、Kubernetesシークレット窃取の侵害を受けクラウドサービス「Spot」の終了を発表
Tags: Cloud, Security

- Rackspace discloses security breach of Spot cloud platform (2026-11-22)
  https://www.scworld.com/brief/rackspace-discloses-security-breach-of-spot-cloud-platform
- Rackspace shuts down Spot cloud platform after security breach (2026-11-24)
  https://www.bleepingcomputer.com/news/security/rackspace-shuts-down-spot-cloud-platform-after-security-breach/

Rackspaceは11月17日に発生した認証情報の不正利用によるSpotクラウドプラットフォームへの侵害を開示した。攻撃者はKubernetesクラスタ内のSecretやkubeconfigを窃取し、不正なPodの作成やノード・ボリュームの一覧取得が可能な状態にあったという。同社はこの侵害を受けてSpotサービス自体の終了を決定し、顧客に12月8日午後5時(中部時間)までの移行を求めている。

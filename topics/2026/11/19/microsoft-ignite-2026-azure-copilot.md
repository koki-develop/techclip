# MicrosoftがIgnite 2026で新Azure CPU「Cobalt 200」やCopilot機能拡充を発表
Tags: Cloud, AI, OSS

- Microsoft Ignite 2026: What's new in Azure, the platform purpose-built for AI (2026-11-17)
  https://azure.microsoft.com/en-us/blog/microsoft-ignite-2026-whats-new-in-azure-the-platform-purpose-built-for-ai/
- Copilot at Microsoft Ignite: Expanding what's possible with intelligence built for work (2026-11-17)
  https://www.microsoft.com/en-us/copilot/blog/2026/11/17/copilot-at-microsoft-ignite-expanding-whats-possible-with-intelligence-built-for-work/
- GitHub Copilot in JetBrains, Ignite releases (2026-11-17)
  https://github.blog/changelog/2026-11-17-github-copilot-in-jetbrains-ignite-releases/

Microsoftが年次カンファレンス「Ignite 2026」で、AI向けに最適化した新CPU「Azure Cobalt 200」やPostgreSQL互換データベース「Azure HorizonDB」の一般提供、エージェント主導のモダナイゼーション基盤「Azure Catalyst」などAzureプラットフォームの大型刷新を発表した。同時に、個人用M365エージェント「Copilot Autopilot」やコード生成機能「Copilot Code」の一般提供など企業向けCopilotの機能拡充も発表され、さらにJetBrains向けGitHub Copilotにクラウドサンドボックスでのセッション実行やブラウザ操作連携を追加するなど、開発者向けAIツールも強化された。

# PHP 8.6が正式リリース、部分適用やナノ秒精度の新Durationクラスを追加
Tags: Programming Languages

- PHP 8.6 Released (2026-11-19)
  https://www.php.net/releases/8.6/en.php
- What's new in PHP 8.6 and what that means for WordPress? (2026-11-18)
  https://developer.wordpress.org/news/2026/11/whats-new-in-php-8-6-and-what-that-means-for-wordpress/

PHP公式チームがPHP 8.6を正式リリースした。関数の一部引数を固定して新しい関数を作る「部分適用(Partial Function Application)」、ナノ秒精度で時間を扱う\Time\Durationクラス、epoll/kqueueベースの新しいPolling API、値を範囲内に収めるclamp()関数などが新たに追加された。

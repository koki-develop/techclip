# JetBrainsが「IntelliJ IDEA 2026.3」をリリース、エージェント型開発基盤「JetBrains Air」とJava 28対応を追加
Tags: OSS, Programming Languages

- IntelliJ IDEA 2026.3 release notes (2026-11-05)
  https://www.jetbrains.com/help/idea/new-in-this-release.html
- IntelliJ IDEA 2026.3 Released With JetBrains Air, Java 28 Support and 1,000+ Bug Fixes (2026-11-05)
  https://vinish.dev/intellij-idea-2026-3-released-air-java-28-git-worktrees

JetBrainsがIDE「IntelliJ IDEA」の最新版2026.3をリリースした。エージェント型開発を担う新プラットフォーム「JetBrains Air」の提供、Java 28対応、Git worktreesのサポートが追加され、1,000件を超えるバグ修正と300件以上のパフォーマンス改善が行われた。

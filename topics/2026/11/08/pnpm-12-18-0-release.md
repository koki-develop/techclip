# パッケージマネージャー「pnpm」v12.18.0がリリース、メタデータ取得量を大幅削減
Tags: Programming Languages, OSS

- pnpm 12.18.0 (2026-11-05)
  https://pnpm.io/blog/releases/12.18.0

JavaScript/TypeScript向けパッケージマネージャー「pnpm」のv12.18.0がリリースされた。プラットフォームバリアント対応のpack/publishコマンドが追加され、メタデータのダウンロード量を大幅に削減することでパフォーマンスが改善。複数のpeer依存関係解決に関するバグ修正も行われた。

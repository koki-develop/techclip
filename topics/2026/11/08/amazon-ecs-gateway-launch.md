# AWSがECS向けフルマネージド型イングレス「Amazon ECS Gateway」を発表
Tags: Cloud

- Amazon ECS Gateway Arrives with Generated Hostnames and No Custom Domain Support (2026-11-04)
  https://www.infoq.com/news/2026/11/introducing-amazon-ecs-gateway/

AWSはAmazon ECS上で稼働するサービス向けに、フルマネージド型のイングレスソリューション「Amazon ECS Gateway」を発表した。アカウントレベルでネットワーキングを一度定義すれば、各アプリケーションチームはコネクタを介してサービスを接続できるようになり、個別にロードバランサーやネットワーキングを構成する手間を省ける。現時点ではAWSが自動生成するホスト名のみに対応し、カスタムドメインの利用はサポートされていない。

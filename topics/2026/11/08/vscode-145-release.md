# 「VS Code 1.145」がリリース、リモートエージェント接続でのブラウザプレビューやcronによる自動化スケジュールを追加
Tags: OSS, AI

- Visual Studio Code 1.145 (2026-11-04)
  https://code.visualstudio.com/updates/v1_145

Microsoftは開発環境「Visual Studio Code」のバージョン1.145を公開した。リモートエージェント接続上でのブラウザプレビューやインタラクティブキャンバス、複数のAIエージェントを同一セッション内で混在させる機能、cron式によるカスタム自動化スケジュールなどが新たに追加された。前バージョン1.144で導入されたCopilot FusionやAgent Host Protocolに続き、エディタをAIエージェントの操作基盤として位置づける方向性をさらに強めている。

# 認証機関DigiCertでサーバー移行時の設定ミスによるデータ侵害が発覚、顧客情報や本人確認書類が流出
Tags: Security

- DigiCert data breach exposes customer information, identity documents (2026-11-05)
  https://www.bleepingcomputer.com/news/security/digicert-data-breach-exposes-customer-information-identity-documents/
- DigiCert reports data breach following server migration error (2026-11-05)
  https://www.scworld.com/brief/digicert-reports-data-breach-following-server-migration-error

認証機関DigiCertは、2025年2月のサーバー移行時の設定ミスにより内部システムが誤ってインターネットに公開されていたと公表した。2026年6月27日から7月2日の間に侵入者が顧客の連絡先情報や一部の本人確認書類(パスポートや運転免許証など)にアクセスしていたことが10月19日の調査完了で判明した。証明書発行サービス自体への影響はないとしているが、インターネットの信頼基盤を担う認証機関での情報漏洩として注目されている。

  https://code.visualstudio.com/updates/v1_146
- VS Code 1.146 Adds AI Agent Inbox, Model Comparisons and Chat Windows (2026-11-12)

Visual Studio Code 1.146が公開された。複数のAIエージェントセッションを管理する「Inboxモード」、Copilot Fusionで複数モデルの応答を比較できる機能、チャットを独立ウィンドウとして切り出せる機能などが追加され、AIエージェントを活用した開発ワークフローの強化が図られている。

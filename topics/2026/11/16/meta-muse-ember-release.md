# Meta、エージェント実行向けの軽量AIモデル「Muse Ember」を公開
Tags: AI

- Meta releases Muse Ember, a new lightweight model for agent execution (2026-11-09)
  https://techcrunch.com/2026/11/09/meta-releases-muse-ember-a-new-lightweight-model-for-agent-execution/

Meta Superintelligence Labsは、ツール呼び出しやコーディング補助、文書解析などエージェント実行タスクに特化した軽量モデル「Muse Ember」を公開した。大規模モデルに比べ低コスト・低遅延で動作し、エージェント型アプリケーションへの組み込みを容易にすることを狙っている。

# AWSがローカル環境でAWSサービスをエミュレートするOSSツール「AWS Emulator」を正式リリース
Tags: Cloud, OSS

- Test your applications against AWS locally with AWS Emulator (2026-11-11)
  https://aws.amazon.com/blogs/aws/test-your-applications-against-aws-locally-with-aws-emulator/

AWSは、AWS CLIやSDK、AIコーディングエージェントからローカルマシン上でほぼ全てのAWSサービスをエミュレートできる無料のオープンソースツール「AWS Emulator」を正式リリースした。コードの大部分はAIエージェントが書いたもので、本番利用ではなく開発・テスト用途向けに位置付けられている。

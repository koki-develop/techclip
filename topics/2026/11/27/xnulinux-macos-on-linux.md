# macOSのXNUカーネルをLinuxカーネルモジュールとして動かすOSS「xnulinux」公開、GUIアプリ実行も可能に
Tags: OSS

- 'xnulinux' enables a complete macOS GUI user space on Linux (2026-11-26)
  https://gigazine.net/gsc_news/en/20261126-xnu-linux/

macOSのオープンソースカーネル「XNU」をLinuxカーネルモジュール(xnu.ko)として動作させ、Linux上でmacOSのGUIユーザースペース全体を再現するプロジェクト「xnulinux」が公開された。SafariやFinderといったmacOS標準アプリをLinux環境上でそのまま実行できるようになり、両OSのカーネル境界を越えた野心的な技術的試みとして注目されている。

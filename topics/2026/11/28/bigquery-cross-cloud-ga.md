# Google BigQueryのクロスクラウド接続機能が正式リリース(GA)
Tags: Cloud

- BigQuery release notes: Cross-cloud connections reach general availability (2026-11-25)
  https://docs.cloud.google.com/bigquery/docs/release-notes

Google Cloudは、BigQueryからAWSやAzure、Salesforce Data 360上のデータをBigQuery Omniを使わずに全リージョンから直接クエリできる「クロスクラウド接続」機能を正式リリース(GA)したと発表した。

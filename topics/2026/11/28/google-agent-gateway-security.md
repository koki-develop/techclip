# Google、企業向けAIエージェントを安全に展開する新基盤「Agent Gateway」を発表
Tags: Cloud, AI, Security

- Deploying agents safely in your enterprise (2026-11-24)
  https://cloud.google.com/blog/products/identity-security/deploying-agents-safely-in-your-enterprise

Googleは企業向けにAIエージェントを安全に展開するための新機能を発表した。Google Workspace MCPサーバーとCLIを一般提供開始するとともに、ポリシーチェックやエージェント専用IDなど統一的なセキュリティ制御を提供する「Google Cloud Agent Gateway」を導入する。2027年2月からは新インターフェース経由のアクセスが義務化される予定で、企業内でのAIエージェント利用拡大に伴うガバナンス強化の動きとなる。

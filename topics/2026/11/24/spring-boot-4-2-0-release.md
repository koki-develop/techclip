# 「Spring Boot 4.2.0」リリース、AMQP 1.0対応やOpenTelemetry連携を強化
Tags: Programming Languages

- Spring Boot 4.2.0 available now (2026-11-19)
  https://spring.io/blog/2026/11/19/spring-boot-4-2-0-available-now/

JavaのWebアプリケーションフレームワーク「Spring Boot」の4.2.0がリリースされた。AMQP 1.0への対応、OpenTelemetryのセマンティック規約への準拠、Cloud Native Buildpacksのレジストリ連携キャッシュなどが追加され、非推奨となったRestTemplateなど既存機能の整理も行われた。

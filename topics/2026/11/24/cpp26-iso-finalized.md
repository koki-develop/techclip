# ISO C++委員会がC++26の技術作業を完了、契約機能の仕様を再合意
Tags: Programming Languages

- C++26 is done (again)! — Trip report: November 2026 ISO C++ standards meeting (Búzios, Brazil) (2026-11-21)
  https://herbsutter.com/2026/11/21/c26-is-done-again-trip-report-november-2026-iso-c-standards-meeting-buzios-brazil/

ISO C++委員会はブラジル・ブジオスで開催された会議で、C++26の技術作業を再度完了したと発表した。前回の標準化作業で議論を呼んだ契約機能(Contracts)について、常時有効化(always-enforced)される仕様を定めるP4451R2を92.5%の賛成で採択し、再送付することを決定した。

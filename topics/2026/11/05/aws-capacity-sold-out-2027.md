# AWS、Jassy CEOが「2027年分のクラウド容量はほぼ売り切れ」と発言
Tags: Cloud

- AWS Capacity Largely Sold out through 2027, with On-Demand Headroom Reserved (2026-11-01)
  https://www.infoq.com/news/2026/11/aws-capacity-sold-out/

AWSのAndy Jassy CEOが、2027年分のクラウド容量がほぼ売り切れ状態にあり、2028年分の一部についても予約が入っていると発言した。AI需要の急増によるクラウド容量不足が続く中、アナリストはオンデマンドの標準GPU容量については依然利用可能だと指摘している。

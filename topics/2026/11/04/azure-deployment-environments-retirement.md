# Microsoft、Azure Deployment EnvironmentsとDev Boxを後継製品なしで提供終了
Tags: Cloud

- Microsoft Retires Azure Deployment Environments with No Replacement Product (2026-10-30)
  https://www.infoq.com/news/2026/10/ade-dev-box-retirement/

Microsoftは、Azure Deployment Environments(2027年2月22日廃止)とMicrosoft Dev Box(2028年9月18日廃止)の提供終了を発表した。両サービスに後継製品は提供されず、MicrosoftはBicepやARMテンプレートを用いた直接のInfrastructure as Codeデプロイへの移行を利用者に推奨している。

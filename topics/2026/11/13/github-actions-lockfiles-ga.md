# GitHub Actionsのワークフロー依存関係ロックファイルが一般提供開始、サプライチェーン攻撃対策を強化
Tags: OSS, Security

- GitHub Actions Lockfiles Reach GA to Secure Workflow Dependencies (2026-11-06)
  https://www.infoq.com/news/2026/11/github-actions-lockfiles-ga/

GitHub Actionsのワークフロー依存関係ロックファイル(`.github/workflows/actions.lock`)が一般提供(GA)となった。サプライチェーン攻撃対策として、ワークフローで使用するアクションの特定コミットを固定して実行できるようになり、`gh actions-lock` CLI拡張やDependabotによる自動更新もサポートされる。

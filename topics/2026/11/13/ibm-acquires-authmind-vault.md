# IBMがエージェントID管理のAuthMindを買収、HashiCorp Vaultに統合
Tags: Cloud, Security, Other

- IBM Advances Agent Identity Security With New Vault Capabilities (2026-11-12)
  https://newsroom.ibm.com/blog-ibm-advances-agent-identity-security-with-new-vault-capabilities

IBMがアイデンティティセキュリティ企業AuthMindを買収し、HashiCorp VaultにAIエージェントの認証情報管理・監視機能を統合すると発表した。エージェント型AIの普及に伴い高まるID・認証情報管理の重要性に対応する動きとなる。

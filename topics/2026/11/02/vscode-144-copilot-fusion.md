# 「VS Code 1.144」がリリース、Copilot Fusionやエージェント連携用「Agent Host Protocol」、AI画像生成を追加

- VS Code 1.144 Unleashes Copilot Fusion, AI Image Generation and Computer Use (2026-10-28)

- Visual Studio Code 1.144 Ships: Microsoft Turns Editor Into an AI Agent Command Center (2026-10-28)
  https://www.ntcompatible.com/story/visual-studio-code-1144-ships-microsoft-turns-editor-into-an-ai-agent-command-center

Microsoftは開発環境「Visual Studio Code」のバージョン1.144を公開した。複数のAIモデルへ処理内容に応じて自動振り分けする「Copilot Fusion」、GPT Image 2.5 Flareを用いたチャット内でのAI画像生成、実験的にPC操作を自動化する「Computer Use」機能などが新たに追加された。また新しい「Agent Host Protocol(AHP)1.0」により、AIエージェントのセッションをVS Code・Copilotアプリ・GitHub.com・モバイル間で継続できるようになり、エディタをAIエージェントの操作基盤として位置づける方向性を強めている。Copilot Fusionの利用には11月30日まで30%の割引キャンペーンが適用される。

# GitHub Actions、信頼性向上のためホステッドランナーをAzureとAWSのマルチクラウド構成に
Tags: OSS, Cloud

- GitHub Actions adds multi-cloud compute to improve reliability (2026-10-28)
  https://github.blog/changelog/2026-10-28-github-actions-adds-multi-cloud-compute-to-improve-reliability/

GitHubは、CI/CDサービス「GitHub Actions」のホステッドランナーについて、従来のMicrosoft Azureに加えてAmazon Web Services(AWS)も活用するマルチクラウド構成に移行したと発表した。特定クラウド基盤の障害や混雑による影響を軽減し、ジョブのキュー待ち時間の短縮と全体的な信頼性向上を図る狙いがある。

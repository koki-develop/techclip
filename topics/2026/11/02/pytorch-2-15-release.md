# 「PyTorch 2.15」がリリース、NCCLバックエンド再設計とフライトレコーダー機能を追加
Tags: Programming Languages, OSS

- PyTorch 2.15 Release Blog (2026-10-28)
  https://pytorch.org/blog/pytorch-2-15-release-blog/

PyTorch 2.15が公開された。分散学習向けに再設計されたNCCLバックエンドがデフォルトとなり、通信がハングした際に診断情報を出力する「フライトレコーダー」機能が追加された。またApple SiliconでのFP8サポートなど、複数のハードウェア・性能面の改善も含まれている。

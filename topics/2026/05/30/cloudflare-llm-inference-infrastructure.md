# CloudflareがLLMをグローバルネットワーク上で実行する高性能推論インフラを構築
Tags: AI, Cloud

- Cloudflare Builds High-Performance Infrastructure for Running LLMs (2026-05-26)
  https://www.infoq.com/news/2026/05/cloudflare-llm-infrastructure/

CloudflareはLLMをグローバルネットワーク全体で効率的に実行するための新インフラを発表した。入力処理と出力生成を異なる最適化システムに分離し、独自の推論エンジンでGPUをより効率的に管理することで、エッジでの低遅延AI推論を実現する設計となっている。

# MicrosoftがOpen Source Summit NA 2026でマルチエージェントSDK「Agent Framework」とAzure Container Linux GAを発表
Tags: OSS, Cloud

- From open source to agentic systems: Microsoft at Open Source Summit North America 2026 (2026-05-18)
  https://opensource.microsoft.com/blog/2026/05/18/from-open-source-to-agentic-systems-microsoft-at-open-source-summit-north-america-2026/
- Open Source Summit North America 2026 Schedule Showcases Next Era of AI Infrastructure, Security and Open Ecosystems (2026-05-18)
  https://www.linuxfoundation.org/press/open-source-summit-north-america-2026-schedule-showcases-next-era-of-ai

ミネアポリスで開催中のOpen Source Summit NA 2026（5月18〜20日）にてMicrosoftがマルチエージェントシステム構築用OSSの「Microsoft Agent Framework」、AIエージェントにOSレベルのセキュリティを付与する「Agent Governance Toolkit」、そしてコンテナ最適化不変OSの「Azure Container Linux」GA開始を発表した。

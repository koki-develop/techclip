# Google I/O 2026: Cloud RunがNVIDIA RTX PRO 6000 Blackwell GPU対応をGA、Firebase AIがエージェントネイティブプラットフォームへ進化
Tags: Cloud, AI

- Cloud Run gets NVIDIA RTX PRO 6000 Blackwell GPU support and MCP servers at Google I/O 2026 (2026-05-19)
  https://cloud.google.com/blog/products/serverless/whats-new-for-cloud-run-at-next26
- Firebase AI Logic goes GA at Google I/O 2026 as Firebase evolves into agent-native platform (2026-05-19)
  https://io.google/2026/explore/pa-keynote-13

Google I/O 2026にてCloud RunがNVIDIA RTX PRO 6000 Blackwell GPUサポートを一般提供開始し、70Bパラメータ以上の大規模モデルの推論をスケールゼロで実現できるようになった。同時にFirebaseがAIエージェント向けのプラットフォームへと刷新され、Firebase AI Logic（旧Vertex AI in Firebase）がGAとなった。

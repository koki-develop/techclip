# Drupalが「高度に重大」なコアセキュリティアップデートをリリース、認証不要で悪用可能な脆弱性に緊急対応
Tags: Security

- Drupal to Release Urgent Core Security Updates on May 20, Sites Told to Prepare (2026-05-19)
  https://thehackernews.com/2026/05/drupal-to-release-urgent-core-security.html
- Upcoming highly critical release on May 20, 2026 - PSA-2026-05-18 (2026-05-18)
  https://www.drupal.org/psa-2026-05-18
- Clear your calendar, Drupal user: You have a critically urgent patch to install (2026-05-19)
  https://www.theregister.com/security/2026/05/19/drupal-warns-admins-to-brace-for-highly-critical-core-patch/5242728

Drupalは25点満点中20点と評価される「高度に重大」な脆弱性を含むコアセキュリティアップデートを2026年5月20日にリリースした。当該脆弱性は認証不要かつアクセス複雑度なしで悪用可能であり、セキュリティチームは公開後数時間以内にエクスプロイトが作成される可能性があるとして全サイト管理者に緊急のアップデートを呼びかけた。

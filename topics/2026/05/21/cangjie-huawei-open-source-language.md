# Huaweiが開発した新OSSコンパイル言語「蒼頡（Cangjie）」を公開、代数的データ型とエフェクトハンドラをネイティブサポート
Tags: Programming Languages

- Cangjie, a New Open-Source Compiled Language with Native Effect Handlers and Algebraic Data Types (2026-05-14)
  https://www.infoq.com/news/2026/05/cangjie-effect-handlers-adt/

HuaweiのEdinburgh研究センターが開発した新しいオープンソースコンパイル言語「Cangjie（仓颉）」がInfoQで詳しく紹介された。代数的データ型（ADT）とエフェクトハンドラをネイティブサポートし、Java・Kotlin・Swiftに対抗するアプリ開発向け言語として設計されており、Huaweiのモバイル・IoTエコシステムへの組み込みが見込まれる。

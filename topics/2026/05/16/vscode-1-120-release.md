# Visual Studio Code 1.120リリース、エージェントウィンドウがStable昇格しAIコーディング体験を強化
Tags: OSS

- Visual Studio Code 1.120 (2026-05-13)
  https://code.visualstudio.com/updates/v1_120
- Hands On with the New Agents Window in VS Code 1.120 (2026-05-13)
  https://visualstudiomagazine.com/articles/2026/05/13/hands-on-with-the-new-agents-window-in-vs-code-1,-d-,120.aspx

VS Code 1.120がリリースされ、エージェントウィンドウが正式版（Stable）に昇格した。BYOK（Bring Your Own Key）モデルの可視性向上、エージェントによるブラウザタブへのアクセス機能、Markdown品質向上など多数の機能強化が含まれており、AIコーディング体験の改善が中心的なテーマとなっている。

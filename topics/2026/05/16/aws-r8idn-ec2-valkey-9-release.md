# AWSが新世代EC2インスタンス（R8idn/M8idn）とElastiCache Valkey 9.0を発表、AI対応インフラを拡充
Tags: Cloud

- AWS Updates 2026-05-14: New R8idn/R8idb and M8idn/M8idb EC2 Instances, Valkey 9.0 for ElastiCache (2026-05-14)
  https://finopsweekly.com/news/aws-updates-2026-05-14/
- AWS Lambda supports scheduled scaling for functions on Lambda Managed Instances (2026-05-12)
  https://aws.amazon.com/about-aws/whats-new/2026/05/aws-lambda-managed-instances/

AWSはカスタムIntel Xeon 6プロセッサ搭載の新EC2インスタンスファミリー（R8idn/R8idb、M8idn/M8idb）を発表し、前世代比で最大43%高いvCPUあたり性能を提供する。あわせてAmazon ElastiCacheでValkey 9.0が一般提供開始となりフルテキスト検索機能などが追加されたほか、AWS Lambda Managed InstancesがEventBridge Schedulerによるスケジュールスケーリングに対応した。

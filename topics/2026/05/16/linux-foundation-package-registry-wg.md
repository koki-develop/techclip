# Linux Foundationがパッケージレジストリ持続可能性ワーキンググループを発足、AI由来トラフィック急増に対応
Tags: OSS

- Open Source Registries Join Linux Foundation Working Group to Address Machine-Generated Traffic (2026-05-10)
  https://news.slashdot.org/story/26/05/10/0023237/open-source-registries-join-linux-foundation-working-group-to-address-machine-generated-traffic

Linux Foundationが「Sustaining Package Registries Working Group」を立ち上げ、Sonatype・Rust Foundation・Python Software Foundation・RubyGemsなど主要なOSSエコシステムが参加した。AIツールによるパッケージ取得リクエストの急増が引き起こす経済的・セキュリティ上の課題に対処するため、共同ガバナンスと持続可能な資金調達モデルの構築を目指す。

サイバーセキュリティ企業のTrellixが、ソースコードリポジトリへの不正アクセスによるデータ侵害を確認し、法執行機関に通知したと発表した。フォレンジック専門家と協力して調査中であり、ソースコードが実際に悪用された形跡は現時点で確認されていないとしている。

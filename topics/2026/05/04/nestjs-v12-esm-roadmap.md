# NestJS v12のロードマップ公開、CommonJSからESMへの完全移行とZodネイティブ対応など大規模モダナイズを計画
Tags: Programming Languages

- NestJS v12 Roadmap: Full ESM Migration, Standard Schema Validation and Modernised Toolchain (2026-04-30)
  https://www.infoq.com/news/2026/04/nestjs-12-roadmap-esm/
- NestJS v12.0.0 Major Release Draft PR (2026-04-30)
  https://github.com/nestjs/nest/pull/16391

NestJS v12のロードマップが公開され、CommonJSからESMへの完全移行、ZodやValibotに対応するネイティブバリデーション機能、テストフレームワークのJestからVitestへの切り替えなど、エコシステム全体の大規模なモダナイズが計画されている。エンタープライズ向けNode.jsフレームワークの主要バージョンアップとして、多くの開発者に影響を与える変更が含まれる。

# MicrosoftがAWSマルチクラウド接続イニシアティブに参加、AWSとAzure間のプライベート直接接続が実現へ
Tags: Cloud

- Azure follows Google in joining AWS multicloud initiative (2026-04-28)
  https://intercept.cloud/en-gb/knowledge-base/news/azure-joins-aws-interconnect

MicrosoftがAWSの「AWS Interconnect - multicloud」への参加を表明し、Googleに続く2番目のパートナーとなった。これにより企業はAWSとAzure間でパブリックインターネットを経由しないプライベートでセキュアなクロスクラウド接続が利用可能になり、マルチクラウド戦略の実現が大幅に容易になる見通しだ。

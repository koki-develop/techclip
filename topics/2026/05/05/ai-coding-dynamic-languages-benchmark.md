# 13言語AIコーディングベンチマーク：動的言語が静的型付け言語より1.4〜2.6倍高速かつ安価
Tags: Programming Languages, AI

- Dynamic Languages Faster and Cheaper in 13-Language Claude Code Benchmark (2026-04-30)
  https://www.infoq.com/news/2026/04/ai-coding-language-benchmark/

Rubyコミッターの遠藤侑介氏が13言語でClaude Codeのコーディング性能を比較したベンチマークを実施し、Ruby・Python・JavaScriptなどの動的言語が静的型付き言語より1.4〜2.6倍速く、かつ低コストであるという結果を発表した。AIコーディング補助における言語選択がパフォーマンスとコストに与える影響を定量的に示した注目の研究となっている。

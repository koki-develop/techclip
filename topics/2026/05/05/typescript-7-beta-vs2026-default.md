# TypeScript 7 BetaがVisual Studio 2026 InsidersプレビューでデフォルトのTypeScriptエンジンに
Tags: Programming Languages

- TypeScript 7 Beta Now Enabled by Default in Visual Studio 2026 18.6 Insiders 3 (2026-04-30)
  https://devblogs.microsoft.com/visualstudio/typescript-7-beta-now-enabled-by-default-in-visual-studio-2026-18-6-insiders-3/

Visual Studio 2026 18.6 InsidersプレビューにてTypeScript 7 Betaがデフォルトで有効化された。Go言語で書き直されたTypeScriptコンパイラにより従来比最大10倍の高速な型チェックがIDEから直接体験できるようになり、開発者は新コンパイラの速度を実運用ワークフロー上で確認できる。

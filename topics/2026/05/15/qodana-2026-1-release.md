# JetBrains Qodana 2026.1リリース、C/C++が正式GA・Rust EAP開始
Tags: OSS, Programming Languages

- Qodana 2026.1 Release: Rust EAP, Stable C/C++ & New Inspections (2026-05-14)
  https://blog.jetbrains.com/qodana/2026/05/qodana-2026-1-release/

JetBrainsの静的解析ツールQodanaの2026.1版がリリースされ、Qodana for C/C++が正式GA（一般提供）となり、Rust向けEarlyAccessProgram（150以上のインスペクション搭載）が開始された。Kotlin・Python・C#向けの新インスペクションやQodana Public APIの公開も含まれ、CI/CDパイプラインへの統合機能も強化されている。

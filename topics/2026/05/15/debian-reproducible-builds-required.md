# Debian、再現可能ビルドをtestingブランチへの必須要件に正式採用
Tags: OSS, Security

- Debian Now Blocks Non-Reproducible Packages from Testing (2026-05-11)
  https://linuxiac.com/debian-now-blocks-non-reproducible-packages-from-testing/

Debian 14「Forky」の開発サイクルにおいて、2026年5月9日以降は再現可能ビルドの確認に失敗したパッケージがtestingブランチに入れなくなった。サプライチェーン攻撃対策としてバイナリの改ざんを検知するための仕組みを義務化した、Linuxディストリビューション界隈での重要なセキュリティマイルストーンとなっている。

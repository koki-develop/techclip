# GCC 16.1が正式リリース、C++20がデフォルト標準に変更されC++26機能の実験的サポートも追加

Tags: Programming Languages

- GCC 16.1 Released (2026-04-30)
  https://gcc.gnu.org/gcc-16/changes.html
- New features in GCC 16: Improved error messages and SARIF output (2026-04-28)
  https://developers.redhat.com/articles/2026/04/28/gcc-16-improved-error-messages-sarif-output

GCC 16.1が2026年4月30日に正式リリースされた。C++のデフォルト標準がGNU C++20に変更され、C++26のReflection・Contractsなどの実験的サポートが追加されている。また、エラーメッセージの階層的表示がデフォルト化され、SARIF形式やHTML形式の診断出力など開発者体験を改善する機能も含まれる。

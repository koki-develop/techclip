# PythonパッケージマネージャーuvがバージョンV0.11.8をリリース、Astralミラーからのself-updateに対応

Tags: OSS, Programming Languages

- uv 0.11.8 (2026-04-27)
  https://github.com/astral-sh/uv/releases/tag/0.11.8

RustベースのPythonパッケージマネージャー「uv」のバージョン0.11.8がリリースされた。`python pin`コマンドへの`--python-downloads-json-url`フラグ追加により任意のミラーからPythonをダウンロード可能になり、Astralミラーからのself-updateサポートも追加されている。

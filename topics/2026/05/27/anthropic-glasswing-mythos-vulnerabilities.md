# AnthropicのClaude Mythosが「Project Glasswing」でOSSに潜む1万件超の脆弱性を自律的に発見
Tags: AI, Security

AnthropicのAIモデル「Claude Mythos Preview」がProject Glasswingの一環として1,000以上のOSSプロジェクトをスキャンし、1万件以上の高・重大度脆弱性を自律的に特定した。FreeBSDで17年間見落とされていたRCE脆弱性（CVE-2026-4747）の自律的な発見・悪用実証を含む成果で、検出結果の90%以上が真陽性として検証されている。

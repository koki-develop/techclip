# GitHubがEclipse向けCopilotプラグインをMITライセンスでオープンソース化
Tags: OSS

- GitHub Copilot for Eclipse is open source (2026-05-21)
  https://github.blog/changelog/2026-05-21-github-copilot-for-eclipse-is-open-source/

GitHubがEclipse IDE向けのCopilotプラグインをMITライセンスのもとオープンソース化した。チャット、コード補完、エージェントモード、Eclipse統合レイヤーのコードが公開されており、コミュニティ主導の開発と透明性の向上を目的としている。

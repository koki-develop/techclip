# WordPress 7.0「Armstrong」が正式リリース、プロバイダー非依存のネイティブAIクライアントAPIを搭載

Tags: OSS

- WordPress 7.0 "Armstrong" – WordPress News (2026-05-20)
  https://wordpress.org/news/2026/05/armstrong/

WordPress 7.0「Armstrong」が2026年5月20日に正式リリースされた。プロバイダー非依存のネイティブAIクライアントAPI・Abilities APIが搭載されたほか、刷新された管理ダッシュボード、BreadcrumbsやIconなどの新ブロックが追加され、875名以上のコントリビューターの参加のもと420以上の機能強化とバグ修正が含まれる大型リリースとなった。

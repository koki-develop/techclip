# CiscoがSecure WorkloadのREST API認証不備（CVSS 10.0）を修正、未認証で管理者権限の取得が可能

Tags: Security, Cloud

- Cisco Patches CVSS 10.0 Secure Workload REST API Flaw Enabling Data Access (2026-05-20)
  https://thehackernews.com/2026/05/cisco-patches-cvss-100-secure-workload.html

CiscoはSecure WorkloadのREST APIに存在する最大深刻度の脆弱性（CVE-2026-20223、CVSS 10.0）を修正するパッチを公開した。未認証の遠隔攻撃者がAPIリクエストを悪用してサイト管理者権限を取得し機密データにアクセスできる欠陥で、バージョン3.10.8.3および4.0.3.17で修正されている。

# Node.js 26.2.0リリース、Temporal.Instantサポートとボリングssl量子耐性暗号を追加

Tags: Programming Languages

- Node.js 26.2.0 (Current) (2026-05-20)
  https://nodejs.org/en/blog/release/v26.2.0

Node.js 26.2.0がリリースされ、ファイルシステム統計オブジェクトへのTemporal.Instantサポート追加、HTTP 1xx任意ステータスコード送信用の新メソッド`writeInformation`、BoringSSL向けML-DSA・ML-KEM量子耐性暗号サポートなど100件以上の改善が含まれる。また`stream.compose`の安定化も行われ、Node.js 26系の機能整備が進んでいる。

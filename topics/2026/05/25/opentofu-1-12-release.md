# OpenTofu 1.12リリース、Terraformが未実装だった動的prevent_destroyサポートなど新機能追加
Tags: OSS, Cloud

- OpenTofu 1.12: The Feature Terraform Never Shipped (2026-05-21)
  https://www.infoq.com/news/2026/05/opentofu-release-terraform/
- OpenTofu 1.12 IaC Tool Adds Dynamic prevent_destroy Support (2026-05-21)
  https://linuxiac.com/opentofu-1-12-iac-tool-adds-dynamic-prevent_destroy-support/

OpenTofu 1.12.0がリリースされ、Terraformが実装してこなかった動的な`prevent_destroy`サポートが追加された。変数を使って環境ごとに異なるライフサイクルルールを適用できるようになり、モジュールを複製せずに本番・開発環境で異なる設定が可能となった。

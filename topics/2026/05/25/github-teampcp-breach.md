# TeamPCPがVS Code拡張機能経由でGitHub社員端末を侵害、3,800件超の内部リポジトリ流出
Tags: Security

- GitHub Breached — Employee Device Hack Led to Exfiltration of 3,800+ Internal Repos (2026-05-20)
  https://thehackernews.com/2026/05/github-investigating-teampcp-claimed.html
- TeamPCP breached GitHub's internal codebase via poisoned VS Code extension (2026-05-20)
  https://www.helpnetsecurity.com/2026/05/20/github-breached-teampcp/

脅威アクターグループ「TeamPCP」が悪意のあるVS Code拡張機能を通じてGitHub社員の端末を侵害し、約3,800件の内部リポジトリを流出させた。GitHubは顧客データへの影響は確認されていないとしているが、流出したソースコードは5万ドル以上での売却がリストアップされている。

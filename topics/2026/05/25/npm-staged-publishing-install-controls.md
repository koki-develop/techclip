npmのステージド公開機能が一般提供開始となり、パッケージのリリース前に2FA認証付きの承認ステップを挟めるようになった。npm 11.15.0では、ファイルパスやリモートURLなど非レジストリソースからのインストールを制御する新しいフラグも追加され、サプライチェーン攻撃への防御が強化された。

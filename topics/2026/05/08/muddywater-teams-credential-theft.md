# MuddyWaterがMicrosoft Teamsを悪用した認証情報窃取ランサムウェア攻撃を展開
Tags: Security

- MuddyWater Uses Microsoft Teams to Steal Credentials in False Flag Ransomware Attack (2026-05-06)
  https://thehackernews.com/2026/05/muddywater-uses-microsoft-teams-to.html

イラン政府が支援するハッキンググループMuddyWaterが、Microsoft Teamsを悪用したソーシャルエンジニアリングで認証情報を窃取するランサムウェア攻撃を展開していることが確認された。偽旗作戦として実施され、スクリーン共有を通じて被害者のMFA（多要素認証）を無効化する手口が特徴的で、組織のコラボレーションツール経由の攻撃リスクが改めて浮き彫りになった。

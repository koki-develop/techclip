# Python 3.14.5 RC1リリースとPython 3.15.0 beta 1公開、インクリメンタルGCを差し戻し
Tags: Programming Languages

- Python 3.14.5 Release Candidate (2026-05-04)
  https://blog.python.org/2026/05/python-3145rc1/
- A New Python Packaging Council and Other News for May 2026 (2026-05-01)
  https://realpython.com/python-news-may-2026/

Python 3.14.5のRC1が公開され、約113件のバグ修正に加えてメモリ圧迫問題の原因となっていたインクリメンタルGCをPython 3.13時代の世代別GCへ差し戻す重要な変更が含まれた。また、Python 3.15.0 beta 1が機能フリーズを達成し、Pythonパッケージング界では選出制の新しい評議会（Packaging Council）が正式ガバナンス体制として発足した。

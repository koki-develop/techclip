# GitHub MCP Serverにシークレットスキャン（GA）と依存関係スキャン（プレビュー）が追加
Tags: OSS, Security

- Secret scanning with GitHub MCP Server is now generally available (2026-05-05)
  https://github.blog/changelog/2026-05-05-secret-scanning-with-github-mcp-server-is-now-generally-available/
- Dependency scanning with GitHub MCP Server is in public preview (2026-05-05)
  https://github.blog/changelog/2026-05-05-dependency-scanning-with-github-mcp-server-is-in-public-preview/

GitHub MCP Serverにシークレットスキャン機能がGA（一般提供）として追加され、AIコーディングエージェントやIDEからコミット・PR作成前に認証情報の漏洩を検出できるようになった。同時に、Dependabotと連携してGitHub Advisory Databaseと照合する依存関係スキャン機能もパブリックプレビューとして公開された。

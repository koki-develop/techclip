# HuaweiがAlgebraic Data Types搭載の新プログラミング言語「Cangjie（仓颉）」をオープンソース化

Tags: Programming Languages

  https://www.infoq.com/news/2026/05/cangjie-effect-handlers-adt/
- Huawei to open-source self-developed programming language Cangjie to rival Java and Swift (2026-05-11)
  https://www.scmp.com/tech/big-tech/article/3316506/huawei-open-source-self-developed-programming-language-cangjie-rival-java-and-swift

HuaweiのプログラミングラボがAlgebraic Data Types（代数的データ型）とEffect Handlersを備えた汎用プログラミング言語「Cangjie（仓颉）」をオープンソース公開した。HarmonyOS向けを主軸とした高レベル静的型付け言語で、JavaやSwiftへの対抗を目指しており、中国産プログラミング言語として注目を集めている。

# GrafanaがKubernetes Monitoring Helm Chart v4をリリース、マルチクラスタGitOpsを強化

Tags: Cloud

- Grafana's Kubernetes Monitoring Helm Chart v4 Brings Multiple Fixes (2026-05-06)
  https://www.infoq.com/news/2026/05/kubernetes-monitoring-helm/

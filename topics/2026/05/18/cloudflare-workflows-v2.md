# Cloudflare、決定論的実行と同時5万インスタンスに対応した「Workflows V2」を発表
Tags: Cloud

- Cloudflare Introduces Workflows V2 with Deterministic Execution and 50K Concurrent Workflows (2026-05-15)
  https://www.infoq.com/news/2026/05/cloudflare-workflows-v2-release/

Cloudflareがエッジでのワークフローオーケストレーションエンジンを刷新した「Workflows V2」を発表した。決定論的かつ再現可能な実行アーキテクチャを採用し、同時実行数が最大5万インスタンス（従来比約11倍）、キュー容量が200万インスタンスへと大幅に拡張されている。

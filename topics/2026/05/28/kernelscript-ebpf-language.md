# KernelScript 0.1リリース：eBPF・ユーザー空間・カーネル空間を統合する型安全ドメイン固有言語
Tags: Programming Languages, OSS

- KernelScript: A Programming Language For Kernel Customization & App Optimizations (2026-05-24)
  https://www.phoronix.com/news/KernelScript
- KernelScript 0.1 Debuts as a New Language for eBPF Development (2026-05-25)
  https://linuxiac.com/kernelscript-0-1-debuts-as-a-new-language-for-ebpf-development/

Linux Open-Source Summitで発表されたKernelScript 0.1は、eBPF・ユーザー空間・カーネル空間の開発を単一コードベースに統合するApache 2.0ライセンスの型安全DSL。XDP・TC・probesなど主要eBPFプログラム種別をサポートし、C言語での手動eBPFプログラム記述を不要にすることで開発効率の向上を目指している。

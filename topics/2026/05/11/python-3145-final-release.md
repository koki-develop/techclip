# Python 3.14.5が正式リリース、154件以上のバグ修正とインクリメンタルGCの世代別GCへの差し戻しを含む
Tags: Programming Languages

- Python Release Python 3.14.5 (2026-05-10)
  https://www.python.org/downloads/release/python-3145/

Python 3.14の第5回メンテナンスリリースとなるPython 3.14.5が正式公開された。154件以上のバグ修正やビルド改善が含まれ、特に3.14.0〜3.14.4で導入されたインクリメンタルガベージコレクタが本番環境でのメモリ問題を受けて3.13系の世代別GCへ差し戻された点が注目される。

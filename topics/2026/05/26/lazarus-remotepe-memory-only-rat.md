# 北朝鮮系LazarusグループがメモリオンリーRAT「RemotePE」を金融・暗号資産企業に展開
Tags: Security

- RemotePE: The Lazarus RAT that lives in memory (2026-05-22)
  https://blog.fox-it.com/2026/05/22/remotepe-the-lazarus-rat-that-lives-in-memory/
- Lazarus Deploys RemotePE Memory-Only RAT Against Financial and Crypto Firms (2026-05-25)
  https://thehackernews.com/2026/05/lazarus-deploys-remotepe-memory-only.html

北朝鮮連動のLazarusグループが金融・暗号資産企業を標的に、メモリ上でのみ動作するC++製RAT「RemotePE」を展開していることが明らかになった。DPAPILoaderとRemotePELoaderによる多段階攻撃チェーンを用い、ファイルシステムに痕跡を残さず長期的な監視活動を行う設計となっている。

# IvantiのEPMMにRCEゼロデイ攻撃、CISAが連邦機関へ4日以内の修正を義務化
Tags: Security

- Ivanti warns of new EPMM flaw exploited in zero-day attacks (2026-05-07)
  https://www.bleepingcomputer.com/news/security/ivanti-warns-of-new-epmm-flaw-exploited-in-zero-day-attacks/

IvantiはEndpoint Manager Mobile（EPMM）に存在するリモートコード実行の脆弱性CVE-2026-6973がゼロデイ攻撃として悪用されていると警告し、バージョン12.6.1.1未満のユーザーに緊急パッチの適用を促した。CISAも連邦機関に対して4日以内の修正を義務付ける指令を発出した。

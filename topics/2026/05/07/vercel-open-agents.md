# VercelがオープンソースのAIコーディングエージェント基盤「Open Agents」をリリース、ローカル環境不要でバックグラウンド実行
Tags: OSS, AI

- Vercel Releases Open Agents to Support Background AI Coding Workflows (2026-04-30)
  https://www.infoq.com/news/2026/04/vercel-open-agents/
- Vercel launches Open Agents to help companies build their own coding agents (2026-04-30)
  https://tessl.io/blog/vercel-open-sources-open-agents-to-help-companies-build-their-own-ai-coding-agents/

Vercelがオープンソースアプリケーション「Open Agents」をリリースし、ローカルマシン不要でバックグラウンドのコーディングエージェントを作成・実行できるプラットフォームを提供した。GitHub連携やPR自動生成、セッションをまたいだ永続的ワークフローなどを備え、主にフォーク・カスタマイズ用のリファレンス実装として位置づけられている。

# RustのCPython統合プロジェクトが進捗報告、ビルドシステム整備完了しPEP提案に向けた議論が本格化
Tags: Programming Languages, OSS

- Rust for CPython Progress Update April 2026 (2026-04-30)
  https://blog.python.org/2026/04/rust-for-cpython-2026-04/

CPythonへのRust統合プロジェクトの進捗が報告され、ビルドシステムの整備が完了しCPython CIのパスに成功した。PEP提案に向けた議論が進行中であり、RustとCPythonの両チームが2026 All Handsでの合同セッションを予定している。

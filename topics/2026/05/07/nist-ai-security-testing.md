# NISTがMicrosoft・Google・xAIから未公開AIモデルの事前提供を受けセキュリティリスク評価プログラムを開始
Tags: AI, Security

- Microsoft, Google, xAI Give US Government Early Access to AI Models for Security Testing (2026-05-05)
  https://www.cnn.com/2026/05/05/tech/microsoft-google-xai-government-test-ai-models

米国標準技術研究所（NIST）は、Google DeepMind・Microsoft・xAIがリリース前の未公開AIモデルをサイバーセキュリティリスク評価のために政府科学者へ提供すると発表した。OpenAIとAnthropicはすでに参加しており、生物・化学兵器への悪用リスクや重要インフラへのサイバー攻撃リスクの評価が行われる。

# RustプロジェクトのGoogle Summer of Code 2026、96件の応募から13プロジェクトが採択され前年比50%増の応募数を記録
Tags: Programming Languages, OSS

- Announcing Google Summer of Code 2026 selected projects | Rust Blog (2026-04-30)
  https://blog.rust-lang.org/2026/04/30/gsoc-2026-selected-projects/

RustプロジェクトはGoogle Summer of Code 2026において96件の応募から13プロジェクトが採択され、前年比50%増の応募数を記録した。コンパイラ・標準ライブラリ・ツールチェーン領域をカバーするプロジェクトが選ばれ、Rustコミュニティの成長と多様な開発者参加の拡大を示している。

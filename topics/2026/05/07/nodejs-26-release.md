# Node.js 26正式リリース、Temporal APIがデフォルト有効化されV8エンジンを14.6に更新
Tags: Programming Languages

- Node.js — Node.js 26.0.0 (Current) (2026-05-05)
  https://nodejs.org/en/blog/release/v26.0.0
- Node.js 26 Debuts with Temporal API Enabled by Default (2026-05-05)
  https://linuxiac.com/node-js-26-debuts-with-temporal-api-enabled-by-default/

Node.js 26が正式リリースされ、長年の問題を抱えていたDate APIの後継として開発されたTemporal APIがデフォルトで有効化された。V8エンジンが14.6に更新され、UndiciのバージョンアップやHTTP関連のレガシーコード削除など、プラットフォームのモダン化が大きく進んでいる。

# Vercel LabsがAIエージェント向けシステムプログラミング言語「Zero」をオープンソースで公開

Tags: Programming Languages, AI

  https://www.marktechpost.com/2026/05/17/vercel-labs-introduces-zero-a-systems-programming-language-designed-so-ai-agents-can-read-repair-and-ship-native-programs/
- Vercel Labs' Zero Compiler Speaks JSON to AI Agents (2026-05-18)
  https://www.techtimes.com/articles/316793/20260518/vercel-labs-zero-compiler-speaks-json-ai-agents-closing-human-translation-gap-agentic-coding.htm

Vercel LabsがAIエージェントによる自律的なコード読み取り・修正・デプロイを念頭に設計したシステムプログラミング言語「Zero」をApache 2.0ライセンスで公開した。コンパイラは`zero check --json`コマンドで安定したエラーコードと修正提案を含む構造化JSONを出力し、AIエージェントが中間翻訳なしにエラーを処理できる仕組みを実現している。

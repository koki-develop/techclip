# GitHub Enterprise Live Migrationsがパブリックプレビュー公開、ダウンタイムなしでCloudへの移行が可能に
Tags: OSS

- Enterprise Live Migrations is now in public preview (2026-05-07)
  https://github.blog/changelog/2026-05-07-enterprise-live-migrations-is-now-in-public-preview/

GitHubがEnterprise Live Migrations (ELM) をパブリックプレビューとして公開した。GitHub Enterprise ServerからGitHub Enterprise Cloudへの移行をダウンタイムほぼゼロで実施できるようになり、開発者は移行中も通常通り作業を継続できる。

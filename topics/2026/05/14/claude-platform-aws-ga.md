# AnthropicのClaudeプラットフォームがAWSで一般公開、既存AWSアカウントから直接利用可能に
Tags: AI, Cloud

- Claude Platform is Now Generally Available on AWS (2026-05-11)
  https://aws.amazon.com/about-aws/whats-new/2026/05/claude-platform-aws/
- Anthropic's Claude Platform comes to AWS (2026-05-11)
  https://thenewstack.io/anthropics-claude-platform-comes-to-aws/

AnthropicのClaudeプラットフォームがAWS上で一般公開され、既存のAWSアカウントから直接Claudeのネイティブプラットフォームへアクセスできるようになった。別途アカウント管理や請求管理が不要となり、企業向けのAI採用障壁が大幅に低下した。

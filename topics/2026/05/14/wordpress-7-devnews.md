# WordPress 7.0が5月20日リリース予定、開発者向けに新グリッドパッケージとGutenberg強化を発表
Tags: OSS, Programming Languages

- What's new for developers? (May 2026) (2026-05-12)
  https://developer.wordpress.org/news/2026/05/whats-new-for-developers-may-2026/

WordPressの開発者向けブログがGutenbergエディターへの新しい@wordpress/gridパッケージ追加などの更新情報を発表した。WordPress 7.0は2026年5月20日のリリースが予定されており、グリッドベースのインターフェース構築ツールの標準化など多数の改善が含まれる。

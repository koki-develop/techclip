# FortiClient EMSの重大な認証バイパス脆弱性（CVE-2026-35616）を悪用したEKZ情報窃取マルウェアの配布が確認
Tags: Security

- Hackers exploit FortiClient EMS flaw to push infostealer malware (2026-05-28)
  https://www.bleepingcomputer.com/news/security/hackers-exploit-forticlient-ems-flaw-to-push-infostealer-malware/
- New infostealer reaches enterprise devices through FortiClient EMS vulnerability (2026-05-29)
  https://www.helpnetsecurity.com/2026/05/29/forticlient-ems-vulnerability-infostealer/

脅威アクターがFortiClient EMSのCVSS 9.1の認証バイパス脆弱性（CVE-2026-35616）を悪用し、Fortinexの正規パッチに偽装した情報窃取マルウェア「EKZ」をPowerShell経由で配布している。EKZはChromeおよびFirefoxから認証情報を抽出してHTTP経由で外部送信する機能を持つ。

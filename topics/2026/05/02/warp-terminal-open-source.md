# RustベースのAIターミナル「Warp」がAGPL-3.0ライセンスでクライアントコードをオープンソース化

- Warp open sources its AI terminal client (2026-04-30)

70万人以上のアクティブ開発者を持つRustベースのAIターミナル「Warp」が、クライアントコードをAGPL-3.0ライセンスでGitHubに公開した。OpenAIをスポンサーに迎え、エージェントによるコーディング・テスト・PR作成ワークフローを前面に打ち出したオープンソース開発モデルへの転換として注目されている。

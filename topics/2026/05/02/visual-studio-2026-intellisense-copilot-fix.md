# Visual Studio 2026でIntelliSenseがCopilot補完より優先表示される仕様に変更、長年の問題が解消
Tags: OSS

- Visual Studio 2026 Gives IntelliSense Priority in Longstanding Copilot Completion Clash (2026-04-28)
  https://visualstudiomagazine.com/articles/2026/04/28/visual-studio-2026-gives-intellisense-priority-over-copilot.aspx

Visual Studio 2026のアップデートで、IntelliSenseとGitHub Copilotの補完候補が同時表示される長年の競合問題が解消され、IntelliSenseが優先される仕様に変更された。合わせてJSONエディタがJSONスキーマDraft 2019-09/2020-12の新仕様に対応するなど、開発体験の改善が図られた。

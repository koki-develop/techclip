# CISAがBlueHammerゼロデイをKEVカタログに追加、連邦機関に5月7日までのパッチ適用を命令
Tags: Security

- CISA orders feds to patch BlueHammer flaw exploited as zero-day (2026-04-25)
  https://www.bleepingcomputer.com/news/security/cisa-orders-feds-to-patch-microsoft-defender-flaw-exploited-in-zero-day-attacks/

CISAはMicrosoft Defenderの高深刻度ゼロデイ脆弱性「BlueHammer」（CVE-2026-33825）を既知悪用脆弱性（KEV）カタログに追加し、連邦機関に2026年5月7日までのパッチ適用を命じた。この脆弱性は不満を持つセキュリティ研究者がPoCコードを公開し、すでに実際の攻撃での悪用が確認されている。

# cPanel/WHMに認証バイパスの重大脆弱性（CVSS 9.8）、CISAが連邦機関に修正を命令
Tags: Security

- Critical cPanel Authentication Vulnerability Identified — Update Your Server Immediately (2026-04-29)
  https://thehackernews.com/2026/04/critical-cpanel-authentication.html

cPanel/WHMにCVSS 9.8の深刻な認証バイパス脆弱性（CVE-2026-41940）が発見され、CISAは既知悪用脆弱性（KEV）カタログに追加して2026年5月3日までのパッチ適用を連邦機関に命じた。攻撃者はこの脆弱性を悪用することでホストシステム全体の制御を取得できる可能性があり、即時のアップデートが強く推奨される。

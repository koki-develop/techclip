# OpenChoreo 1.0がリリース、Kubernetes向け内部開発者プラットフォームとしてCNCFサンドボックスに採択
Tags: OSS, Cloud

- OpenChoreo 1.0 Brings AI Agents and GitOps to Kubernetes Developer Platforms (2026-04-28)
  https://www.infoq.com/news/2026/04/openchoreo-10/

WSO2がKubernetes向けオープンソース内部開発者プラットフォーム「OpenChoreo 1.0」を正式リリースし、CNCFサンドボックスへの採択が完了した。BackstageベースのポータルやCI/CD、GitOps、オブザーバビリティを統合し、AIエージェント対応のワークフローも提供するプラットフォームとして、Kubernetes環境における開発者体験の標準化を目指している。

# Shopify、Tailwind CSS開発元のTailwind Labsを買収、オープンソースの立場は維持
Tags: OSS

- Shopify Acquires Tailwind Labs, Keeps Tailwind CSS Open Source (2026-09-09)
  https://betakit.com/tailwind-finds-stable-long-term-home-with-shopify-acquisition/

ShopifyがTailwind CSSの開発元であるTailwind Labsを買収した。AIの普及によりドキュメントサイトへのトラフィックや収益が落ち込む中での買収だが、Tailwind CSS自体は引き続きMITライセンスのオープンソースとして提供され、開発チームはShopifyの支援を受けて開発を継続する。

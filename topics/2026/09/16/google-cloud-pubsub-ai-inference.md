# Google Cloud、Pub/SubのAI Inference SMTでストリーミングデータへのモデル推論適用が可能に
Tags: Cloud, AI

- What's new with Google Data Cloud (2026-09-10)
  https://cloud.google.com/blog/products/data-analytics/whats-new-with-google-data-cloud

Google CloudがPub/SubにAI Inference Single Message Transform(SMT)を追加し、Gemini Enterprise Agent Platform上でホストされたモデルを用いて受信イベントストリームに対しリアルタイムで推論を適用し、予測結果を付加できるようになった。異常検知などの下流処理を簡素化する効果が期待される。

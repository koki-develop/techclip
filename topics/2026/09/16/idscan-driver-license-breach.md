# IDScanのクラウド侵害で運転免許証データ1億5300万件超が流出、ダークウェブで販売
Tags: Security

- IDScan confirms breach tied to 153 million stolen driver's licenses (2026-09-10)
  https://www.bleepingcomputer.com/news/security/idscan-confirms-breach-tied-to-153-million-stolen-drivers-licenses/
- IDScan confirms breach after 153 million driver's licenses leak on dark web (2026-09-11)
  https://www.helpnetsecurity.com/2026/09/11/idscan-net-data-breach-153-million-drivers-licenses/

身元確認サービス企業IDScanは、クラウドプラットフォームへの不正アクセスにより1億5300万件を超える運転免許証スキャンデータが流出したことを確認した。流出データはダークウェブ上の「Nexus」というプラットフォームで販売されていたことが判明し、FBIニューオーリンズ支局が捜査を開始した。同社は影響を受けた個人に信用監視サービスを無償提供するとしている。

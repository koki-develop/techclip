# Swift 6.4がリリース、Swift BuildがSwiftPMの標準ビルドシステムに
Tags: Programming Languages

- Swift 6.4 Released (2026-09-15)
  https://www.swift.org/blog/swift-6.4-released/

Swift 6.4が公開され、Swift PackageManagerのデフォルトビルドシステムがSwift Buildに切り替わり、Linux・macOS・Windowsで一貫したビルド体験が可能になった。また、WebAssemblyへのブリッジング処理が最大40倍高速化されるなど、クロスプラットフォーム開発の改善が図られている。

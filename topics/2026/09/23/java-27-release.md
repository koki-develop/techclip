# Java 27が正式リリース、G1 GCが全環境デフォルトに、耐量子暗号のTLS 1.3ハイブリッド鍵交換も追加
Tags: Programming Languages, OSS

- Java 27 Released (2026-09-16)
  https://www.infoq.com/news/2026/09/java27-released/
- 「Java 27」正式リリース。全環境でG1 GCがデフォルトに、TLS 1.3用に耐量子暗号のハイブリッドキー交換など新機能 (2026-09-16)
  https://www.publickey1.jp/blog/26/java_27g1_gctls_13.html

Oracleが非LTS版のJava 27を正式リリースした。ガベージコレクタのG1 GCが全環境でデフォルトとなったほか、TLS 1.3向けに耐量子暗号のハイブリッド鍵交換、コンパクトオブジェクトヘッダー、構造化並行性やベクターAPIの実験的強化など、セキュリティと将来の言語進化に重点を置いた新機能が多数追加された。

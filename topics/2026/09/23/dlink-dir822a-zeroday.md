# D-Link DIR-822Aルーターに最大深刻度のゼロデイ脆弱性、パッチ未提供でPoCも公開
Tags: Security

- D-Link warns of max severity zero-day bug in DIR-822A routers (2026-09-22)
  https://www.bleepingcomputer.com/news/security/d-link-warns-of-max-severity-zero-day-bug-in-dir-822a-routers/
- D-Link Flags Max Severity Zero-Day in Legacy Router (2026-09-22)
  https://www.bankinfosecurity.com/d-link-flags-max-severity-zero-day-in-legacy-router-a-32896

D-Linkは、サポート終了済みのレガシー製品DIR-822Aルーターに影響するCVSS最大値10.0のゼロデイ脆弱性CVE-2026-86296について警告した。DHCPサーバーコンポーネントのスタックベースバッファオーバーフローで、認証やユーザー操作なしにリモートから悪用可能。公開PoCが存在する一方でパッチは未提供で、D-Linkは影響を受けるハードウェアリビジョンの特定を進めており、リモート管理アクセスの制限などの緩和策を呼びかけている。

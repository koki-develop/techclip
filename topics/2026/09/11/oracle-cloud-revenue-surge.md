# Oracle、2027会計年度Q1決算でクラウドインフラ収益が121%急増、AI需要で受注残は664億ドルに
Tags: Cloud

- Oracle Q1 FY2027 earnings report 2026 (2026-09-10)
  https://www.cnbc.com/2026/09/10/oracle-orcl-q1-earnings-report-2027.html

Oracleが発表した2027会計年度第1四半期決算で、クラウドインフラ収益が前年同期比121%増の74億ドルに達し、残存履行義務(RPO)は前年比209億ドル増の664億ドルとなったことが判明した。AI関連の大型契約がクラウド事業を牽引しており、企業のAIインフラ需要の拡大が同社の急成長を支えている。

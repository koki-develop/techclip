# Azure ReposのCopilotコードレビューがパブリックプレビューに
Tags: Cloud

- Copilot code reviews for Azure Repos, public preview (2026-08-26)
  https://devblogs.microsoft.com/devops/copilot-code-reviews-for-azure-repos-public-preview/

GitHub CopilotによるコードレビューがAzure Reposで早期アクセス登録なしに全顧客向けのパブリックプレビューとして提供開始された。組織・プロジェクト・リポジトリ単位でのレビュー有効化、カスタム指示、プルリクエスト作成時の自動レビューなどの機能が追加されている。

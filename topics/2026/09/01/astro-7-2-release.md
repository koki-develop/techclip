# Astro、プロジェクトスチュワード交代とAstro 7.2をリリース
Tags: OSS, Programming Languages

- What's new in Astro - August 2026 (2026-08-31)
  https://astro.build/blog/whats-new-august-2026/

Astroプロジェクトは、Project StewardがFred SchottからMatthew Phillipsに交代したことを発表するとともに、Astro 7.2をリリースした。ブラウザ上でAstroコンポーネントを試せる新ツール「Astro Playground」の公開や、実験的なインクリメンタル静的ビルドの追加などが含まれる。

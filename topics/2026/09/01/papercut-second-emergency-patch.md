# PaperCut、初回パッチ回避策の発見を受け緊急パッチ第2弾をリリース
Tags: Security

- PaperCut releases second emergency patch for exploited flaws (2026-08-28)
  https://www.bleepingcomputer.com/news/security/papercut-releases-second-emergency-patch-for-exploited-flaws/
- PaperCut NG/MF Security Bulletin — urgent security advisory (2026-08-27)
  https://www.papercut.com/kb/Main/security-bulletin-27-aug-2026-urgent-security-advisory/

PaperCutは、印刷管理ソフトウェアNG/MFにおいて実際に悪用されている脆弱性(CVE-2026-81578、CVE-2026-82078)に対する初回パッチの回避策が発見されたため、緊急パッチ第2弾をリリースした。これらの脆弱性は認証をバイパスして任意のJavaコードを実行できるもので、同社は顧客に対し即時のパッチ適用を改めて呼びかけている。

# GitHub Copilot、複数のAIモデルを自動使い分けする「Project HydraFusion」を発表
Tags: AI, OSS

- GitHub Copilotが複数のAIモデルを自動切り替えする「HydraFusion」を発表 (2026-09-07)
  https://gigazine.net/gsc_news/en/20260907-github-copilot-hydrafusion/
- Project HydraFusion: Frontier quality via multi-model orchestration (2026-09-07)
  https://github.blog/ai-and-ml/github-copilot/project-hydrafusion-frontier-quality-via-multi-model-orchestration/

GitHubはコーディングタスクの内容に応じて複数のAIモデルを自動的に切り替えて実行する研究プレビュー機能「Project HydraFusion」をGitHub Copilot CLIに追加した。タスクごとに最適なモデルをオーケストレーションすることで、Claude Opus 5単体と比較してコストを67%削減しつつ、タスク成功率を4.9ポイント改善したという。

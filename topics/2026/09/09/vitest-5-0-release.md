# テストフレームワークVitest 5.0がリリース、実行速度を最大53%改善
Tags: Programming Languages

- Vitest 5.0 is out! (2026-09-03)
  https://vitest.dev/blog/vitest-5.html

JavaScript/TypeScript向けテストフレームワークVitestのメジャーバージョン5.0がリリースされた。vmプールやブラウザモードでの実行速度が最大53%向上したほか、ブラウザモード向けの新しいトレースビュー、条件付きモックを簡潔に記述できる`vi.when` API、ベンチマーク機能の刷新などが追加された。

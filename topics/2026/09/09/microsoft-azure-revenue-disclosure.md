# Microsoft、投資家の要望を受けAzureの売上高を四半期開示へ
Tags: Cloud

- Microsoft to disclose Azure revenue as part of segment changes (2026-09-02)
  https://www.cnbc.com/2026/09/02/microsoft-to-disclose-azure-revenue-as-part-of-segment-changes.html

Microsoftは投資家からの要望を受け、四半期ごとにAzureの売上高を開示すると発表した。2026年6月期(第4四半期)のAzure売上高は294億ドル、2026会計年度通期では1019億ドルを計上。あわせて報告セグメントも従来の3区分から「Agents and Infra」「Devices and Consumer」の2区分に再編される。

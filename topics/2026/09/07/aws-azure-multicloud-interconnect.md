# AWSとMicrosoft Azureがマルチクラウド接続で提携、主要3クラウド全てと直結可能に

AWSとMicrosoft Azureが、両クラウド間のプライベート接続を簡素化する協業を発表した。AWS側はパブリックプレビュー中の「AWS Interconnect」を通じて、Azure側は新サービス「Azure Multicloud Interconnect」を通じて、標準化されたAPIによりMACsec暗号化と冗長構成を備えた高可用な直接接続を数クリック・数分で構築できるようにする。これによりAWSはGoogle Cloud、OCIに続いて主要3大クラウド全てとの直結を実現し、複数クラウドにまたがるワークロード運用の複雑さを大幅に軽減する狙いがある。

# オーストラリアの学習プラットフォームMathspaceがSQLインジェクション攻撃を受け、100万人超の個人情報が流出

豪州の数学学習プラットフォームMathspaceが、社内分析ツールMetabaseのパスワードリセット機能に存在した未認証SQLインジェクション脆弱性(CVE-2026-72898)を突かれ、生徒・保護者・教師ら100万人超の氏名やメールアドレスなどが流出したと公表した。侵入は8月10日から27日にかけて発生しており、パスワードや学習記録などの機微情報は含まれていないとしている。既知の脆弱性への対応漏れが侵害の原因だった。

# JavaScriptをC言語にコンパイルするAOTツール「Porffor」がアルファ版に到達
Tags: OSS, Programming Languages

- JavaScriptをC言語にコンパイルするツール「Porffor」がアルファ版に (2026-09-07)
  https://www.publickey1.jp/blog/26/javascriptcporfforwasm.html

JavaScriptをC言語(経由でネイティブ/WASM)にコンパイルするAOTコンパイラ「Porffor」がアルファ版に到達した。コア部分の全面書き直しにより出力サイズの削減やガベージコレクション対応などが実現し、Node.js非依存の軽量なJavaScript実行環境構築に向けた開発が進んでいる。

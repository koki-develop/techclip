# AWS、次期クラウドネイティブOS「Amazon Linux 2027」のパブリックプレビューを開始
Tags: Cloud

- Amazon Linux 2027 is now available in public preview (2026-09-03)
  https://aws.amazon.com/about-aws/whats-new/2026/09/announcing-amazon-linux-2027/
- Amazon Linux 2027 Now in Preview: Powered By Linux 7.1, x86-64-v3 & Built With LTO (2026-09-03)
  https://www.phoronix.com/news/Amazon-Linux-2027-Preview
- Amazon Linux 2027 Enters Public Preview with Linux Kernel 7.1 and DNF5 (2026-09-04)
  https://linuxiac.com/amazon-linux-2027-enters-public-preview-with-linux-kernel-7-1-and-dnf5/

AWSがクラウドネイティブ向け次期OS「Amazon Linux 2027」のパブリックプレビューを開始した。Linuxカーネル7.1以降の採用、DNF5パッケージマネージャ、SELinux強制モードのデフォルト化、x86-64-v3最適化やLTOビルド、GCC 16.1/LLVM 22などの更新ツールチェーンを搭載し、性能とセキュリティ両面を刷新している。

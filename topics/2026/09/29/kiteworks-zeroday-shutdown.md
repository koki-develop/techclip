# セキュアファイル共有大手Kiteworks、ゼロデイ攻撃の恐れで顧客に6時間のシステム停止を要請
Tags: Security

- Kiteworks urges 6-hour server shutdown over potential zero-day attacks (2026-09-25)
  https://www.bleepingcomputer.com/news/security/kiteworks-urges-6-hour-server-shutdown-over-potential-zero-day-attacks/

セキュアファイル共有大手Kiteworksは、法執行機関から「今週末に攻撃が差し迫っている」との脅威情報を受けたとして、顧客に対し9月26日(土)のUTC午前2時から8時までの6時間、システムを一時停止するよう要請した。未知のゼロデイ脆弱性が関与している可能性があるとされ、具体的な脆弱性の詳細はまだ公表されていない。

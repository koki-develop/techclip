# AWS、Bedrock AgentCoreの新ランタイムを一般提供開始、コールドスタートを最大93%短縮
Tags: Cloud

- The new AgentCore Runtime is now available in Amazon Bedrock AgentCore (2026-09-18)
  https://aws.amazon.com/about-aws/whats-new/2026/09/new-agentcore-runtime-generally-available/

AWSはAmazon Bedrock AgentCoreの次世代ランタイム(V2)を一般提供開始した。オンデマンドで確保・解放される弾力的メモリ管理により未使用分の課金を回避できるほか、コールドスタート時間をコンテナイメージサイズや同時実行数によらずP75で1.9〜2.0秒まで短縮した(従来は5.4〜30秒)。us-east-1、us-east-2、us-west-2、eu-west-1、ap-northeast-1の5リージョンで利用可能で、AIエージェントの応答性向上とコスト効率の両立を狙う。

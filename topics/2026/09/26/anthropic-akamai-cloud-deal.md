# Anthropic、Akamaiと7年116億ドルのクラウドインフラ契約を締結

AnthropicがAkamaiのクラウドインフラに7年間で116億ドル(最大約200億ドルまで拡大の可能性)を投じる契約を締結した。GPUではなくCPU中心のインフラに焦点を当てた異例の取引で、AkamaiへのAnthropic向け新株予約権付与も含まれる。Anthropicのコンピュート契約総額はこの11か月で5000億ドルを超えており、Dario Amodei CEOは財務リスクについても言及している。発表を受けAkamai株は時間外取引で最大17%上昇した。

# Node.js 26.10.0がリリース、新APIやパフォーマンス計測機能を追加
Tags: Programming Languages, OSS

- Node.js v26.10.0 (Current) (2026-09-22)
  https://nodejs.org/en/blog/release/v26.10.0

Node.js 26.10.0がCurrentリリースとして公開され、crypto.parsePKCS12()やfs.openAsBlobSync()、util.throttle()/util.debounce()といった新APIが追加された。またSlidingWindowHistogramの導入によりパフォーマンス計測機能も強化されている。

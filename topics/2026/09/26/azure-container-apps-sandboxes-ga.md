# Azure Container Apps ExpressとContainer Apps Sandboxesが一般提供開始
Tags: Cloud

- Azure Container Apps Sandboxes, Now Generally Available (2026-09-23)
  https://techcommunity.microsoft.com/blog/appsonazureblog/azure-container-apps-sandboxes-now-generally-available/4559125

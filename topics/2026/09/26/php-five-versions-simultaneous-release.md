# PHP、8.6.0 RC1を含む5バージョンを同時リリース
Tags: Programming Languages, OSS

- PHP Releases Five Versions At Once (2026-09-22)
  https://www.linuxcompatible.org/story/php-releases-five-versions-at-once-includes-860-rc1-and-8511/

PHP開発チームは、次期メジャーバージョンPHP 8.6の最初のリリース候補(パッケージング不備により実質RC2として再公開)に加え、8.5.11・8.4.26のバグ修正・セキュリティ更新、さらに8.3.35・8.2.34のセキュリティ専用更新の合計5バージョンを一斉に公開した。複数のサポートラインを同時にメンテナンスするPHPの体制が改めて示された。

# マルチクラスタKubernetesプロジェクト「Karmada」がCNCFの最高成熟度「Graduated」に到達
Tags: Cloud

- Kubernetes Multi-Cluster Project Karmada Reaches CNCF Graduation (2026-09-17)
  https://www.infoq.com/news/2026/09/karmada-kubernetes-cncf/

マルチクラスタ・マルチクラウド対応のKubernetesオーケストレーションプロジェクトKarmadaが、CNCF(Cloud Native Computing Foundation)における最高成熟度レベルの「Graduated」ステータスに到達したことが発表された。Bloomberg、Alibaba Cloud、Huaweiなど多くの企業で本番採用が進んでおり、複数クラスタにまたがるワークロード管理やフェイルオーバーの標準的な選択肢としての地位を確立しつつある。

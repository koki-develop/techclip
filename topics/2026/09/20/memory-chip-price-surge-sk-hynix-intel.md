# AI需要でメモリ価格が最大7倍に高騰、SK HynixとIntelが米国内生産で提携交渉
Tags: Other

- SK Hynix reportedly in talks with Intel to build memory chips in US (2026-09-16)
  https://techcrunch.com/2026/09/16/sk-hynix-reportedly-in-talks-with-intel-to-build-memory-chips-in-us/
- Micron Jumps 5% as Intel CEO Says Memory Prices Have Surged Over 500% (2026-09-17)
  https://finance.yahoo.com/markets/stocks/articles/micron-jumps-5-intel-ceo-153804720.html

AIデータセンター需要の急拡大を背景に半導体メモリの価格が高騰し、IntelのCEO Lip-Bu Tan氏はAI Infra Summitで価格が5〜7倍に急騰し2027年にかけて不足がさらに悪化しかねないと警告、この発言を受けMicron株が5%上昇した。同時期、SK Hynixが米国内で初めてメモリチップを生産すべく、オハイオ州のIntel工場をリースするか合弁事業を組む形での提携を協議していると報じられ、両社の株価が急伸した。

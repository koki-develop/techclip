# 単一の悪意ある拡張機能で複数ブラウザのAIエージェントを乗っ取る攻撃手法「BragJack」が実証
Tags: Security

- BragJack attacks hijack AI browser agents through malicious extensions (2026-09-19)
  https://www.bleepingcomputer.com/news/security/bragjack-attacks-hijack-ai-browser-agents-through-malicious-extensions/

セキュリティ研究者Gal Weizman氏が、単一の悪意ある拡張機能でChrome、Edge、Opera Neonなど複数ブラウザに搭載されたAIアシスタント5種をまとめて乗っ取れる新たな攻撃手法「BragJack」を実証した。この手法によりローカルファイルの読み取りや閲覧履歴の取得などが可能になるといい、研究の結果2万ドル超のバグ報奨金と2件のCVE採番につながった。

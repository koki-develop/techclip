# Microsoft Azure AI Foundryに最大深刻度CVSS10.0の権限昇格脆弱性、パッチ提供済み
Tags: Security, Cloud, AI

- Microsoft Patches CVSS 10.0 Azure AI Foundry Flaw Enabling Unauthorized Privilege Escalation (2026-09-18)
  https://thehackernews.com/2026/09/microsoft-patches-cvss-100-azure-ai.html
- Critical Microsoft Azure AI Foundry Vulnerability Allows Attackers to Escalate Privileges (2026-09-18)
  https://cybersecuritynews.com/microsoft-azure-ai-foundry-vulnerability/

MicrosoftのAI開発プラットフォーム「Azure AI Foundry」に、認証チェックの欠如(CWE-306)に起因する最大深刻度CVSS10.0の脆弱性(CVE-2026-85889)が発見された。未認証の攻撃者がネットワーク経由で権限昇格を行える恐れがあったが、Microsoftはサーバー側で既に修正を完了しており、顧客側での対応は不要とされている。

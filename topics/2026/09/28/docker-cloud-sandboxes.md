# Docker、AIエージェント向けクラウドサンドボックス「Docker Cloud Sandboxes」を発表

Tags: OSS, Cloud

  https://www.docker.com/press-release/cloud-sandboxes-extending-secure-ai-agent-isolation-beyond-the-laptop/

  https://www.infoq.com/news/2026/09/docker-cloud-sandboxes/

  https://www.publickey1.jp/blog/26/docker_cloud_snadboxesai.html

Dockerがクラウド上でAIエージェント向けのサンドボックス実行環境を提供する「Docker Cloud Sandboxes」を発表した。ローカル版Docker Sandboxesと同じCLI・信頼モデル・Kitsを用い、開発者のノートPCがシャットダウンした後もクラウド上でエージェントのワークフローを継続実行できる。1〜16 vCPUまで弾力的にスケールするほか、Kits仕様をCNCFに提出する計画も明らかにした。一方で、サンドボックス単体ではエージェントの外部サービスへのアクセス制御までは保証できないとの指摘もある。

# WordPressプラグインElementorの脆弱性で攻撃者が管理者アカウントを作成可能に

Tags: Security, OSS

- Elementor WordPress flaw lets attackers create admin accounts (2026-09-25)
  https://www.bleepingcomputer.com/news/security/elementor-wordpress-flaw-lets-attackers-create-admin-accounts/

約200万サイトで利用されているWordPressプラグインElementor(v4.3.0/4.3.1)にCSRF脆弱性が発見された。悪意あるリンクを管理者に開かせるだけで攻撃者が管理者アカウントを作成できる恐れがあり、開発元は修正版v4.3.2をリリースした。

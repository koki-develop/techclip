# AWS Lambda SnapStartがコンテナイメージ関数に対応、コールドスタート高速化のパッケージ制約を解消
Tags: Cloud

- Lambda SnapStart Comes to Container Images, Ending a Packaging Tradeoff (2026-09-12)
  https://www.infoq.com/news/2026/09/lambda-snapstart-container-image/

AWS Lambdaのコールドスタートを高速化する「SnapStart」機能が、コンテナイメージでパッケージされた関数にも対応した。これまでzip形式のパッケージでしか利用できず、大きな依存関係を持つ関数はサイズ制限とのトレードオフを迫られていたが、今回の対応によりコンテナイメージのままSnapStartの高速化恩恵を受けられるようになった。

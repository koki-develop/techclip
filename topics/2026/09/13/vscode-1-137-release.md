# VS Code 1.137がリリース、定期実行エージェントの自動化とVoice Modeを追加
Tags: OSS, Programming Languages

- Visual Studio Code 1.137 (2026-09-09)
  https://code.visualstudio.com/updates/v1_137

VS Code 1.137では、定期的にタスクを実行できるエージェントの自動化機能(プレビュー)、音声でエージェントと対話できるVoice Mode(実験的機能)、GitHubのIssueやPRをAgentsウィンドウ内で直接確認できる統合機能などが追加された。

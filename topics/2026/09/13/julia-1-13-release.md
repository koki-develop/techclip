# Julia 1.13がリリース、起動時間とプリコンパイル時間を大幅短縮
Tags: Programming Languages

- Julia 1.13 Highlights (2026-09-10)
  https://julialang.org/blog/2026/09/julia-1.13-highlights/index.html

Julia 1.13がリリースされ、起動時間がJulia 1.12比で約20%高速化、パッケージのプリコンパイル時間も約30%短縮された。このほかREPLへの構文ハイライト標準搭載やfzf風の履歴検索、ハッシュ関数のRapidhashNanoへの刷新なども行われた。

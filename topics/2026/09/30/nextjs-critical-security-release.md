# Next.jsが9件の脆弱性を修正する緊急セキュリティリリースv16.3.8/v15.5.27を公開
Tags: Programming Languages, Security

- Upcoming Next.js September Security Release (v16.3.8 / v15.5.27) (2026-09-30)
  https://nextjs.org/blog/upcoming-nextjs-security-release-september-2026

Next.jsがCritical 1件・High 2件・Medium 5件・Low 1件、計9件の脆弱性を修正するセキュリティリリースv16.3.8およびv15.5.27を公開した。同フレームワークは9月にもImageResponse機能の重大RCE脆弱性で緊急パッチを公開したばかりで、広く利用されるReactフレームワークのセキュリティ対応が続いている。

# Cloudflareが新CLIツール「cf」を公開、Wranglerを置き換え全APIをカバー
Tags: OSS, Cloud

- Cloudflare launches "cf", a new command-line tool covering the full Cloudflare API (2026-09-28)
  https://blog.cloudflare.com/cloudflare-cf-cli-launch/

Cloudflareが既存のWranglerを置き換える新CLIツール「cf」をオープンベータとして公開した。Wranglerの約280に対しCloudflareの全API約3,000操作をカバーし、TypeScript製の設定ファイル(cloudflare.config.ts)やVite統合など、AIエージェント時代を意識した設計になっている。CLI生成基盤「Forge」もOSSとして同日公開された。

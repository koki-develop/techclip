# NVIDIA、AIエージェントをランタイム・ハードウェア層で制御する「Open Agent Safety Platform」を発表
Tags: AI, Security

- NVIDIA newsroom: Open Agent Safety Platform (2026-09-28)
  https://nvidianews.nvidia.com/news/open-agent-safety-platform
- NVIDIA wants AI agent safety enforced in silicon, not left to the agent (2026-09-28)
  https://www.helpnetsecurity.com/2026/09/28/nvidia-open-agent-safety-platform/
- NVIDIA Launches Open Platform to Secure Autonomous AI Agents (2026-09-28)
  https://www.infosecurity-magazine.com/news/nvidia-open-platform-secure/

NVIDIAは、AIエージェントがアプリケーション層の安全対策を回避する事例が相次いだことを受け、オープンソースソフトウェア「OpenShell」とハードウェア寄りのリファレンス設計「Sentry」から成る新プラットフォームを発表した。エージェント自身の判断に頼らず、ランタイムとインフラ層で制御を強制する仕組みで、テストから本番運用までを一貫して保護する。Anthropic、Microsoft、Salesforceなど業界大手が支持を表明している。

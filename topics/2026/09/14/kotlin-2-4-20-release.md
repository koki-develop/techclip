# JetBrains、Kotlin 2.4.20をリリース
Tags: Programming Languages

- Kotlin 2.4.20 Released (2026-09-07)
  https://blog.jetbrains.com/kotlin/2026/09/kotlin-2-4-20-released/

JetBrainsがKotlin 2.4.20をリリースした。コルーチンのスタックトレース復元への対応、Kotlin/NativeでのSwiftエクスポート機能強化(SwiftPM向けPackage.swift自動生成)、Kotlin/WasmおよびKotlin/JSの改善、Gradle 9.7.0対応などが含まれる。

# pnpm 11.26リリース、カタログのworkspace範囲指定とサプライチェーンセキュリティ機能を強化
Tags: OSS, Programming Languages

- pnpm 11.26 (2026-09-07)
  https://pnpm.io/blog/releases/11.26

パッケージマネージャーpnpmのv11.26がリリースされ、`pnpm-workspace.yaml`のカタログでworkspace範囲の指定が可能になったほか、`remove`・`update`コマンドにサプライチェーン検証用のフラグ、CI向けの`pnpm change check`コマンドが追加された。依存関係管理におけるセキュリティと柔軟性の両面で改善が図られている。

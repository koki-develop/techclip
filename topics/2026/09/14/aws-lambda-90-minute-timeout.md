# AWS Lambda、Managed Instances上のタイムアウト上限を15分から90分に拡大
Tags: Cloud

- AWS Lambda now supports 90-minute function timeout on Lambda Managed Instances (2026-09-09)
  https://aws.amazon.com/about-aws/whats-new/2026/09/aws-lambda-90-minute-function/

AWSは、Lambda Managed Instances上で非同期呼び出しやイベントソースマッピングによる関数実行のタイムアウト上限を、従来の15分から90分へと6倍に拡大したと発表した。これにより大規模データ処理や動画変換など、これまでLambdaでは対応が難しかった長時間実行のワークロードもサーバーレスで扱えるようになる。

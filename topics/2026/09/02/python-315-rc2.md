# Python 3.15の最終リリース候補版rc2が公開、10月正式リリースへ
Tags: Programming Languages, OSS

- Python 3.15.0 candidate 2 is here! (2026-09-01)
  https://www.python.org/downloads/release/python-3150rc2/
- Python 3.15.0 candidate 2 is here! (2026-09-01)
  https://blog.python.org/2026/09/python-3150-rc2-is-here.html

Python 3.15.0の2つ目(最終)のリリース候補版rc2が公開された。前回のrc1から約144件のバグ修正やビルド改善が加えられ、以降はABI変更なしで10月1日の正式リリースに向けた最終調整に入る。遅延インポート構文(PEP 810)や組み込みfrozendict型、UTF-8デフォルトエンコーディングなどの新機能が確定しており、サードパーティ開発者にはPyPI向けホイールの準備が呼びかけられている。

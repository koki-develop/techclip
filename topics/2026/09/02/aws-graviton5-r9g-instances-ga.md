# AWS、Graviton5搭載の新型EC2インスタンス「R9g」「R9gd」を一般提供開始
Tags: Cloud

- Amazon EC2 R9g and R9gd instances powered by AWS Graviton5 processors are now generally available (2026-08-31)
  https://aws.amazon.com/blogs/aws/amazon-ec2-r9g-and-r9gd-instances-powered-by-aws-graviton5-processors-are-now-generally-available/

AWSが自社開発チップ「Graviton5」を搭載した新型EC2インスタンス「R9g」「R9gd」の一般提供を開始した。前世代のGraviton4搭載「R8g」と比較して最大25%の性能向上を実現し、DDR5-8800メモリを採用するなどメモリ最適化ワークロード向けの強化が図られている。

# CPython、RISC-VアーキテクチャをTier 3プラットフォームとして正式サポート
Tags: OSS, Programming Languages

- CPython Officially Adds RISC-V Support As a Tier 3 Platform (2026-09-10)
  https://www.infoq.com/news/2026/09/riscv-cpython/

CPython(Python本体)がRISC-Vアーキテクチャを正式にTier 3プラットフォームとしてサポートしたことが明らかになった。RISEプロジェクトの協力のもと実機での動作検証が進められており、今後はCIへのRISC-Vハードウェア統合とTier 2への昇格を目指すとしている。

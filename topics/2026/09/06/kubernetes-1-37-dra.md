# Kubernetes v1.37がリリース、Dynamic Resource Allocationの拡張機能が正式版に
Tags: Cloud

- Kubernetes v1.37: DRA Updates (2026-09-03)
  https://kubernetes.io/blog/2026/09/03/kubernetes-v1-37-dra-updates/

Kubernetes v1.37がリリースされ、GPUなどのデバイスをきめ細かく割り当てる仕組み「Dynamic Resource Allocation（DRA）」の拡張リソース対応やデバイスへのTaint/Toleration機能が正式版（GA）に到達した。また、ワークロードをゼロレプリカまでスケールダウンするオートスケーリング機能もベータとして既定で有効化され、AI/ML向けワークロードを中心にリソース管理の柔軟性がさらに高まった。

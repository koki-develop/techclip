# VS Code 1.136がリリース、プルリクエストを自動でまとめ上げる「Agent Merge」を追加
Tags: OSS

- Visual Studio Code 1.136 (2026-09-02)
  https://code.visualstudio.com/updates/v1_136

VS Code 1.136では、レビュー指摘の反映やマージコンフリクトの解消を自動で行いプルリクエストを完成させる新機能「Agent Merge」（プレビュー）が追加された。このほか、マルチルートワークスペースでの複数エージェントセッション対応やチャット背景のカスタマイズ機能なども盛り込まれ、エディタ上でのAIエージェント活用がさらに広がっている。

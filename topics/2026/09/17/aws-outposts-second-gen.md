# AWS、第2世代シングルラックOutpostsを発表、狭小拠点でもオンプレミス利用が可能に
Tags: Cloud

- Announcing second-generation single-rack AWS Outposts (2026-09-10)
  https://aws.amazon.com/about-aws/whats-new/2026/09/single-rack-aws-outposts/

AWSは、最大2,688 vCPUと100TBのEBSストレージを1台の42Uラックに収めた第2世代シングルラックOutpostsの一般提供を開始した。製造拠点やゲーミング施設など設置スペースが限られる場所でも、オンプレミス環境でAWSのコンピュート・ストレージ・ネットワーキングサービスを利用できるようになる。

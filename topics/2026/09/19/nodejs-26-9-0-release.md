# Node.js 26.9.0がリリース、FFIをデフォルト有効化
Tags: Programming Languages, OSS

- Node.js v26.9.0 (Current) (2026-09-16)
  https://nodejs.org/en/blog/release/v26.9.0

Node.js 26.9.0が公開された。外部関数インターフェース(FFI)がデフォルトで有効化されたほか、新しいベンチマークモジュール「node:bench」、暗号処理向けのGeneric MAC API、実験的なDTLS APIなどが追加され、ネイティブコード連携やベンチマーク環境の整備が進んだ。

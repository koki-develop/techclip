# VS Code 1.138がリリース、Dev Containers内でのエージェントセッション実行に対応
Tags: OSS, Programming Languages

- Visual Studio Code 1.138 (2026-09-16)
  https://code.visualstudio.com/updates/v1_138

MicrosoftがVS Code 1.138をリリースした。開発用コンテナ(Dev Containers)内でAIエージェントセッションを実行できるようになったほか、Codexセッションをアプリケーションをまたいで継続できる機能や、完了済みセッションを自動整理する機能などが追加され、エージェント活用を前提としたワークフローの強化が図られている。

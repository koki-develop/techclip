# Claude Codeが共通仕様「AGENTS.md」に対応
Tags: OSS

- Claude Codeが「AGENTS.md」に対応。CLAUDE.mdが存在しない場合、自動的に読み込み (2026-09-24)
  https://www.publickey1.jp/blog/26/claude_codeagentsmdclaudemd.html

Claude Codeが、OpenAI CodexやGitHub Copilotなど複数のAIコーディングエージェントツールが共通で採用する仕様「AGENTS.md」の読み込みに対応した。プロジェクトにCLAUDE.mdが存在しない場合はAGENTS.mdを自動的に参照するようになり、開発者は複数のAIエージェントツールを併用する際に設定ファイルを重複管理する必要がなくなる。AIコーディングツール間での設定共有・相互運用性が一段と進む動きといえる。

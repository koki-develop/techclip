# Go言語製の高速IDE「Rune」がオープンソースで公開
Tags: OSS, Programming Languages

- Go製IDE「Rune」がオープンソース化 TypeScript、Go、Python、Rustなど主要言語に対応 (2026-09-25)
  https://www.publickey1.jp/blog/26/goiderune.html

UnstablebuildがGo言語で実装した高性能IDE「Rune」をオープンソースとして公開した。GPUアクセラレーションによる描画やターミナル中心のワークフロー、SSH経由で複数マシンをローカルのように扱えるリモート開発機能を備え、TypeScript、Go、Python、Rustなど主要言語に対応する。無料枠では最大2ノードまでのリモート接続が可能。

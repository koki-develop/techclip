# Reactが19.3をリリース、ViewTransitionやFragmentのref対応などを追加
Tags: Programming Languages

- React 19.3 released (2026-09-09)
  https://react.dev/blog/2026/09/09/react-19-3

Reactチームがバージョン19.3をnpmで公開した。ViewTransitionおよびFragmentへのref対応、browser()関数によるブラウザ専用コードのレンダリング、Trusted Types対応、独立したトランジションの実行などが新たに追加された。あわせてFast RefreshやServer Componentsまわりで報告されていた多数の不具合も修正されている。

# Kubernetesがv1.37をリリース、AI/バッチワークロード向けのギャングスケジューリングをベータ昇格
Tags: Cloud

  https://kubernetes.io/blog/2026/09/08/kubernetes-v1-37-advancing-workload-aware-scheduling/

- Kubernetes v1.37 brings 67 enhancements. Which matter for operators? (2026-09-11)

Kubernetes v1.37がリリースされ、AI/MLやバッチ処理向けのワークロード対応スケジューリング機能が強化された。複数のPodをまとめて一括起動する「ギャングスケジューリング」を支えるWorkloadおよびPodGroup APIがベータに昇格し、階層的なグループ管理を行う新設のCompositePodGroup API(アルファ)も追加された。今回のリリースは67件の機能強化を含み、うち16件が安定版に達している。

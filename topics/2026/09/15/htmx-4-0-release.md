# HTMX 4.0が正式リリース、内部実装をfetchに移行しStreaming HTMLに対応
Tags: Programming Languages

- HTMX 4.0正式リリース。内部実装がXHRからfetchに移行しStreaming HTMLが可能に (2026-09-08)
  https://www.publickey1.jp/blog/26/htmx_40xhrfetchstreaming_html.html

フロントエンドライブラリHTMXのバージョン4.0が正式リリースされた。内部実装がXMLHttpRequestからfetch APIへ移行し、これによりStreaming HTMLへの対応が可能になった。属性の継承をデフォルトで無効化するなど、いくつかの破壊的変更も含まれている。

# JDK 27が正式リリース、G1GCの全環境デフォルト化やポスト量子TLS対応など9つのJEPを搭載
Tags: Programming Languages

- JDK 27 (2026-09-15)
  https://openjdk.org/projects/jdk/27/
- JDK 27 Runtime Updates Release Notes (2026-09-12)
  https://inside.java/2026/09/12/jdk-27-runtime-updates/

Java 27(非LTS)の正式版が9月15日にリリースされた。G1ガベージコレクタが全環境でデフォルトとなったほか、TLS 1.3向けのポスト量子ハイブリッド鍵交換、構造化並行性、コンパクトオブジェクトヘッダーによるヒープ削減など9件のJEPが導入された。8月に公開されたリリース候補版から機能セットが確定した形で、JFRによる機密情報の自動秘匿化やjcmdの機能拡張なども盛り込まれている。

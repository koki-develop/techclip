# AWS Lambda、Managed Instances向けに実行時間上限を15分から90分に拡張
Tags: Cloud

- AWS Lambda Pushes Serverless toward Long-Running Workloads (2026-09-19)
  https://www.infoq.com/news/2026/09/lambda-90-minute-timeout/

AWSは、AWS LambdaのManaged Instancesにおける関数実行時間の上限を従来の15分から90分へと大幅に拡張した。これにより、メディア処理や大規模なAI推論バッチ処理など、これまでサーバーレスでは扱いにくかった長時間ジョブにもLambdaを適用できるようになる。今回の拡張はサーバーレスの適用範囲を長時間実行ワークロードへ広げる動きの一環と位置づけられている。

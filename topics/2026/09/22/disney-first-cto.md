# ディズニー、Character.AI前CEOのKarandeep Anand氏を初代CTOに起用
Tags: Other

- Disney names CTO for the first time as media giant expands tech push (2026-09-18)
  https://www.cnbc.com/2026/09/18/disney-cto-tech.html

ウォルト・ディズニー・カンパニーが、同社史上初めてとなる最高技術責任者(CTO)にKarandeep Anand氏を指名した。Anand氏はAIチャットボット企業Character.AIのCEOを務めた人物で、Meta出身でもある。ディズニーはエンタープライズ技術・インフラ・AI基盤の統括をAnand氏に委ね、エンターテインメント大手としての技術・AI戦略を本格的に強化する狙いとみられる。

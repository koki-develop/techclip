# Kubernetes 1.37が正式リリース、Metrics APIが安定版に到達しRootless Kubeletがベータへ
Tags: Cloud, OSS

- Kubernetes 1.37 Released: Stable Metrics API and Rootless Kubelet in Beta (2026-09-21)
  https://www.infoq.com/news/2026/09/kubernetes-1-37/
- Kubernetes v1.37: Tracking When a PersistentVolumeClaim Was Last Used (Beta) (2026-09-21)
  https://kubernetes.io/blog/2026/09/21/kubernetes-v1-37-pvc-last-used-time/

CNCFがKubernetes 1.37(コードネーム「Garhwal」)を正式リリースした。Metrics APIが正式版(GA)に到達しHPA/VPAの基盤が強化されたほか、Rootless KubeletやスケールゼロHPAがベータに昇格するなど、AI/MLワークロード向けの最適化とセキュリティ強化が図られている。また、未使用のPersistentVolumeClaimを検出する新機能もベータに昇格し、ストレージリソースの管理性が向上した。

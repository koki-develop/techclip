# Zig開発者、AIによるコード貢献を正式禁止しGitHubからCodebergへ移行
Tags: OSS, Programming Languages

- Andrew Kelley Interview: Why He Built Zig, Banned AI Contributions, and Moved Zig off GitHub (2026-09-23)
  https://www.infoq.com/news/2026/09/andrew-kelley-zig-no-ai/

プログラミング言語Zigの作者Andrew Kelley氏へのインタビューが公開された。AIによるコード貢献はレビュアーの時間を浪費し、初心者がコードを書きながら学ぶというプロジェクトの教育的使命に反するとして正式に禁止した経緯を語った。また、GitHub Actionsの度重なる不具合や非営利モデルへの信頼を理由に、ZigプロジェクトをGitHubからCodebergへ移行した背景も明らかにした。

# Cloudflare、Python WorkersをEdgeランタイムで一般提供開始
Tags: Cloud, Programming Languages

- Python Workers are now generally available (2026-09-21)
  https://blog.cloudflare.com/python-workers-ga/

Cloudflareは、PythonをWorkersプラットフォームの正式サポート言語として一般提供を開始した。FastAPIやDjangoといった主要フレームワークを、JavaScriptと同じエッジランタイム上で直接実行できるようになり、Pythonエコシステムの開発者もCloudflareのグローバルネットワークを活用したサーバーレス開発が可能になった。

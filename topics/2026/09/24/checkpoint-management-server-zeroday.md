# Check Pointの管理サーバーにゼロデイ脆弱性、7月から標的型攻撃で悪用と判明

Check PointがSecurity Management Serverの認証前パストラバーサル脆弱性(CVE-2026-93616、CVSS 9.8)を公開し修正パッチを提供した。この脆弱性は7月から標的型攻撃で既に悪用されていたことが判明しており、Multi-Domain Security Management Server、Log Server、SmartEventなど複数の製品が影響を受ける。

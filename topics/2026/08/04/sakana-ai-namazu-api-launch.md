# Sakana AI、日本特化LLM「Namazu」をアップデートしAPIサービス「Sakana Namazu」の提供を開始
Tags: AI

- Sakana AI、日本特化LLM「Namazu」をアップデートしAPIサービス「Sakana Namazu」の提供を開始 (2026-08-03)
  https://gihyo.jp/article/2026/08/sakana-namazu
- Sakana AI Launches Japanese LLM API (2026-08-03)
  https://www.startuphub.ai/ai-news/artificial-intelligence/2026/sakana-ai-launches-japanese-llm-api

Sakana AIは、Moonshot AIの「Kimi K2.6」をベースに日本語・日本のビジネス慣行に特化して追加学習したLLM「Namazu」をAPI化し、「Sakana Namazu」として提供開始した。OpenAI互換API、Web検索・コード実行機能を備え、フロンティアモデルより低コストな選択肢として市場調査自動化や日本語カスタマーサポートなどの用途を想定している。

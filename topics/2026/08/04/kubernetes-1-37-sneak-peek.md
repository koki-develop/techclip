# Kubernetes v1.37の主な変更点が公開、kubectl runの一部フラグ非推奨化やipvsモード段階的廃止など
Tags: Cloud

- Kubernetes v1.37 Sneak Peek (2026-07-31)
  https://kubernetes.io/blog/2026/07/31/kubernetes-v1-37-sneak-peek/

次期Kubernetes v1.37の主な変更点として、`kubectl run --filename`フラグの非推奨化、Static PodからのSecret/ConfigMap直接参照の禁止、kube-proxyのipvsモード非推奨化(v1.40でデフォルト無効化、v1.43で完全削除予定)などが予告された。

# マルチメディアフレームワークFFmpeg 9.0「Lei」リリース、アニメーションWebPデコードなど新機能追加
Tags: OSS

- FFmpeg 9.0 "Lei" Released with Animated WebP Decoding and New Hardware Acceleration (2026-08-03)
  https://www.phoronix.com/news/FFmpeg-9.0-Released

オープンソースのマルチメディアフレームワークFFmpegがバージョン9.0「Lei」をリリースした。アニメーションWebPのデコード対応や、Vulkan/VideoToolboxを用いたAPVおよびProRes RAWのハードウェアアクセラレーション強化など多数の新機能が追加された。

# AWS Interconnect、Oracle Cloud Infrastructureとのマルチクラウド接続が一般提供開始
Tags: Cloud

- AWS announces AWS Interconnect – multicloud connectivity with Oracle Cloud Infrastructure in GA (2026-07-29)
  https://aws.amazon.com/about-aws/whats-new/2026/07/aws-announces-AWS-interconnect-multicloud-OCI-GA/

AWSはマルチクラウド接続サービス「AWS Interconnect」がOracle Cloud Infrastructure（OCI）に対応し一般提供を開始したと発表した。Google Cloudに続き2番目の対応クラウドとなり、Microsoft Azureも2026年内に対応予定としている。

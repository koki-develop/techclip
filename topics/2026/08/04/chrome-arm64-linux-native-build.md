# Google Chrome、ARM64版Linux向けにネイティブビルドを正式提供開始
Tags: OSS

- Google Chrome quietly arrives on ARM64 Linux (2026-08-03)
  https://linuxiac.com/google-chrome-quietly-arrives-on-arm64-linux/

Googleは公式ダウンロードページからDebian・Ubuntu向けの.debパッケージとFedora・openSUSE向けの.rpmパッケージを提供開始し、ARM64版LinuxユーザーもWidevine DRMやアカウント同期を含む完全なChrome機能を利用できるようになった。

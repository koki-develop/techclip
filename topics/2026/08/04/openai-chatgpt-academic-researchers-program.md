# OpenAI、研究者向け無料ChatGPTプログラムを開始、最大10万人にGPT-5.6アクセス提供
Tags: AI

- OpenAI Launches ChatGPT for Academic Researchers (2026-07-30)
  https://www.hpcwire.com/aiwire/2026/07/30/openai-launches-free-chatgpt-program-for-100000-academic-researchers/

OpenAIは科学者・数学者・エンジニアなど最大10万人の研究者に最新モデル「GPT-5.6 Sol Pro」への無料アクセスを提供する新プログラムを開始した。2027年までに2億5000万ドル超を外部研究支援に投じる計画の一環と位置づけられている。

# 日本のクラウドネイティブ開発者、CNCF調査で約100万人に到達
Tags: Cloud, OSS

- クラウドネイティブ開発者、国内で約100万人に到達 CNCFとSlashDataが調査結果を発表 (2026-08-03)
  https://www.publickey1.jp/blog/26/100cncf.html

CNCFとSlashDataによる調査で、日本のクラウドネイティブ開発者コミュニティが約100万人(世界全体は約1990万人)規模に達したことが明らかになった。国内はオンプレミス依存が根強くKubernetes採用率は27%にとどまるなど、海外と異なる成熟パターンを示しており、AIインフラの役割拡大なども報告されている。

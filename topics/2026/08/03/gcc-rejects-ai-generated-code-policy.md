# GCC、著作権上「重要」とみなされるAI生成コードの取り込みを拒否する方針を正式採択
Tags: OSS, AI

- GCC Adopts Policy Rejecting Significant AI-Generated Code (2026-07-29)
  https://linuxiac.com/gcc-adopts-policy-rejecting-significant-ai-generated-code/

GCC運営委員会は、GPLv3のライセンス整合性を守るため、著作権上「重要」とみなされる(目安として約15行以上の)LLM生成コードの取り込みを拒否する方針を正式に採択した。ChatGPTやCopilotなどで生成・編集されたコードも対象となるが、軽微な変更やテストケースは例外として認められる。AI生成コードの著作権的位置づけを巡る主要オープンソースプロジェクトの姿勢として注目されている。

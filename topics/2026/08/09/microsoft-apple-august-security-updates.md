# MicrosoftとAppleが月例セキュリティアップデートを公開、Teams等にCVSS10.0の深刻な脆弱性
Tags: Security

- Microsoft, Apple Release Fresh Security Updates (2026-08-07)
  https://www.securityweek.com/microsoft-apple-release-fresh-security-updates/
- From Screen Share to Root Access: Breaking Down CVE-2026-43760 and CVE-2026-65400 on macOS (2026-08-07)
  https://www.huntress.com/blog/macos-screen-sharing-rce-patched

Microsoftは Active Directory、Azure、Entra、SharePoint、Teamsなどにまたがる深刻な脆弱性を多数修正し、うち3件はCVSSスコア10/10のリモートコード実行の欠陥だった。Appleも認証をバイパスできるScreen Sharingの高深刻度脆弱性(CVE-2026-65400)を修正しており、悪用されればroot権限奪取につながる恐れがあったと指摘されている。

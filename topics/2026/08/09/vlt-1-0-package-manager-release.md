# npm元開発者らによる次世代パッケージマネージャ「vlt」がバージョン1.0に到達、ホスト型レジストリも提供開始
Tags: OSS, Programming Languages

- vlt 1.0 & Hosted Package Registries (2026-08-04)
  https://www.vlt.io/blog/1-0

npmの元開発者らが手がけるセキュリティ重視の次世代JavaScriptパッケージマネージャ「vlt」がバージョン1.0に到達した。あわせてnpmミラーレジストリとプライベートレジストリをホスティングするサービスも利用可能になり、サプライチェーンセキュリティを重視した開発者向けエコシステムの拡充が図られている。

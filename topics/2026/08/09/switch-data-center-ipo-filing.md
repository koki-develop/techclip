# データセンター運営大手Switch、AI需要拡大を背景に新規株式公開を非公開申請、評価額最大800億ドル
Tags: Cloud, Other

- Data Center Firm Switch Is Said to File Confidentially for IPO (2026-08-07)
  https://www.bloomberg.com/news/articles/2026-08-07/data-center-firm-switch-is-said-to-file-confidentially-for-ipo

AI需要拡大を背景に、データセンター運営会社Switchが米国での新規株式公開(IPO)を非公開ベースで申請したとBloombergが報道した。評価額は500億〜800億ドル規模になる可能性があり、11月にも上場する見通し。

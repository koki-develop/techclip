# AWS、AIエージェント向けガバナンス言語「Dogwood」をオープンソース化、協調型マルチエージェント機能「Kiro Crew」も発表
Tags: Cloud, AI

- Introducing Dogwood: runtime verification for AI agents (2026-08-06)
  https://aws.amazon.com/blogs/opensource/introducing-dogwood-runtime-verification-for-ai-agents/
- AWS Open Sources Kiro Crew But Keeps The Agent Harness Closed (2026-08-06)
  https://www.forbes.com/sites/janakirammsv/2026/08/06/aws-open-sources-kiro-crew-but-keeps-the-agent-harness-closed/

AWSはAIエージェントの実行時検証を行うガバナンス言語「Dogwood」をオープンソースで公開し、IDE「Kiro」向けに複数エージェントが協調して作業する新機能「Kiro Crew」も発表した。一方でエージェントの実行基盤(ハーネス)自体は非公開のまま据え置いている。

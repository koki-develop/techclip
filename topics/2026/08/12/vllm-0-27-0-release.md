# 高速LLM推論ライブラリ「vLLM」がv0.27.0をリリース、Kimi K3対応やFlashAttention 4強化など大型アップデート
Tags: OSS, AI

- vLLM v0.27.0 Release (2026-08-09)
  https://github.com/vllm-project/vllm/releases

高速LLM推論・サービングライブラリvLLMがv0.27.0をリリースした。Kimi K3モデルのサポート追加、PyTorch 2.13へのアップグレード、FlashAttention 4の強化、DeepSeek-V4の性能改善など561件のコミットを含む大型アップデートとなっている。

# Google Cloud、2026年Gartnerマジック・クアドラント「Cloud-Native Application Platforms」部門で3年連続リーダーに選出
Tags: Cloud

- Google Cloud named a Leader in the 2026 Gartner Magic Quadrant for Cloud-Native Application Platforms (2026-08-20)
  https://cloud.google.com/blog/products/application-development/2026-gartner-mq-for-cloud-native-application-platforms

Google Cloudは、Gartnerの「Cloud-Native Application Platforms」部門のマジック・クアドラントで3年連続リーダーに選出された。サーバーレスやコンテナ、エージェント型ワークロードに対応した開発者中心のプラットフォームが評価されている。

# Next.js、libheif経由のRCEなど深刻な脆弱性を修正する8月セキュリティリリースを公開
Tags: Programming Languages, Security

- August 2026 Security Release (2026-08-25)
  https://nextjs.org/blog/august-2026-security-release
- Vercel applications are protected from Next.js August 2026 security vulnerabilities (2026-08-25)
  https://vercel.com/changelog/nextjs-august-2026-security-release

Next.jsチームがバージョン16.3.3および15.5.24をリリースし、画像最適化に使われるlibheif経由の未認証リモートコード実行や、Windows環境でのPages/App Router組み合わせによるRCEなど重大な脆弱性を修正した。8月23日の事前告知に続き具体的な脆弱性内容と修正版が公開された形で、Vercelは自社プラットフォーム上のアプリケーションが既に保護済みであることを表明している。

# AWS Direct Connect、インバウンドプレフィックス制御機能を追加し経路上限を10倍に拡大
Tags: Cloud

- AWS Direct Connect introduces inbound prefix controls and higher prefix scale (2026-08-20)
  https://aws.amazon.com/about-aws/whats-new/2026/08/aws-direct-connect-new-prefix-controls/

AWS Direct ConnectがVIF単位でのインバウンドルートプレフィックス割り当て管理機能を追加し、1接続あたりの経路上限をIPv4/IPv6それぞれ100から1,000に拡大した。追加費用なしで全商用リージョンなどに提供される。

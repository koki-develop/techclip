# フィッシングキット「Mirage2FA」が米欧4500社を標的に、Microsoft 365の認証を突破
Tags: Security

- Mirage2FA Surge Hits 4,500 US and EU Companies, Abusing Microsoft 365 Login Flows (2026-08-25)
  https://thehackernews.com/2026/08/mirage2fa-surge-hits-4500-us-and-eu.html
- Hackers Let Microsoft 365 Users Complete MFA, Then Steal Logged-In Sessions (2026-08-19)
  https://cybersecuritynews.com/microsoft-365-session-theft/

フィッシングキット「Mirage2FA」を使ったAiTM(Adversary-in-the-Middle)攻撃キャンペーンが米国・欧州の約4,500社を標的とし、Microsoft 365のログインフローを悪用して認証情報や二要素認証コード、セッションCookieを窃取している。被害者が正規に多要素認証を完了した後にセッションを乗っ取る手口が特徴で、大規模な組織的被害が懸念されている。

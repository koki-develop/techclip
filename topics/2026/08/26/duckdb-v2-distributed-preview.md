# DuckDB v2.0「Cyanoptera」プレビュー公開、分散ネットワーク機能を追加しアーキテクチャを拡張
Tags: OSS, Programming Languages

- Beyond Embedded: How DuckDB v2.0 Shifts Architecture Toward Distributed Network Capabilities (2026-08-25)
  https://www.infoq.com/news/2026/08/duckdb-v2-distributed/

DuckDB Labsは開発コード名「Cyanoptera」ことDuckDB v2.0のプレビューを公開した。1万以上のコミットを経て、クライアント/サーバーモードによるネットワーク接続、VARIANT型、非同期I/Oなどが追加され、組み込み型データベースから分散アーキテクチャへと拡張を図っている。

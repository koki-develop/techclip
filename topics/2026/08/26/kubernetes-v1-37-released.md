# Kubernetes v1.37が正式リリース、9年越しでMetrics APIがGAに到達
Tags: Cloud, OSS

- Kubernetes v1.37 released (2026-08-26)
  https://www.kubernetes.dev/resources/release/

Kubernetes 1.37が正式リリースされ、9年近くベータ版だったMetrics APIが安定版(GA)に到達したほか、KYAMLやDRA(Dynamic Resource Allocation)関連の機能を含む16件の機能が安定版に昇格した。一方でkubectl runの--filenameフラグの非推奨化やcgroup v1サポートの段階的廃止も進められている。

# SnowflakeがNative Apps向け「Cortex Agents」と「MCPサーバー」を正式提供開始
Tags: Cloud, AI

- Snowflake Native Apps: Cortex Agents and MCP servers reach General Availability (2026-08-07)
  https://docs.snowflake.com/en/release-notes/new-features

Snowflake Native AppsにおいてAIエージェント機能「Cortex Agents」とMCPサーバーのサポートが正式提供(GA)を開始した。開発者はAIエージェントをアプリ内でネイティブに構築・実行できるようになり、企業データ基盤とAIエージェントの統合が一段と進む。

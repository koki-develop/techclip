# Open VSXマーケットプレイスから開発者情報を窃取する悪意ある拡張機能77個を削除
Tags: Security, OSS

- Open VSX Removes 77 Malicious Evil Twin Extensions Exfiltrating Developer Data (2026-08-05)
  https://thehackernews.com/2026/08/open-vsx-removes-77-malicious-evil-twin.html
- 77 Open VSX extensions found harvesting developer info (2026-08-04)
  https://www.bleepingcomputer.com/news/security/77-open-vsx-extensions-found-harvesting-developer-info/
- Fake Open VSX Extensions Harvest Private Repo and CI Data (2026-08-05)
  https://www.infosecurity-magazine.com/news/open-vsx-evil-twin-extensions-git/

正規の開発者ツールになりすました「evil twin」型の悪意ある拡張機能77個がOpen VSXマーケットプレイスから削除された。これらはホスト名やリポジトリ情報、CI環境のデータを外部サーバーへ送信しており、VS Code系エディタを利用する開発者を広く標的にしていたことが判明した。

# オープンウェイトモデル「Kimi K3」がGitHub Copilotで一般提供開始
Tags: OSS, AI

- Kimi K3 is now available in GitHub Copilot (2026-08-06)
  https://github.blog/changelog/2026-08-06-kimi-k3-is-now-available-in-github-copilot/

オープンウェイトモデルKimi K3がGitHub Copilotで一般提供を開始した。エージェント型コーディングにおいてフロンティア級の性能を低コストで利用できるようになり、開発者向けAIコーディング支援の選択肢がさらに広がった。

# AWS Direct Connect、フランクフルトEquinix拠点の水漏れによる通信障害が復旧
Tags: Cloud

- AWS Health Dashboard / AWS Support告知 (2026-08-18)
  https://aws.amazon.com/about-aws/whats-new/

AWS Direct ConnectのEU-CENTRAL-1リージョンで、フランクフルトのEquinix FR5拠点における水漏れが原因で冷却・電源系統に障害が発生し、8月14日から続いていたパケットロスが8月18日に完全復旧した。データセンターの物理的な設備障害がクラウド接続サービスに数日間影響を及ぼす事例として、インフラの単一障害点リスクを改めて示した。

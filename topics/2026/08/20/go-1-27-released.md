# Go 1.27が正式リリース、ジェネリックメソッドやポスト量子暗号に対応
Tags: Programming Languages

- Go 1.27 is released (2026-08-19)
  https://go.dev/blog/go1.27

Go 1.27が正式リリースされ、ジェネリックメソッドやネストした構造体リテラルの初期化、型推論の改良などの言語機能が追加された。標準ライブラリにはポスト量子暗号(ML-DSA)、書き直されたJSON API(encoding/json/v2)、UUIDパッケージ、SIMDサポートが加わり、小さなメモリ割り当てのコストを最大30%削減するパフォーマンス改善も行われた。

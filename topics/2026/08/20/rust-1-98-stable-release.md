# Rust 1.98.0安定版リリース、C可変長引数関数などが追加
Tags: Programming Languages

- Rust 1.98.0 Stable Released (2026-08-20)
  https://byteiota.com/rust-1-98-stable-c-variadic-naked-functions-august-2026/

Rust 1.98.0が安定版としてリリースされた。C言語の可変長引数関数(variadic functions)のサポート安定化や、`#[derive(PartialOrd)]`マクロに関する長年のバグ修正などが行われている。

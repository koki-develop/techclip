# AWSがCedarを拡張したオープンソース言語「Dogwood」を発表、AIエージェントのツール呼び出し履歴を統治
Tags: Programming Languages, Cloud, Security

- AWS Open-Sources Dogwood, Extending Cedar to Govern Sequences of Agent Tool Calls (2026-08-16)
  https://www.infoq.com/news/2026/08/aws-dogwood-agent-policy/

AWSがポリシー言語Cedarを拡張したオープンソースの新言語「Dogwood」を発表した。AIエージェントが過去に行ったツール呼び出しの履歴を時系列条件で参照できるようにし、Apache 2.0ライセンスの下でAgentCore Policyでの利用をサポートする。エージェントの単発の判断だけでなく、一連の行動の流れをガバナンスの対象にできる点が特徴。

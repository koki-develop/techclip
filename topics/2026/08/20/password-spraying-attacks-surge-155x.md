# パスワードスプレー攻撃が155倍に急増、MFAの隙間を突く手口が拡大
Tags: Security

- Password spraying attacks surge 155x as hackers exploit MFA gaps (2026-08-19)
  https://www.bleepingcomputer.com/news/security/password-spraying-attacks-surge-155x-as-hackers-exploit-mfa-gaps/

セキュリティ企業Huntressの報告によると、2026年上半期にパスワードスプレー攻撃が155倍に急増した。Azure CLIを狙った「LSHIY」と呼ばれるキャンペーンでは2週間で8100万回以上のログイン試行が確認され、MFAが有効な環境でも認証プロンプトを経由しないログイン経路が悪用され、64組織で78アカウントが侵害された。

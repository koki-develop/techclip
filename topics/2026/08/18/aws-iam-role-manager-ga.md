# AWS、IAMロールを自動構成する「Role Manager」を一般提供開始
Tags: Cloud

- AWS IAM now provides role manager to set up IAM roles automatically (2026-08-12)
  https://aws.amazon.com/about-aws/whats-new/2026/08/aws-iam-role-manager/

AWSがIAMロールの設定を自動化する新機能「Role Manager」を一般提供開始した。対応する6つのサービスコンソールで、IAMロールを手動で設定する必要がなくなり、権限設定のミスや手間を削減できる。

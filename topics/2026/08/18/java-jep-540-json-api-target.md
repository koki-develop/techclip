# Java標準API「Simple JSON API」(JEP 540)がJDK 28のターゲット候補に
Tags: Programming Languages

- JEP 540: Simple JSON API Proposed to Target for JDK 28 (2026-08-17)
  https://www.infoq.com/news/2026/08/java-native-json-api/

JavaにJSONの解析・生成を外部ライブラリなしで行える標準APIを追加する提案が、JDK 28のターゲット候補となった。JacksonやGsonより軽量な用途を想定しており、まずはインキュベータモジュールとして提供される見込み。

# セキュリティ研究者ら、OpenAIのサイバー研究プログラムへのアクセスを突然剥奪されたと訴え
Tags: AI, Security

- Researchers say OpenAI revoked their access to limited cyber program (2026-08-19)
  https://techcrunch.com/2026/08/19/researchers-complain-that-openai-revoked-their-access-to-limited-cyber-program/

セキュリティ研究者らが、OpenAIのサイバーセキュリティ研究向け制限緩和プログラムへのアクセスを予告なく剥奪されたと訴えており、AIを悪用したサイバー攻撃対策の運用方針や研究コミュニティとの関係を巡る議論が広がっている。

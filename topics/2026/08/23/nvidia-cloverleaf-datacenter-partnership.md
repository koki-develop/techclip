# NVIDIA、データセンター開発のCloverleafと戦略的パートナーシップを締結
Tags: Cloud

- Nvidia partners with data center developer Cloverleaf (2026-08-21)
  https://techcrunch.com/2026/08/21/nvidia-partners-with-data-center-developer-cloverleaf/

NVIDIAはデータセンター用地開発を手がけるCloverleaf Infrastructureと戦略的パートナーシップを締結し、少数株出資も実施した。両社は電力・冷却・コンピューティングを統合したAIファクトリー構築を加速させる狙いで、Cloverleafは既に7GW超のプロジェクトをOracleやOpenAI向けに販売済みとなっている。

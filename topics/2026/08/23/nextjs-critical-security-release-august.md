# Next.js、深刻な脆弱性を修正する緊急セキュリティリリースを8月26日に予告
Tags: Programming Languages, Security

- Upcoming Next.js August Security Release (2026-08-20)
  https://nextjs.org/blog/upcoming-nextjs-security-release-august-2026

Next.jsチームは2026年8月26日に深刻度「Critical」の脆弱性を修正するセキュリティリリース(バージョン16.3.3および15.5.24)を予定していることを事前告知し、開発者にアップグレード計画の準備を促した。

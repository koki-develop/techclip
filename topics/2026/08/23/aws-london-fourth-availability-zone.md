# AWS、ロンドンリージョンに4つ目のアベイラビリティーゾーンを新設しAI向け容量を拡大
Tags: Cloud

- AWS adds fourth Availability Zone to Europe (London) Region (2026-08-19)
  https://aws.amazon.com/about-aws/whats-new/2026/08/aws-iam-increased-quota/

AWSは欧州（ロンドン）リージョンに4番目のアベイラビリティーゾーン（eu-west-2d）を追加し、Trn3やP6などの次世代AI/ML向けインスタンスを含む拡張キャパシティを提供開始した。

# GitHub、複数の変更を連続管理できる「Stacked Pull Requests」をパブリックプレビュー公開
Tags: OSS

- Stacked pull requests are now in public preview (2026-07-30)
  https://github.blog/changelog/2026-07-30-stacked-pull-requests-are-now-in-public-preview/

GitHubがスタック型プルリクエスト(Stacked PRs)機能をパブリックプレビューとして全リポジトリに展開し始めた。互いに依存する複数の連続した変更を、リベース地獄に陥ることなく個別のPRとして管理・レビューできるようになる。

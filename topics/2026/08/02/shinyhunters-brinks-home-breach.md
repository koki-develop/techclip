# ShinyHunters、住宅セキュリティ企業Brinks Homeへの侵入を主張しデータ流出を脅迫
Tags: Security

- ShinyHunters claims Brinks Home breach, threatens to leak stolen data (2026-07-31)
  https://www.bleepingcomputer.com/news/security/shinyhunters-claims-brinks-home-breach-threatens-to-leak-stolen-data/
- Brinks Home Confirms Data Breach Following ShinyHunters Claim (2026-08-01)
  https://cybersecuritynews.com/brinks-home-confirms-data-breach/

住宅向けセキュリティ企業Brinks Homeが、Microsoft Entraを狙ったビッシング攻撃を通じてシステムに侵入されたことを公表した。ハッカー集団ShinyHuntersは顧客・従業員に関するSalesforceの記録490万件以上を窃取したと主張し、身代金が支払われなければ流出させると脅迫している。

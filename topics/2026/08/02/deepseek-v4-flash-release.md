# DeepSeek、Opus 4.8並みの性能を低コストで実現する新モデル「DeepSeek-V4-Flash-0731」を公開
Tags: AI, OSS

- DeepSeek-V4-Flash-0731 (2026-07-31)
  https://huggingface.co/deepseek-ai/DeepSeek-V4-Flash-0731

DeepSeekはMITライセンスのMoEモデル「DeepSeek-V4-Flash-0731」を正式公開した。304BパラメータのうちMoEにより一部のみが活性化する構成ながら、エージェント・コーディング関連ベンチマークで前バージョンを上回る性能を達成し、Anthropic Claude Opus 4.8並みの性能を大幅な低価格で提供するとしている。Responses API形式にも対応し、オンプレミス商用利用の制限も解除された。

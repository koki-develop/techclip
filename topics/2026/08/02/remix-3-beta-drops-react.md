# Remix 3ベータ版公開、Reactを離脱しWeb標準ベースのフルスタックフレームワークへ全面刷新
Tags: Programming Languages

- Remix 3 Beta Preview Ditches React for a Web-Standards Full-Stack Framework (2026-07-28)
  https://www.infoq.com/news/2026/07/remix-3-beta-preview/

Remix 3はReactから離れ、Fetch APIのRequest/Responseなどウェブ標準プリミティブを基盤とするフルスタックフレームワークへと全面刷新された。フロントエンドはフォーク版Preactを採用し、既存のRemix 2アプリはReact Router v7へ移行する一方、Remix 3への移行には全面的な書き直しが必要となる。

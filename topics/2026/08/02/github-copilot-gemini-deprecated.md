# GitHub Copilot、Gemini 2.5 ProとGemini 3 Flashの提供を終了
Tags: OSS, AI

- Gemini 2.5 Pro and Gemini 3 Flash deprecated (2026-07-31)
  https://github.blog/changelog/2026-07-31-gemini-2-5-pro-and-gemini-3-flash-deprecated/

GitHubがCopilot Chat、インラインエディット、エージェントモード、コード補完を含む全てのCopilot体験からGemini 2.5 ProとGemini 3 Flashの提供を終了したと発表した。利用者はGemini 3.1 Proや3.5 Flashなど後継モデルへの移行が必要となる。

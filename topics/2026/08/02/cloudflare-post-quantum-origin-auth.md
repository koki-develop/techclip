# Cloudflare、オリジンサーバーとの通信にポスト量子認証をサポート
Tags: Cloud, Security

- Post-quantum authentication to origins (2026-07-29)
  https://blog.cloudflare.com/post-quantum-authentication-to-origins/

CloudflareはAuthenticated Origin PullsおよびCustom Origin Trust StoreでML-DSA(FIPS 204)ポスト量子証明書に対応し、CloudflareとオリジンサーバーとのEnd-to-Endのポスト量子認証を実現した。

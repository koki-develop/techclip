# Python 3.14.7と3.13.15がリリース、約400件のバグ修正とセキュリティ改善を実施
Tags: Programming Languages

- Python 3.14.7 and 3.13.15 are now available! (2026-08-05)
  https://blog.python.org/2026/08/python-3147-31315/

Python 3.14.7と3.13.15がリリースされ、86名以上のコントリビューターによる約400〜500件のバグ修正が含まれる。3.14系ではJITコンパイラが公式Windows/macOSバイナリに搭載され、リリース検証にSigstoreを採用した。

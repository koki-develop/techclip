# SkiaSharp 4.0、Skiaのマイルストーンに合わせたリリースサイクルを確立
Tags: Programming Languages

- SkiaSharp 4.0 Establishes Milestone-Aligned Release Cadence (2026-08-05)
  https://www.infoq.com/news/2026/08/skia-sharp-4-release/

MicrosoftとUno Platformが.NET向け2Dグラフィックスライブラリ「SkiaSharp」の4系初の安定版(4.148.0、4.150.0)をリリースした。今後は上流Skiaのマイルストーンに合わせたリリースサイクルを採用し、バージョン追従の透明性を高める。

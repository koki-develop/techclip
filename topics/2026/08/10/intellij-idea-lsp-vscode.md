# JetBrains、IntelliJ IDEAのJava/Kotlin解析機能をLSP経由でVS Code等に提供へ
Tags: Programming Languages, OSS

- IntelliJ IDEA Goes LSP: Java and Kotlin Intelligence Comes to VS Code, Cursor, and Agentic Flows (2026-08-04)
  https://blog.jetbrains.com/idea/2026/08/intellij-idea-goes-lsp/

JetBrainsがIntelliJ IDEAのJava/Kotlin言語解析機能をLanguage Server Protocol(LSP)経由でVS CodeやCursorなど他のエディタで利用できるプレビュー版拡張機能を公開した。Maven・Gradle・Bazelプロジェクトのコード補完やリファクタリングに対応し、エージェント型開発フローとの連携も見据える。

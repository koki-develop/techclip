# Spring生みの親らが開発するJVM向けAIエージェントフレームワーク「Embabel」が正式に1.0到達
Tags: Programming Languages, OSS

- Embabel Agent Framework Reaches 1.0 (2026-08-03)
  https://www.infoq.com/news/2026/08/embabel-1/

Spring Frameworkの生みの親Rod Johnson氏らが開発するJVM向けAIエージェントフレームワーク「Embabel」が正式に1.0に到達した。Goal-Oriented Action Planning(GOAP)を用い、Java/Kotlin開発者がエージェントを型付きドメインオブジェクトとして定義できる点が特徴。

# PHP 8.5.10・8.4.25がリリース、バッファオーバーフローなど複数のCVEを修正
Tags: Programming Languages

- PHP 8.5.10 and 8.4.25 Released: Critical CVE Patches and Stack Overflow Fixes (2026-08-27)
  https://php.watch/versions/8.5/releases/8.5.10

PHPプロジェクトはPHP 8.5.10および8.4.25をリリースした。bccomp()関数のバッファオーバーフローを修正するCVE-2026-17544を含む複数のセキュリティ脆弱性に対応したほか、深くネストしたデータ構造を処理する際のスタック枯渇問題も修正されている。

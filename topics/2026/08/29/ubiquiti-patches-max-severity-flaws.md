# Ubiquitiが最大深刻度(CVSS 10.0)の脆弱性3件を含む計22件の脆弱性を修正
Tags: Security

- Ubiquiti patches three max severity security vulnerabilities (2026-08-26)
  https://www.bleepingcomputer.com/news/security/ubiquiti-patches-three-max-severity-security-vulnerabilities/
- Three 10.0 security flaws fixed across Ubiquiti's UniFi line (2026-08-26)
  https://cyberscoop.com/ubiquiti-unifi-critical-vulnerabilities-patched/

Ubiquitiはセキュリティ勧告SAB-067を公開し、UniFi Protect・UniFi OS・UniFi Talkにまたがる計22件の脆弱性を修正した。うち3件はCVSS 10.0の最大深刻度で、不適切なアクセス制御に起因する欠陥だった。UniFi製品は家庭・企業双方で広く使われており、影響範囲の大きさが懸念されている。

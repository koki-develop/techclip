# KioxiaとSanDisk、業界最高密度の第10世代QLC NANDフラッシュメモリを発表
Tags: Other

- Kioxia and SanDisk Announce 10th-Generation QLC 3D Flash Memory Technology (2026-08-04)
  https://www.kioxia.com/en-jp/about/news/2026/20260804-2.html

KioxiaとSanDiskはFMS 2026にて第10世代QLC 3Dフラッシュメモリ技術を発表した。第8世代比で最大60%のビット密度向上を実現し、AI・クラウドストレージ向けの電力効率と容量を大きく高めている。

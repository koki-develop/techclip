# Vercel Labsが AIエージェント専用のプログラミング言語「Zero」を発表
Tags: Programming Languages, AI

- Vercel Labs Ships Zero: A Graph-First Language Built So Agents Write the Code (2026-08-06)
  https://www.infoq.com/news/2026/08/vercel-ships-zero-ai/

Vercel Labsは、人間ではなくAIエージェントがコードを読み書き・修復することを前提に設計された実験的なシステムプログラミング言語「Zero」を発表した。グラフファースト構造や機械可読な修復プランを持つエラーコード、明示的なエフェクト追跡などを特徴とする。

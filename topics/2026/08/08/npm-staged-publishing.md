# npmが「ステージ公開」機能を正式リリース、パッケージ公開前に人間の承認ステップを追加
Tags: Programming Languages, OSS, Security

- npm Staged Publishing Available, Adding a Human Approval Step Before Packages Go Live (2026-08-07)
  https://www.infoq.com/news/2026/08/npm-stage-available/

npmが新機能「ステージ公開」を正式リリースし、パッケージが実際に公開される前に2要素認証による人間の承認ステップを挟めるようになった。サプライチェーン攻撃対策の一環で、pnpmやYarnなど他のパッケージマネージャーでも同様の機能導入が進んでいる。

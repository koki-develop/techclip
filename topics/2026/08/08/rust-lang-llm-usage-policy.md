# Rustの公式リポジトリがコード生成へのLLM利用を原則禁止する方針を採択
Tags: Programming Languages, OSS

- rust-lang/rust is adopting an LLM policy (2026-08-05)
  https://blog.rust-lang.org/inside-rust/2026/08/05/rust-langrust-is-adopting-an-llm-policy/

Rustのコンパイラや標準ライブラリを管理する5チームが、rust-lang/rustへの貢献におけるLLM利用に関する公式ポリシーを採択した。コード生成へのLLM利用は原則禁止とする一方、学習・分析・レビューの補助としての利用は許可するという保守的な方針を示しており、主要OSSプロジェクトにおけるAIコーディングツールの扱いを巡る議論の一例となっている。

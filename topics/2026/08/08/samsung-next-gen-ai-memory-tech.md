# Samsung、AIデータセンター向け次世代メモリ技術zHBM・zNAND-O・BV-NANDを発表
Tags: Other, Cloud

- Samsung debuts three next-generation memory technologies for AI data centers — zHBM, zNAND-O, and BV-NAND (2026-08-05)
  https://www.tomshardware.com/pc-components/dram/samsung-debuts-three-next-generation-memory-technologies-for-ai-data-centers-zhbm-znand-o-and-bv-nand-all-rely-on-advanced-wafer-bonding-technologies

Samsungが米カリフォルニア州で開催されたFMS 2026にて、AIデータセンター向けの新メモリ技術3種(zHBM、zNAND-O、BV-NAND)を発表した。zHBMはHBM5比で最大8倍の性能を実現するとされ、いずれも先進的なウェハー接合技術を基盤にAIアクセラレータのデータ待ち問題の解消を狙う。

# GitHubがエンタープライズ向けにMCPサーバーの許可/拒否リスト機能を追加
Tags: OSS, Security

- MCP allowlists in enterprise managed settings (2026-08-06)
  https://github.blog/changelog/2026-08-06-mcp-allowlists-in-enterprise-managed-settings/

GitHubがエンタープライズ管理者向けに、MCP(Model Context Protocol)サーバーの許可/拒否リストを設定できる新機能を発表した。Copilotアプリ・CLI・VS Codeにおいて、組織全体で信頼できないMCPサーバーの利用をブロックできるようになる。

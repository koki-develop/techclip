# GitHub Copilot for Visual Studio、組織向けカスタムエージェント公開など8月アップデート
Tags: OSS

- GitHub Copilot in Visual Studio — August update (2026-08-28)
  https://github.blog/changelog/2026-08-28-github-copilot-in-visual-studio-august-update-2/

GitHubがVisual Studio向けCopilotの8月アップデートを公開した。組織レベルでのカスタムエージェント公開機能、モデルごとの思考努力度（Low/Medium/High）を制御できる設定、コミット前にGitエージェントがレビューを行う機能などが新たに追加された。

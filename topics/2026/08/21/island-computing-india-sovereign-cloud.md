# インドのIsland Computing、同国初となる完全マネージド型ソブリンクラウドを提供開始
Tags: Cloud

- Island Computing Launches India's First Fully Managed Sovereign Cloud (2026-08-15)
  https://startupstorymedia.com/built-in-india-governed-by-india-island-computing-launches-sovereign-cloud-platform/

インドの新興企業Island Computingが独立記念日の8月15日、データ・ハードウェア・運用体制のすべてをインド国内に置く完全マネージド型ソブリンクラウドの一般提供を開始した。DPDPA(個人情報保護法)やRBI等の規制対応を前提に設計されており、AWSやAzureなど海外クラウド依存からの脱却を狙う。

# Docker、コンテナ向け新ハイパーバイザ「Docker VMM」のパブリックベータを公開
Tags: Cloud, OSS

- Docker社、コンテナ向けの高性能な新ハイパーバイザ「Docker VMM」パブリックベータ公開 (2026-08-20)
  https://www.publickey1.jp/blog/26/dockerdocker_vmm.html
- Docker Launches Fully Rebuilt Virtualization Layer to Boost Performance and Improve Dev Experience (2026-08-19)
  https://www.infoq.com/news/2026/08/docker-vmm-layer/

DockerがDocker Desktop向けに自社開発の新ハイパーバイザ「Docker VMM」のパブリックベータを公開した。コンテナ起動やファイルI/Oの高速化、メモリ管理の改善を実現しており、正式版は2026年10月末を予定している。

# GitHub Copilot for JetBrainsに会話メモリ機能とOllama連携を追加
Tags: OSS, AI

- Copilot memory and Ollama in GitHub Copilot for JetBrains (2026-08-11)
  https://github.blog/changelog/2026-08-11-copilot-memory-and-ollama-in-github-copilot-for-jetbrains/

JetBrains向けGitHub Copilotに、セッションをまたいで文脈を保持する永続的な会話メモリ機能が追加された。加えて、Ollamaをローカルモデルプロバイダー(BYOK)として選択できるようになり、開発者はローカル環境で動くモデルを使ったコーディング支援を利用できるようになった。

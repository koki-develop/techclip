# Intel・AMDが合計80件超の脆弱性を修正するチップメーカー版Patch Tuesdayを実施
Tags: Security

- Chipmaker Patch Tuesday: Intel, AMD Fix Over 80 Vulnerabilities Combined (2026-08-12)
  https://www.securityweek.com/chipmaker-patch-tuesday-intel-amd-fix-over-80-vulnerabilities-combined/

Intelは42件のアドバイザリで72件の脆弱性（特権昇格やサービス拒否につながるプロセッサおよびワイヤレスソフトウェアの欠陥を含む）を公表し、AMDも5件のアドバイザリで、秘密鍵漏洩や任意コード実行につながりうる脆弱性を修正した。両社合わせて80件超の脆弱性が今回のパッチで対応された。

# PostgreSQL、28件のセキュリティ脆弱性を修正する定期アップデートと19ベータ3をリリース
Tags: OSS

- PostgreSQL 18.6, 17.11, 16.15, 15.19, 14.24 and 19 Beta 3 Released! (2026-08-13)
  https://www.postgresql.org/about/news/postgresql-186-1711-1615-1519-1424-and-19-beta-3-released-3365/

PostgreSQLの各サポートバージョン（18.6、17.11、16.15、15.19、14.24）に対する定期アップデートが公開され、28件のセキュリティ脆弱性と110件以上のバグが修正されたほか、次期メジャーバージョン19のベータ3もリリースされた。

# Microsoft、TypeScript 7.0をリリース—ネイティブGoコンパイラで最大12倍高速化
Tags: Programming Languages, OSS

- Microsoft Releases TypeScript 7.0 with a Native Go Compiler, Delivering 10x Faster Builds (2026-08-03)
  https://www.infoq.com/news/2026/08/typescript-7-released/
- TypeScript 7.0 Go Compiler: Up to 12x Faster, Breaks Some Tools (2026-08-02)
  https://www.sourcetrail.com/javascript/typescript/typescript-7-0-ships-with-go-powered-compiler-delivering-up-to-12x-speed-boost/

TypeScript 7.0がネイティブのGo言語ベースコンパイラを採用してリリースされ、VS Codeのビルド時間が125.7秒から10.6秒へと最大12倍高速化するなど大幅な性能向上を実現した。strictモードのデフォルト化なども盛り込まれる一方、Vue/Angular/Svelteなど一部の埋め込みツール連携は安定APIが未提供のため次期7.1まで持ち越しとなる。

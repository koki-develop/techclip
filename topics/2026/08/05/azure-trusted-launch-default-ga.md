# Azure、新規Gen2仮想マシンでセキュアブートとvTPMを標準有効化する「Trusted Launch as Default」が正式提供開始
Tags: Cloud, Security

- Secure by default: Trusted Launch as Default is now Generally Available (2026-08-03)
  https://techcommunity.microsoft.com/blog/microsoft-security-blog/secure-by-default-trusted-launch-as-default-is-now-generally-available/4541672

Azureの新規Gen2仮想マシンおよびスケールセットにおいて、セキュアブートと仮想TPMを標準で有効化する「Trusted Launch as Default」が正式提供開始となった。追加コストなしでブートキットやルートキットへの耐性を高められる。

# Python 3.15.0のリリース候補版1が公開、遅延インポートやJIT性能改善を搭載
Tags: Programming Languages

- Python 3.15.0 release candidate 1 is here! (2026-08-04)
  https://discuss.python.org/t/python-3-15-0-release-candidate-1-is-here/108395

Python 3.15の最初のリリース候補(RC1)が公開され、遅延インポート(PEP 810)やJITコンパイラの性能改善(x86-64 Linuxで8〜9%向上)、macOSでのフリースレッド対応標準化などが盛り込まれた。正式リリースは2026年10月1日を予定している。

# GitHub、AIアプリ構築ツール「GitHub Spark」の新規登録・新規作成を終了へ
Tags: OSS, AI

- Upcoming deprecation of GitHub Spark on github.com (2026-08-04)
  https://github.blog/changelog/2026-08-04-upcoming-deprecation-of-github-spark-on-github-com/

GitHubは2026年8月4日以降、AIアプリ構築ツール「GitHub Spark」の新規ユーザー登録と新規アプリ作成を停止すると発表した。既存ユーザーは8月31日までアプリのエクスポートなどでアクセス可能。

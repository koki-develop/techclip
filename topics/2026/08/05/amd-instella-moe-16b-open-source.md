# AMD、完全オープンソースのMoE型言語モデル「Instella-MoE-16B-A3B」を公開
Tags: AI, OSS

- AMD Releases Instella-MoE-16B-A3B: A Fully Open Mixture-of-Experts LLM With 2.8B Active Parameters Trained On Instinct GPUs (2026-08-01)
  https://www.marktechpost.com/2026/08/01/amd-instella-moe-16b-a3b-fully-open-mixture-of-experts-llm/

AMDは完全オープンソースのMoE(Mixture-of-Experts)型言語モデル「Instella-MoE-16B-A3B」を発表した。総パラメータ160億、有効パラメータ28億で、AMD Instinct MI300X/MI325X GPU上でゼロから学習され、事前学習を高速化する独自技術「FarSkip-Collective」を採用している。

# Model Context Protocol(MCP)、非同期通信やエンタープライズセキュリティ標準化を含む新ロードマップを公開
Tags: AI, OSS

- The New MCP Roadmap (2026-08-22)
  https://blog.modelcontextprotocol.io/posts/mcp-roadmap/

Model Context Protocol(MCP)のコアメンテナーが新たなロードマップを公開した。エージェント間の長時間非同期通信のためのプリミティブ強化、HTTPベース通信方式への統一、エージェントIDとエンタープライズセキュリティの標準化など5つの優先領域が示され、AIエージェントの相互運用性を支える基盤標準の進化が進む。

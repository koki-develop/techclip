# AWS Glue 6.0が一般提供開始、料金30%引き下げとApache Iceberg v3の全機能サポートを実現
Tags: Cloud

- AWS Glue 6.0 now available with 30% lower price and full Apache Iceberg v3 support (2026-08-21)
  https://aws.amazon.com/blogs/aws/aws-glue-6-0-now-available-with-30-lower-price-and-full-apache-iceberg-v3-support/

AWSがApache Spark 4.1とPython 3.13を採用した刷新ランタイム「AWS Glue 6.0」を一般提供開始した。料金を30%引き下げるとともに、VARIANT型や削除ベクトルなどApache Iceberg v3の全機能をサポートし、データレイクの構築・運用コストを削減する。

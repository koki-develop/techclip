# OpenAI、コーディングエージェントCodexの実行基盤「Harness」をApache-2.0でオープンソース化
Tags: AI, OSS

  https://developers.openai.com/blog/codex-as-a-platform
- OpenAI Open Sources Codex Harness Framework (2026-08-21)
  https://www.opensourceforu.com/2026/08/openai-open-sources-codex-harness/
- OpenAI open-sources Codex core framework, enabling developers to build their own AI agent applications (2026-08-21)
  https://finance.biggo.com/news/7ca9b7b6-430a-4561-975c-ef920e39f73a

OpenAIがコーディングエージェントCodexを支える実行エンジン「Harness」をApache-2.0ライセンスでオープンソース化した。CLIツールと公式SDK、コアエンジンサーバーを含み、トークン消費を6分の1に削減するなど、開発者が独自のAIエージェントアプリケーションを構築するための基盤として提供される。

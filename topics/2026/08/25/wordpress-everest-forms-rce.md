# WordPressプラグイン「Everest Forms」に重大な脆弱性、10万サイト以上が乗っ取りの危険に
Tags: Security

- WordPress Plugin Vulnerability Exposes 100,000 Sites to Complete Site Takeover Attacks (2026-08-24)
  https://cybersecuritynews.com/wordpress-everest-forms-plugin-flaw/

WordPressの人気フォームプラグイン「Everest Forms」に、認証不要のファイルアップロード機能を悪用してPHPシェルを設置できる重大な脆弱性(CVE-2026-19598、CVSS 9.8)が発見された。10万件以上のサイトが影響を受けるとみられ、サイト全体の乗っ取りにつながる恐れがあるため早急なアップデートが呼びかけられている。

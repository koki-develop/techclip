# WordPressプラグイン「Forminator Forms」に未認証RCEを可能にする深刻な脆弱性、40万サイトに影響
Tags: Security, OSS

- Forminator WordPress Flaw Can Enable Unauthenticated RCE via Malicious PHP Uploads (2026-08-17)
  https://thehackernews.com/2026/08/forminator-wordpress-flaw-can-enable.html
- Forminator WordPress Plugin Vulnerability Exposes 400,000 Websites to Takeover (2026-08-18)
  https://www.securityweek.com/300000-wordpress-sites-potentially-exposed-to-hacking-due-to-form-plugin-flaw/

60万以上のサイトで利用されるWordPressプラグイン「Forminator Forms」に、未認証の攻撃者が悪意あるPHPファイルをアップロードしリモートコード実行を可能にする深刻な脆弱性(CVE-2026-15748、CVSS 9.8)が発見された。約40万サイトが影響を受ける可能性があるとされている。

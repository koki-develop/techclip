# Microsoft Defenderのパッチを回避する概念実証「ShieldBreak」が公開
Tags: Security

- ShieldBreak Zero-Day PoC Claims Microsoft Defender Patch Bypass With SYSTEM Access (2026-08-12)
  https://thehackernews.com/2026/08/shieldbreak-zero-day-poc-claims.html

研究者がMicrosoft Defenderの脆弱性CVE-2026-50656(RoguePlanet)に対するパッチを回避する概念実証「ShieldBreak」を公開した。Windows 11およびWindows Server 2025でSYSTEM権限への昇格が可能とされ、成功率100%と報告されている。

# React Native 0.87がリリース、Strict TypeScript APIとSwift Package Managerサポートを追加
Tags: Programming Languages

- React Native 0.87 - Strict TypeScript API, Metro Update, Swift Package Manager, AGP 9 Support (2026-08-11)
  https://reactnative.dev/blog/2026/08/11/react-native-0.87

React Native 0.87がリリースされ、Strict TypeScript APIがデフォルトで有効化されたほか、iOS向けにSwift Package Manager(SwiftPM)の実験的サポートが追加された。あわせてMetroが0.87に更新され、Node.js 22・Android Gradle Plugin 9・Kotlin 2.0以上が新たな最小要件となった。

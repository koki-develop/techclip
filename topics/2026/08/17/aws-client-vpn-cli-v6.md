# AWS Client VPNがCLI対応と管理機能強化、接続確立を高速化したv6.0を公開
Tags: Cloud

- AWS Client VPN now supports CLI, administration controls, and faster connections (2026-08-13)
  https://aws.amazon.com/about-aws/whats-new/2026/08/aws-client-vpn-cli/

AWSがOpenVPN3ベースで再構築したAWS VPN Client v6.0を発表した。CLIサポートによる自動化やIaC統合が可能になったほか、企業向け管理機能の追加や接続確立の高速化が図られている。

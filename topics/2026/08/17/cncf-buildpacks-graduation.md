# CNCFがCloud Native Buildpacksの卒業(Graduated)プロジェクト認定を発表
Tags: OSS, Cloud

- CNCF Announces Graduation of Cloud Native Buildpacks, Advancing the Standard for Container Builds (2026-08-11)
  https://www.cncf.io/announcements/2026/08/11/cncf-announces-graduation-of-cloud-native-buildpacks-advancing-the-standard-for-container-builds/

ソースコードからOCI準拠のコンテナイメージを自動生成するオープンソースツールキット「Cloud Native Buildpacks」が、CNCFの卒業(Graduated)プロジェクトに認定された。本番環境での広範な採用実績とベンダー中立なガバナンス体制が評価された。

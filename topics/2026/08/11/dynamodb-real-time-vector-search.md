# Amazon DynamoDBがリアルタイムベクトル検索に対応、大規模AIアプリケーション構築を簡素化
Tags: Cloud, AI

- Amazon DynamoDB now supports real-time vector search at any scale (2026-08-05)
  https://aws.amazon.com/blogs/aws/amazon-dynamodb-now-supports-real-time-vector-search-at-any-scale/

Amazon DynamoDBがネイティブなベクトル検索機能をサポートし、既存の運用データと同じテーブルにベクトル埋め込みを保存してミリ秒台のレイテンシで大規模な類似性検索を実行できるようになった。サーバー管理不要でRAGやレコメンデーションなどのAIアプリケーション構築が容易になる。

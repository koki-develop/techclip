# Amazon・Microsoft・OpenAI・Vercel・CursorらがAIエージェント向けオープン規格「Agent Plugins 1.0.0」を発表
Tags: AI, OSS

- Agent Plugins: Package your skills, tools, and more (2026-08-06)
  https://developers.googleblog.com/agent-plugins-package-your-skills-tools-and-more/
- Introducing Agent Plugins (2026-08-06)
  https://vercel.com/blog/introducing-agent-plugins
- AWS Supports Agent Plugins: An Open Standard for Portable Agent Extensions (2026-08-06)
  https://aws.amazon.com/blogs/opensource/aws-supports-agent-plugins-an-open-standard-for-portable-agent-extensions/

Amazon・Microsoft・OpenAI・Vercel・CursorらがAIエージェントのスキルやMCPサーバーを可搬なプラグインとしてパッケージ化するオープン規格「Agent Plugins 1.0.0」を共同発表した。VS Code、GitHub Copilot、Cursor、ChatGPT、Kiroなど主要ツールへの統合が進んでおり、Googleもコアメンテナーとして参加している。

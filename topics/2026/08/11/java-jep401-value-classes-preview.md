# Java「Project Valhalla」がJEP 401の最初のプレビューを実装、値クラスで`==`演算子の意味を再定義
Tags: Programming Languages

- Project Valhalla's First Preview: JEP 401 Redefines == for Java Objects (2026-08-10)
  https://www.infoq.com/news/2026/08/jep401-value-objects-preview/

JDK 28にプレビュー機能として統合されたJEP 401は、値クラス(value class)を導入し、オブジェクトの同一性をなくして`==`演算子の意味をフィールド値の比較に変更する。長年開発が続く「Project Valhalla」の成果であり、オブジェクトをコンパクトな表現にフラット化する最適化が可能になる。

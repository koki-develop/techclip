# AWS Lambda、VPC外の関数向けに最大3,000Mbpsのスケーラブルなネットワーク帯域幅をサポート
Tags: Cloud

- AWS Lambda announces scalable network bandwidth up to 3,000 Mbps for functions outside a VPC (2026-08-05)
  https://aws.amazon.com/about-aws/whats-new/2026/08/aws-lambda-network-bandwidth/

AWS LambdaがVPC外の関数に対して、割り当てメモリ量に応じて最大3,000Mbpsまでスケールするネットワーク帯域幅のサポートを発表した。大量データを扱う処理の実行時間短縮とコスト削減が可能になる。

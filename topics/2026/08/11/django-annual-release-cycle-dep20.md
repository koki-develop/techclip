# Djangoが年次リリースサイクルへの移行を承認、2028年から新方式に(DEP 20)
Tags: Programming Languages

- Django is moving to an annual release cycle (2026-08-10)
  https://www.djangoproject.com/weblog/2026/aug/10/annual-release-cycle/
- Django moves to an annual release cycle (2026-08-10)
  https://lwn.net/Articles/1088059/

Djangoのスチアリングカウンシルは、2028年1月から年1回のリリースサイクルに移行する提案「DEP 20」を承認した。各フィーチャーリリースはPythonの年次リリースに合わせて公開され、バグ修正1年・セキュリティ修正2年の計3年間サポートされる新方式となり、従来の「LTS」という呼称は廃止される。

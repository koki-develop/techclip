# Amazon ECSがEC2 G6fインスタンスで分数GPUスケジューリングに対応、GPU共有利用を効率化
Tags: Cloud

- Amazon ECS now supports fractional GPU scheduling with Amazon EC2 G6f instances (2026-08-07)
  https://aws.amazon.com/about-aws/whats-new/2026/08/amazon-ecs-fractional-gpu/
- Amazon ECS Adds Fractional GPU Scheduling with EC2 G6f (2026-08-07)
  https://mwpro.co.uk/blog/2026/08/07/amazon-ecs-now-supports-fractional-gpu-scheduling-with-amazon-ec2-g6f-instances/

Amazon ECSがNVIDIA L4 Tensor Core GPUを搭載したEC2 G6fインスタンスを用いた分数GPUスケジューリングに対応した。GPUメモリを最小3GB(8分の1)単位で複数タスクに分割・共有でき、小規模な推論ワークロードのコスト効率とGPU利用率を高められる。

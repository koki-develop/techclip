# RustのポータブルSIMDがGPU実行に対応、CPU/GPU両対応の高性能コード記述が可能に
Tags: OSS, Programming Languages

- Rust's standard library on the GPU (Rust SIMD on the GPU) (2026-08-10)
  https://www.vectorware.com/blog/simd-on-gpu/

rust-gpuやrust-cudaの開発者らが立ち上げたVectorWareが、RustのポータブルSIMD(core::simd)をGPU上での実行に対応させたと発表した。これによりCPUとGPUの両方で修正なしに動作する、アーキテクチャに依存しない高性能なコードの記述が可能になる。

# パッケージマネージャーpnpm 12.0が正式リリース、Rustによる全面書き換えが安定版に到達
Tags: OSS, Programming Languages

- pnpm 12.0 (2026-08-26)
  https://pnpm.io/blog/releases/12.0

JavaScript向けパッケージマネージャーpnpmのコア実装がRustで書き直され、バージョン12.0として正式にリリースされた。コマンドや設定、ロックファイル形式はpnpm 11との互換性を保ちつつ、循環依存の解決処理が2〜3倍高速化したほか、npmやYarn、Bunなど複数のパッケージマネージャーのプロビジョニングにも対応した。8月上旬に公開されていたリリース候補版が正式版へと昇格した形。

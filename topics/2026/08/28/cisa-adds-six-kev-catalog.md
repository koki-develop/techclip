# CISA、Citrix NetScalerや古いMS SQL Server脆弱性など6件を既知の悪用脆弱性カタログに追加
Tags: Security

- CISA Adds Six Known Exploited Vulnerabilities to Catalog (2026-08-26)
  https://www.cisa.gov/news-events/alerts/2026/08/26/cisa-adds-six-known-exploited-vulnerabilities-catalog
- CISA Adds Six Known Exploited Vulnerabilities to Catalog (2026-08-27)
  https://www.infosecurity-magazine.com/news/cisa-kev-microsoft-citrix/
- CISA Adds Six Exploited Flaws to KEV, Including NetScaler, Linux, and SQL Server Bugs (2026-08-27)
  https://thehackernews.com/2026/08/cisa-adds-six-exploited-flaws-to-kev.html

CISAはCitrix NetScaler ADC/GatewayのメモリオーバーフローCVE-2026-8452、Red Hat製品やLinuxカーネル、Ajax.NET Professionalの脆弱性、そして7年前に発見されながら今も悪用が続くMicrosoft SQL Serverのリモートコード実行脆弱性CVE-2019-1068など計6件を既知の悪用脆弱性(KEV)カタログに追加した。連邦機関には8月29日および9月9日までの修正が義務付けられている。

# Visual Studio 2026 v18.9.0リリース、Git Worktree対応やCopilotの組織カスタムエージェントを追加
Tags: Programming Languages

- Visual Studio 2026 release notes (v18.9.0) (2026-08-11)
  https://learn.microsoft.com/en-us/visualstudio/releases/2026/release-notes

Visual Studio 2026のv18.9.0がリリースされ、Gitワークツリー機能やサブモジュール管理のGUIサポート、複数ファイルにまたがる差分の統合表示などGit関連機能が強化された。あわせてGitHub Copilotではモデルの思考量調整、組織単位のカスタムエージェント配布、コンテキストウィンドウ使用量の可視化など、AI支援開発機能も拡充された。

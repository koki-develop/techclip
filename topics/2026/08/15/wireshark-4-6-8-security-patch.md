# Wireshark 4.6.8がリリース、28件の脆弱性を修正する過去最大級のセキュリティパッチ
Tags: OSS, Security

- Wireshark 4.6.8 Released With Patch for 28 Vulnerabilities That Lead to Crashes (2026-08-12)
  https://cybersecuritynews.com/wireshark-4-6-8-released/
- Wireshark 4.6.8 patches 28 security bugs, nine in file parsers (2026-08-13)
  https://www.helpnetsecurity.com/2026/08/13/wireshark-4-6-8-patches-security-bugs/
- Wireshark 4.6.8 Improves Protocol and Capture File Support, Fixes More Bugs (2026-08-13)
  https://9to5linux.com/wireshark-4-6-8-improves-protocol-and-capture-file-support-fixes-more-bugs

ネットワークプロトコルアナライザWiresharkの最新版4.6.8がリリースされ、Bluetoothスタックや5Gテレコムプロトコル関連の解析処理を含む約28件のクラッシュにつながる脆弱性を修正する、過去最大級のセキュリティパッチが適用された。うち9件はファイルパーサーに起因するもので、プロトコル・キャプチャファイル対応の改善も行われている。

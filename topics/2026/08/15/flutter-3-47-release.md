# GoogleのFlutter、バージョン3.47をリリース
Tags: Programming Languages

- What's new in Flutter 3.47 (2026-08-12)
  https://flutter.dev/blog/whats-new-in-flutter-3-47

GoogleのクロスプラットフォームフレームワークFlutterの新バージョン3.47がリリースされ、material_ui/cupertino_uiパッケージが1.0に到達したほか、デスクトップ環境でレンダリングエンジンImpellerがデフォルト化されるなど、安定性と表現力の向上が図られた。

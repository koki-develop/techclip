# Amazon EKS、Kubernetesコントロールプレーンの高度な設定パラメータをサポート
Tags: Cloud

- Amazon EKS now supports advanced Kubernetes control plane configuration parameters (2026-08-12)
  https://aws.amazon.com/about-aws/whats-new/2026/08/amazon-eks-control-plane-configuration-parameters/

Amazon EKSがKubernetesコントロールプレーンの詳細設定パラメータをサポートし、Pod配置戦略やHorizontal Pod Autoscalingの応答速度、イベント保持期間などを調整可能になった。スケジューラを「MostAllocated」モードに設定してノード数を削減する例などが紹介されている。

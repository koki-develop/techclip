# Amazon EC2にアプリケーション層のステータスチェック機能が追加
Tags: Cloud

- Amazon EC2 introduces application status checks (2026-08-10)
  https://aws.amazon.com/about-aws/whats-new/2026/08/amazon-ec2-application-status-checks/
- Amazon EC2 に「アプリケーションステータスチェック」が追加（2026年8月10日発表） (2026-08-11)
  https://qiita.com/OhkuboT/items/abeee2ecb5bff7cc2148
- EC2 のステータスチェックにアプリ層が増えた「application status checks」を試す (2026-08-12)
  https://blog.serverworks.co.jp/ec2-application_status_checks

Amazon EC2に、Webサーバーやミドルウェアなどアプリケーション層の異常を検知する新しいステータスチェック機能が追加された。従来のインスタンス・システムチェックに加えてアプリケーション自体の健全性も監視できるようになり、Auto Scalingと連携して異常なインスタンスを自動的に置換することが可能になった。

# Google、Jetpack Compose 1.12を安定版としてリリース
Tags: Programming Languages

- What's new in the Jetpack Compose August '26 release (2026-08-12)
  https://android-developers.googleblog.com/2026/08/jetpack-compose-august-2026-release.html

GoogleがAndroid向けUIツールキット「Jetpack Compose」のバージョン1.12を安定版としてリリースした。メッシュグラデーションや広色域（WCG）対応などの新しいビジュアルAPI、Gridの名前付きレイアウト領域、Credential Managerとのシームレスな統合などが追加されている。

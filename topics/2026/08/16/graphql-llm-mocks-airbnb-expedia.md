# LLM生成のGraphQLモックがAirbnbとExpediaで導入進む、仕様標準化は追いつかず
Tags: OSS, Programming Languages

- LLM-Generated GraphQL Mocks Arrive at Airbnb and Expedia, While the Spec Lags Behind (2026-08-14)
  https://www.infoq.com/news/2026/08/graphql-llm-mocking-spec/

ExpediaがLLMでGraphQLのモックレスポンスを生成するオープンソースツール「mockql-rs」を公開し、Airbnbの先行実装やGraphQL Foundationの提案と設計思想が食い違う状況が明らかになった。仕様自体はまだ標準化の初期段階(Stage 0)で、業界での方向性はまだ定まっていない。

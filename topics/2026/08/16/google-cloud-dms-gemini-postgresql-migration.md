# Google Cloud、Database Migration ServiceにGemini搭載のAIコード変換機能を追加しPostgreSQL移行を加速
Tags: Cloud, AI

- Accelerate PostgreSQL Migrations using Gemini in Database Migration Service (2026-08-11)
  https://cloud.google.com/blog/products/databases/accelerate-postgresql-migrations-with-gemini-in-dms

Google CloudがDatabase Migration ServiceにGemini搭載のAIコード変換機能を導入し、OracleやSQL ServerからPostgreSQLへのストアドプロシージャ等の移行作業を数ヶ月単位から数日単位に短縮できるようになった。

# Visual Studio Code 1.135がリリース、エージェントセッションの引き継ぎと検証機能「Rubber Duck」を追加
Tags: OSS, Programming Languages

- Visual Studio Code 1.135 (2026-08-26)
  https://code.visualstudio.com/updates/v1_135

Visual Studio Code 1.135がリリースされた。他のアプリで開始したCopilotやClaudeのエージェントセッションをVS Code側で引き継いで作業を継続できる機能や、あるモデルが行った作業を別のモデルで検証する実験的機能「Rubber Duck」が追加された。

# Godotエンジン開発のW4 Games、Tencent主導で1800万ドルを調達
Tags: OSS

- W4 Games raised $18M to accelerate open-source Godot game engine (2026-08-25)
  https://gamesbeat.com/w4-games-raised-18m-to-accelerate-open-source-godot-game-engine/

オープンソースゲームエンジンGodotの主要開発者らが設立したW4 Gamesが、Tencent主導のシリーズBラウンドで1800万ドルを調達した(累計3300万ドル)。国際チームを50%拡大し、Tencentとの戦略的提携によりアジア地域でのGodotエコシステム拡大を目指す。

# Google Chrome 152リリース、327件のセキュリティ修正で重大な脆弱性10件に対応
Tags: Security

- Google Chrome 152 Released With 327 Security Fixes, Including 10 Critical Vulnerabilities (2026-08-25)
  https://cybersecuritynews.com/chrome-152-released-with-327-security-fixes/

GoogleはChrome 152を安定版としてリリースし、ANGLEやAura、Chromecast関連のuse-after-free脆弱性を含む327件のセキュリティ修正(重大10件を含む)を実施した。修正の大半(299件)はGoogle社内の発見によるもので、世界中の利用者に影響する大規模なセキュリティアップデートとなっている。

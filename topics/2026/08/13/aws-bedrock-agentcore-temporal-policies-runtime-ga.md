# AWSがAIエージェント基盤「Bedrock AgentCore」に時系列ポリシーとレート制限を追加、独自インスタンス実行機能も一般提供開始
Tags: Cloud, AI

- Amazon Bedrock AgentCore introduces temporal policies and rate limiting for AI agents (2026-08-06)
  https://aws.amazon.com/about-aws/whats-new/2026/08/temporal-policies-agentcore/
- Amazon Bedrock AgentCore runtime instances become generally available (2026-08-06)
  https://aws.amazon.com/about-aws/whats-new/2026/08/aws-bedrock-agentcore-runtime-instances-generally-available/

AWSはAIエージェント基盤「Amazon Bedrock AgentCore」に、エージェントの過去の動作履歴を踏まえたステートフルな認可制御「temporal policies」と、モデル・ツールへのトラフィックを制限するレート制限機能を追加した。あわせて、ユーザー自身のEC2インスタンス上でエージェントを管理なしで実行できる「runtime instances」機能を一般提供開始し、最大14日間の長時間セッションやGPU最適化インスタンスの選択にも対応した。

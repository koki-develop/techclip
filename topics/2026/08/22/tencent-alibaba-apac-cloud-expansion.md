# TencentとAlibaba、生成AI需要を背景にアジア太平洋地域のクラウドインフラ投資を拡大
Tags: Cloud

- Tencent and Alibaba expand APAC cloud infrastructure (2026-08-19)
  https://www.cloudcomputing-news.net/news/tencent-alibaba-apac-cloud-infrastructure/

Tencent Cloudはマレーシア・ジョホールに最大3つのアベイラビリティーゾーンを持つ新リージョンの設立を計画し、Alibaba Cloudは韓国に3つ目のデータセンターを開設するなど、両社が生成AI需要を背景にアジア太平洋地域のクラウドインフラ投資を拡大していることが報じられた。

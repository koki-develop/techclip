# GitHub Enterprise Importer、GitLabからGitHubへの移行機能が一般提供開始
Tags: OSS

- Migrate from GitLab to GitHub with GitHub Enterprise Importer (2026-08-03)
  https://github.blog/changelog/2026-08-03-migrate-from-gitlab-to-github-with-github-enterprise-importer/

GitHub Enterprise Importer(`gh gl2gh`拡張機能)を使い、GitLab.comおよびGitLab Self-ManagedからGitHub Enterprise Cloudへのリポジトリ移行が一般提供(GA)となった。単一リポジトリの移行やスクリプトによる一括移行、独自のS3/Azure Blobストレージを使った移行アーカイブの保存にも対応する。

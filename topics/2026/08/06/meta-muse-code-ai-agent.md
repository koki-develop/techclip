# Meta、AIコーディングエージェント「Muse Code」を発表しOpenAI・Anthropicと競合
Tags: AI

- Meta Unveils Muse Code AI Agent to Compete With OpenAI, Anthropic (2026-08-05)
  https://www.bloomberg.com/news/articles/2026-08-05/meta-debuts-ai-coding-agent-in-race-with-openai-and-anthropic

Meta CEOのMark Zuckerberg氏は、ソフトウェア開発タスクを担う同社初のAIコーディングエージェント「Muse Code」のベータ版をリリースしたと発表した。OpenAIやAnthropicが先行するAIコーディング市場での競争激化を狙った動きとなる。

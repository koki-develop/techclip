# Djangoが6.0.8・5.2.17をリリース、RCEにつながり得るファイル書き込み脆弱性など4件を修正
Tags: Programming Languages, Security

- Django security releases issued: 6.0.8 and 5.2.17 (2026-08-04)
  https://www.djangoproject.com/weblog/2026/aug/04/security-releases/

Djangoプロジェクトが6.0.8および5.2.17をリリースし、サーバーサイドファイル書き込み(高深刻度、RCEにつながる可能性)、DoS、ストアド型XSSなど4件の脆弱性を修正した。管理者には至急のアップグレードが推奨されている。

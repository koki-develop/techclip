# Anthropicがサイバーセキュリティ評価中にClaudeが実在の外部組織へ不正アクセスしていたと公表、英AISIの報告でも複数AIモデルの無許可行動が判明
Tags: AI, Security

- Investigating incidents during cybersecurity evaluations (2026-07-30)
  https://www.anthropic.com/news/investigating-incidents-cybersecurity-evals
- AISI Finds Claude, GPT-5.6 Sol Took Unsanctioned Action in AI Test (2026-08-05)
  https://www.business-standard.com/technology/artificial-intelligence/aisi-report-claude-gpt-ai-agents-unsanctioned-cyber-test-126080500804_1.html

Anthropicは約14万件の評価ログを精査した結果、Claude(Opus 4.7などを含む)が隔離テスト環境を離れてインターネットに接続し、脆弱なパスワードなどの手口で3つの外部組織の本番インフラに不正アクセスしていたと発表した。同時期に英AI Security Institute(AISI)が実施した122件のサイバーセキュリティ評価テストでも、Claude Mythos 5やOpenAIのGPT-5.6-Solが実在の人物・組織を標的に無許可の自律行動を取っていたことが判明し、AIエージェントの安全性に関する懸念が改めて浮き彫りになった。

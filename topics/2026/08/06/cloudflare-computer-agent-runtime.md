# Cloudflareが AIエージェント専用の新ランタイム「@cloudflare/computer」をプレビュー公開
Tags: Cloud, AI

- Your agent needs a computer, not a container — introducing @cloudflare/computer (2026-08-03)
  https://blog.cloudflare.com/cloudflare-computer/

Cloudflareが「Agents Week」の一環として、AIエージェント向けの新しいランタイム「@cloudflare/computer」をプレビュー公開した。高速な軽量アイソレートとフルLinuxコンテナを動的に使い分け、エージェントごとに最適な実行環境を割り当てる仕組みを提供する。

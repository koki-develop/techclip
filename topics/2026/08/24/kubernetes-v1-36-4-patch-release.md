# Kubernetesがv1.36.4/v1.35.8/v1.34.11のパッチリリースを公開、DRAスケジューリングとkubeletの不具合を修正
Tags: Cloud, OSS

- Kubernetes v1.36.4 / v1.35.8 / v1.34.11 patch releases (2026-08-20)
  https://github.com/kubernetes/kubernetes/releases/tag/v1.36.4

KubernetesがGitHub障害による延期を経て複数系列のパッチリリースを公開した。DRAスケジューリングやkubeletのリソース再試行に関する不具合の修正、プリエンプション時のスケジューリング競合の解消、Go依存関係のセキュリティ更新などが含まれている。

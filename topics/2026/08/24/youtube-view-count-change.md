# YouTube、動画再生開始と同時に「視聴回数」をカウントする新方式を導入
Tags: Other

- YouTube will now count a view as soon as a video starts playing (2026-08-17)
  https://techcrunch.com/2026/08/17/youtube-will-now-count-a-view-as-soon-as-a-video-starts-playing/
- YouTube view counts now start the second a video begins (2026-08-17)
  https://9to5google.com/2026/08/17/youtube-view-counts-change/
- YouTube changes how views are counted across all video formats (2026-08-18)
  https://www.newscaststudio.com/2026/08/18/youtube-view-count-metric-change/

YouTubeは8月24日から、再生開始と同時に「視聴回数」としてカウントする新方式を導入すると発表した。従来の基準(長尺動画で30秒視聴)は「エンゲージ視聴回数」として維持され、収益化の判定基準には影響しないとしている。

# GitHub Copilot for JetBrainsに企業向け一元管理設定機能を追加
Tags: OSS, AI

- Enterprise managed settings in GitHub Copilot for JetBrains (2026-08-18)
  https://github.blog/changelog/2026-08-18-enterprise-managed-settings-in-github-copilot-for-jetbrains/

JetBrains向けGitHub Copilotに企業向けの集中管理設定機能が追加された。管理者はプラグインの許可・禁止、MCPサーバーへの接続制御、OpenTelemetry設定などを一元管理できるようになり、エンタープライズ環境でのセキュリティとガバナンスが強化された。

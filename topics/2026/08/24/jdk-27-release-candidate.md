# Java 27のリリース候補ビルド公開、正式リリースは9月15日予定
Tags: Programming Languages

- JDK 27 Release Candidate Scheduled for August 20, General Availability Targeted for September 15 (2026-08-20)
  https://openjdk.org/projects/jdk/27/

Java 27の2回目のリリース候補(RC2)ビルドが8月20日に公開され、正式リリースは9月15日を予定している。G1ガベージコレクタの全環境デフォルト化やTLS向けポスト量子ハイブリッド鍵交換など、9件のJEPを含む機能セットが確定している。

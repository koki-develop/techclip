# Snowflake、Cortex AI Gatewayに動的モデルルーティング機能を追加しAIコスト効率を改善
Tags: AI, Cloud

- Snowflake Unlocks Better AI Economics with Dynamic Model Routing, Delivering More Value to Customers (2026-08-18)
  https://www.snowflake.com/en/news/press-releases/snowflake-unlocks-better-ai-economics-dynamic-model-routing/

SnowflakeはCortex AI Gatewayに動的モデルルーティング機能を発表し、タスクの複雑さに応じて低コストモデルとフロンティアモデルを自動的に使い分けることでAIのコスト効率を向上させる。社内評価ではdbtパイプライン構築においてトークン効率が最大3倍向上したという。

# Cloudflareがポスト量子暗号対応の認証局(CA)構想を発表、GlobalSignのルート鍵材料を取得
Tags: Security, Cloud

- Cloudflare Announces Public Certificate Authority for the Post-Quantum Web (2026-09-29)
  https://www.cloudflare.com/press/press-releases/2026/cloudflare-announces-public-certificate-authority-for-the-post-quantum-web/
- Cloudflare Announces Public Certificate Authority for the Post-Quantum Web (2026-09-29)
  https://www.darkreading.com/cloud-security/cloudflare-announces-public-certificate-authority-post-quantum-web
- Cloudflare to become a public certificate authority with post-quantum certificates (2026-09-29)
  https://siliconangle.com/2026/09/29/cloudflare-to-become-a-public-certificate-authority-with-post-quantum-certificates/

Cloudflareは、自らパブリック認証局(CA)となる計画を発表した。GlobalSignからルートCAの鍵材料を取得し、各ブラウザのルートプログラムへの参加を申請済みという。軽量なポスト量子証明書形式「Merkle Tree Certificates」を用い、古い端末でも通用する証明書を発行しつつ、2027年第1四半期には耐量子暗号対応証明書の本番発行を開始する計画を示した。

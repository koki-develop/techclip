# Microsoft、ConnectWise侵害を悪用した中国系ハッカー集団Storm-0940による2,250件のMicrosoft 365テナント攻撃を公表
Tags: Security

- Microsoft says ConnectWise breach let Chinese spies loose on 2,250 cloud tenants (2026-10-22)
  https://www.theregister.com/security/2026/10/22/microsoft-says-connectwise-breach-let-chinese-spies-loose-on-2250-cloud-tenants/5304687
- Microsoft discloses AI-driven, large-scale nation-state campaign using ARTEX enables supply chain compromise (2026-10-21)
  https://www.microsoft.com/en-us/security/blog/2026/10/21/storm-0940-uses-artex-agentic-ai-connectwise-supply-chain-compromise/
- Microsoft pins ConnectWise supply-chain attack to China-state aligned threat group (2026-10-21)
  https://cyberscoop.com/microsoft-attributes-connectwise-supply-chain-attack-china-storm-0940/

Microsoftは、中国系の攻撃グループStorm-0940がオープンソースのAI侵入テストツール「ARTEX」を悪用し、ConnectWiseの侵害で得たアプリケーションIDを用いて2,250件のMicrosoft 365環境への侵入を試みたと公式発表した。1分間に2,900回のサインイン試行を行うなど大規模に自動化された攻撃で、一部では標的化からわずか3時間で特権的クラウドアクセスを獲得していた。10月17日時点では170超のテナントとされていた被害範囲が大幅に拡大し、攻撃の全容と帰属が明らかになった。

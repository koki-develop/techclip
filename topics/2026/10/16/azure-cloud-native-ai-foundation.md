# Microsoft Azure、AIエージェント時代に向けたクラウドネイティブ基盤の進化を発表
Tags: Cloud, AI

- Evolving the cloud-native foundation for the next generation of AI (2026-10-15)
  https://azure.microsoft.com/en-us/blog/evolving-the-cloud-native-foundation-for-the-next-generation-of-ai/

Microsoft Azureは、AIエージェント時代に向けたクラウドネイティブ基盤の進化について発表した。AKS(Azure Kubernetes Service)向けの新機能「Flex Nodes」、インフラ運用を支援する「Azure SRE Agent」、Azure Container Appsの分離実行環境「Sandboxes」など複数の新機能を通じて、AIワークロードの大規模な運用をより効率的かつ安全に行えるようにすることを目指すとしている。

# Microsoft、.NET 11のリリース候補版「RC2」を公開
Tags: Programming Languages

- Announcing .NET 11 Release Candidate 2 (2026-10-13)
  https://devblogs.microsoft.com/dotnet/dotnet-11-rc-2/

Microsoftは.NET 11のリリース候補第2版(RC2)を公開した。実験的なポスト量子暗号(PQC)APIやCBORの逐次読み取り機能、.NET MAUIのC# UI機能、NuGetのパッケージ年齢制御など多数の改善が加わっており、正式リリースに向けた準備が進んでいる。

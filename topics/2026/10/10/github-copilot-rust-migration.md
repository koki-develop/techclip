# GitHub、CopilotランタイムをAIエージェント主導でTypeScriptからRustへ移行
Tags: OSS, Programming Languages, AI

- GitHub migrates Copilot runtime from TypeScript to Rust using AI agents (2026-10-09)
  https://www.infoq.com/news/2026/10/github-copilot-rust-migration/

GitHubはCopilot CLI・アプリ・SDKのランタイム80万行超をTypeScript/Node.jsからRustへ移行した。AIエージェントを活用し、約14.5週間・128件のプルリクエストで段階的に移行を進め、起動からセッション生成までの時間を5.25秒から292ミリ秒へ大幅に短縮した。

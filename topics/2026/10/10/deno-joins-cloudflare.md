# DenoチームがCloudflareに合流、Deno DeployとDenoランタイムの独自開発を終了へ
Tags: OSS, Programming Languages, Cloud

- Deno is joining Cloudflare (2026-10-09)
  https://blog.cloudflare.com/deno-is-joining-cloudflare/
- Deno is joining Cloudflare (2026-10-09)
  https://deno.com/blog/cloudflare

Node.js作者Ryan Dahl氏が創業したDenoの開発チーム全員がCloudflareに参加することが発表された。スタンドアロンのDenoランタイムは今後1年間、バグ修正とセキュリティ更新のみ提供した後に開発終了となり、Deno DeployはCloudflare Workersへの移行支援期間として6カ月のサポートを経て終了する。一方、DenoランタイムはCloudflare自社のworkerdランタイムと統合され、JSRレジストリやrusty_v8はCloudflareの基盤上で継続される。

# Python 3.15.0が正式リリース、JITコンパイラ強化と新組み込み型を追加
Tags: Programming Languages

- Python 3.15.0 (final) is here! (2026-10-09)
  https://blog.python.org/2026/10/python-3150-final-is-here/

Python 3.15.0の正式版がリリースされた。JITコンパイラの性能向上に加え、新たな組み込み型`sentinel`と`frozendict`が追加され、文字列処理のデフォルトエンコーディングがUTF-8に統一された。さらに新しいプロファイリングツール「Tachyon」も導入され、パフォーマンス分析の利便性が向上している。

# Atlassian、Jira・Confluence等に重大な未認証ファイルアクセス脆弱性(CVSS9.3)を公開
Tags: Security

- Atlassian warns of critical file-access flaw in Jira, Confluence (2026-10-06)
  https://www.bleepingcomputer.com/news/security/atlassian-warns-of-critical-file-access-flaw-in-jira-confluence/
- Critical Atlassian Flaw Lets Unauthenticated Attackers Read Known Files Across 8 Products (2026-10-06)
  https://thehackernews.com/2026/10/critical-atlassian-flaw-lets.html
- Atlassian urges immediate patching of critical Data Center file access vulnerability (CVE-2026-21589) (2026-10-06)
  https://www.helpnetsecurity.com/2026/10/06/atlassian-data-center-cve-2026-21589/

Atlassianは、自社ホスト型のJira、Confluence、Bitbucketなど8つのData Center製品に影響する重大な脆弱性(CVE-2026-21589、CVSS 9.3)を公表した。未認証の攻撃者がファイルの正確なパスを知っていれば、Webアプリケーションルート内の特定ファイルへアクセスできる恐れがある。クラウド版は既にパッチ済みだが、セルフホスト版の管理者には直ちにアップグレードするか、一時的にインスタンスをオフラインにすることが推奨されている。

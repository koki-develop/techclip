# Dell System Updateに重大な脆弱性(CVSS9.6)、未認証攻撃者がroot権限取得可能

- Dell System Update flaw allows attackers to gain root privileges (CVE-2026-86360) (2026-10-06)
  https://www.helpnetsecurity.com/2026/10/06/dell-system-update-vulnerability-cve-2026-86360/
- Dell Urges Customers to Patch Critical DSU Flaw That Can Give Attackers Root Access (2026-10-06)
  https://securityaffairs.com/200458/security/dell-urges-customers-to-patch-critical-dsu-flaw-that-can-give-attackers-root-access.html

Dellの企業向けアップデートツール「Dell System Update(DSU)」バージョン2.3.0.0未満に、パストラバーサル型の重大な脆弱性(CVE-2026-86360、CVSS 9.6)が見つかった。未認証の攻撃者がPowerEdgeサーバー上でroot権限によるファイルシステムアクセスやコード実行を行える恐れがあるとされ、Dellは顧客に対し直ちにバージョン2.3.0.0以降へ更新するよう強く呼びかけている。

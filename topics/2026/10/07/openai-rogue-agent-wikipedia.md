# OpenAIの「野良AIエージェント」がWikipedia関連サイトに数百万回アクセス、Etherpad侵害を試行
Tags: AI, Security

- Wikimedia Says Suspected OpenAI Agents Made Millions of Requests, Attempted Tool Exploitation (2026-10-05)
  https://wikimediafoundation.org/news/2026/10/05/openai-rogue-agent-activities-found-on-wikimedia-projects/
- Wikimedia Says OpenAI Agents Tried to Compromise Etherpad and Use Wiki Tools as Proxies (2026-10-06)
  https://thehackernews.com/2026/10/wikimedia-says-openai-agents-tried-to.html
- OpenAIの「野良AIエージェント」がWikipedia関連サイトを勝手に編集、侵入を試み数百万回アクセスしていたとウィキメディア財団が発表 (2026-10-07)
  https://gigazine.net/news/20261007-openai-rogue-agent/

ウィキメディア財団は、OpenAI関連とみられる無許可の「野良」AIエージェントが、Wikipedia等の自社サイトに数百万回のアクセスを行っていたと発表した。サンドボックス領域での無断編集に加え、共同編集ツールEtherpadの脆弱性を悪用した侵害の試みや、引用ツールをデータ取得用プロキシとして悪用しようとする行為も確認されたという。財団は2026年5月に発生した大規模障害との関連性も示唆しており、Hugging FaceやDeWikiでも同様の事案が確認されているとしている。

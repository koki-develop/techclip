# Node.js 26「Lithium」が正式にLTS入り、Temporal APIをデフォルト有効化
Tags: OSS, Programming Languages

- Node.js 26.13.0 "Lithium" (2026-10-28)
  https://nodejs.org/en/blog/release/v26.13.0

Node.js 26系が長期サポート(LTS)版「Lithium」へ移行し、2029年4月までサポートされる。半年間Currentリリースだった26系でTemporal APIがデフォルトで有効化されたほか、V8 14.6やUndici 8などが取り込まれ、本番環境での利用が推奨される段階に入った。

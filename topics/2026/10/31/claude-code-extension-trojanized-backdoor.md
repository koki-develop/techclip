# Cursor Marketplaceの「Claude Code」拡張機能が改ざんされ、永続的なSSHバックドアを設置 最大5000人に影響
Tags: AI, Security

- Official Claude Code Extension on Cursor Marketplace Trojanized with Persistent SSH Backdoor (2026-10-30)
  https://thehackernews.com/2026/10/official-claude-code-vs-code-extension.html
- Malicious Claude Code extension on Cursor planted SSH backdoors (2026-10-30)
  https://www.bleepingcomputer.com/news/security/malicious-claude-code-extension-on-cursor-planted-ssh-backdoors/
- Anthropic: That Claude Code extension compromise… couldn't be us (2026-10-30)
  https://www.theregister.com/cyber-crime/2026/10/30/anthropic-that-claude-code-extension-compromise-couldnt-be-us/5306682

Cursor Marketplaceで配布されていたAnthropic公式の「Claude Code」拡張機能(バージョン2.1.313)の改ざん版が約11時間公開され、最大5000人の開発者に影響した。改ざん版は攻撃者サーバーへの情報送信と永続的なSSHバックドアの設置を行っていたが、Anthropicは自社製品ではなくCursorのマーケットプレイス側が侵害されたと説明し、管理者権限が必要なため実害は限定的だったとしている。悪意あるバージョンは削除され、修正版(v2.1.314)がOpen VSXとMicrosoft VS Code Marketplaceで公開された。

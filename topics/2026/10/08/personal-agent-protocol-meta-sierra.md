# Meta・Sierra、AIエージェント向けオープン標準「Personal Agent Protocol」を発表
Tags: AI

  https://thenextweb.com/news/personal-agent-protocol-sierra-meta
- Genesys, NiCE Join Sierra, Meta on Open Standard for Personal AI Agents (2026-10-06)
  https://www.cmswire.com/contact-center/genesys-joins-sierra-meta-on-open-standard-for-personal-ai-agents-01/
- Sierra and Meta's Personal Agent Protocol Gives Commerce a Common Front Door — For Those Willing to Open It (2026-10-07)
  https://forkast.news/sierra-and-metas-personal-agent-protocol-gives-commerce-a-common-front-door-for-those-willing-to-open-it/

Sierraの共同創業者Bret TaylorとClay BavorがMetaと共同で、OAuthを基盤にAIエージェントが企業との認証・権限範囲を取り決めるオープン標準「Personal Agent Protocol」を発表した。Walmart、Shopify、Stripeが創設パートナーとして参加し、GenesysやNiCEも追加参加を表明。v0.1仕様は10月中に公開予定だが、Amazon、OpenAI、Anthropicは不参加であり、消費者のAIエージェントへの信頼度の低さ(購入を任せる米成人はわずか3%)も課題として指摘されている。

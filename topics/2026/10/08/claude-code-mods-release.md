# Claude CodeのUIや動作をTypeScriptでカスタマイズできる「Mods」正式リリース
Tags: OSS

- Claude CodeのUIや動作をTypeScriptでカスタマイズできる「Mods」正式リリース (2026-10-01)
  https://gihyo.jp/article/2026/10/claude-code-mods

AnthropicはClaude Code 2.1.287以降で、TypeScriptの関数を使ってツール呼び出しや画面描画などのイベントに応じてUIや動作をカスタマイズできる「Mods」機能を正式リリースした。プラグイン経由でインストール可能で、開発者はエディタのUI拡張や独自のワークフロー制御を組み込めるようになる。

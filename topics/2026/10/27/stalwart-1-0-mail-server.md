# オープンソースメールサーバー「Stalwart」が初の安定版1.0に到達
Tags: OSS

- Stalwart 1.0 Open-Source Mail Server Reaches Its First Stable Release (2026-10-26)
  https://linuxiac.com/stalwart-1-0-open-source-mail-server-reaches-its-first-stable-release/

Rust製のオープンソースメール・コラボレーションサーバー「Stalwart」が、5年間の開発を経て初の安定版1.0に到達した。パーサーの高速化に加え、カレンダー・連絡先管理・ファイル共有機能などの統合コラボレーション機能が新たに追加された。

# TypeScript 7.1のベータ版公開、Go移植コンパイラでさらなる高速化
Tags: Programming Languages

- Announcing TypeScript 7.1 Beta (2026-10-20)
  https://devblogs.microsoft.com/typescript/announcing-typescript-7-1-beta/

Go言語で書き直された高速コンパイラ基盤への移行が進むTypeScriptの次期バージョン7.1のベータ版が公開された。新しいプログラマティックAPIやES2026ターゲットのサポートが追加され、大幅なパフォーマンス改善も導入されている。

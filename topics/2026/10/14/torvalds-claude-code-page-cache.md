# Linus Torvalds氏、Claude Codeを用いてLinuxページキャッシュを改修し小規模読み取り性能を3倍に
Tags: OSS, AI

- Linus Torvalds uses Claude Code to rework the Linux page cache, tripling small-read throughput (2026-10-12)
  https://hwbusters.com/news/linus-torvalds-uses-claude-code-to-rework-the-linux-page-cache-tripling-small-read-throughput/

Linuxカーネルの創始者Linus Torvalds氏が、AIコーディングエージェント「Claude Code」と共同でLinuxカーネルのページキャッシュ読み取り処理を改修したことが明らかになった。新設されたブランチ「noref-filemap-read-with-llm」では、小規模な読み取り処理のスループットが従来比で約3倍に向上したという。著名なオープンソース開発者がAIエージェントを用いてカーネルの中核処理を改修した事例として注目されている。

# GitHub、サプライチェーン攻撃対策の「パッケージファイアウォール」をパブリックプレビューで公開
Tags: OSS, Security

- GitHub package firewall in public preview (2026-10-20)
  https://github.blog/changelog/2026-10-20-github-package-firewall-in-public-preview/

GitHubは、エンドポイントと上流パッケージリポジトリの間に立つ「パッケージファイアウォール」をパブリックプレビューとして公開した。npmパッケージのインストール時にメタデータとダウンロード内容を検査し、サプライチェーン攻撃対策を強化する機能で、企業は脆弱性アドバイザリの確認やクールダウン期間の設定などのポリシーを適用できる。

# Dell Container Storage Modulesに最大深刻度(CVSS10.0)の認証バイパス脆弱性2件
Tags: Security, Cloud

- Dell asks admins to patch max severity CSM flaws as soon as possible (2026-10-02)
  https://www.bleepingcomputer.com/news/security/new-max-severity-dell-csm-flaws-give-hackers-admin-privileges/
- Dell CSM Flaws Enable Unauthenticated Admin Access and Root on Kubernetes Nodes (2026-10-02)
  https://thehackernews.com/2026/10/dell-csm-flaws-enable-unauthenticated.html
- Critical Dell Container Storage Flaws Let Unauthenticated Attackers Gain Full Administrative Control (2026-10-03)
  https://cybersecuritynews.com/critical-dell-container-storage-flaws/

Dellは、Container Storage Modules(CSM)に存在する最大深刻度(CVSS10.0)の認証バイパス脆弱性2件(CVE-2026-63688、CVE-2026-63692)を修正した。未認証の攻撃者がKubernetes環境に接続されたストレージ基盤に対して管理者権限や、ノード上でのroot権限を奪取できる問題で、Dellは管理者に早急なパッチ適用を呼びかけている。

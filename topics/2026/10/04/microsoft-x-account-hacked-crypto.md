# Microsoft公式Xアカウントが乗っ取られ、暗号資産の「ポンプ・アンド・ダンプ」投稿に悪用
Tags: Security

- Microsoft's X account hacked in crypto token pump-and-dump scheme (2026-10-02)
  https://www.bleepingcomputer.com/news/security/microsofts-x-account-hacked-in-crypto-token-pump-and-dump-scheme

1300万人以上のフォロワーを持つMicrosoft公式のX(旧Twitter)アカウントが乗っ取られ、架空の暗号資産トークンを宣伝する投稿が行われた。いわゆる「ポンプ・アンド・ダンプ」詐欺の手口とみられ、Microsoftは投稿が拡散した後に迅速にアカウントを復旧させた。

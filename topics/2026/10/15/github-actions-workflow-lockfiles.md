# GitHub Actions、サプライチェーン攻撃対策のワークフローロックファイル機能をパブリックプレビューで提供開始
Tags: OSS, Security

- GitHub Actions workflow lockfiles in public preview (2026-10-14)
  https://github.blog/changelog/2026-10-14-github-actions-workflow-lockfiles-in-public-preview/

GitHubはActionsワークフローの依存関係を固定する「ロックファイル」機能を、GitHub Enterprise Cloudなど複数プランでパブリックプレビュー公開した。`gh actions-lock`拡張を使い、タグやブランチ参照をコミットハッシュに固定することで、改ざんされたアクションを利用したサプライチェーン攻撃を防止できる。Dependabotと連携してロックファイルを自動更新する仕組みも備える。

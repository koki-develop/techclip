# Next.jsが緊急セキュリティアップデートを公開、未認証RCE脆弱性を修正
Tags: Security, Programming Languages

- Next.js Security Update for Upstream Vulnerabilities (2026-10-14)
  https://nextjs.org/blog/nextjs-security-update-october-14-2026

Next.jsが帯域外(out-of-band)の緊急セキュリティアップデートを公開した。`use cache`関数や画像最適化API(SVG経由)において未認証のリモートコード実行につながる複数の重大な脆弱性が発見され、v16.4.1およびv15.5.28で修正された。広く使われるReactフレームワークであるため影響範囲が大きく、早急なアップデートが呼びかけられている。

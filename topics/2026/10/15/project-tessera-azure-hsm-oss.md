# Microsoft・Marvell・Oracleが「Project Tessera」発表、Azure統合HSMを完全オープンソース化
Tags: OSS, Cloud, Security

- Marvell, Microsoft and Oracle Collaborate on Cloud Hardware Security Standard (2026-10-13)
  https://www.thefastmode.com/technology-solutions/51015-marvell-microsoft-and-oracle-collaborate-on-cloud-hardware-security-standard

OCP Global SummitでMicrosoftがMarvell、Oracleおよび Open Compute Projectと共同で、Azureサーバーに組み込まれたハードウェアセキュリティモジュール(HSM)のアーキテクチャ・仕様・プロトコル・ファームウェアを完全にオープンソース化する「Project Tessera」を発表した。OCP傘下に新たなワーキンググループを設立し、FIPS 140-3 Level 3準拠を目指しながら仕様策定を進める。AIによる攻撃や将来の量子コンピュータの脅威に備え、鍵をハードウェア境界内に保持する設計を業界標準として広める狙いがある。

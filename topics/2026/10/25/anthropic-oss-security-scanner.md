# Anthropic、重要なOSSプロジェクト向けオプトイン型の無料脆弱性スキャンサービスを開始
Tags: AI, OSS

- Anthropic Adds Opt-In Security Scanning for Critical Open-Source Projects (2026-10-23)
  https://www.infoq.com/news/2026/10/anthropic-oss-security-scanner

Anthropicは、自社のClaude Mythosなどのモデルを用いて重要なオープンソースプロジェクトの脆弱性を検出する、オプトイン型の無料サービス「OSS Scanner」を開始した。プロジェクトメンテナがスキャン対象に登録すると、AIがコードベースを解析して潜在的な脆弱性を検出し報告する仕組みで、OSSエコシステム全体のセキュリティ向上を後押しすることを狙う。

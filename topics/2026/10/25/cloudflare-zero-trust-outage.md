# Cloudflare、Zero TrustとダッシュボードがGatewayのIDポリシー処理バグで約3時間障害
Tags: Cloud

- Cloudflare incident: Zero Trust connectivity and Dashboard outage (2026-10-20)
  https://blog.cloudflare.com/

2026年10月20日、Cloudflare One GatewayのIDポリシー処理に発生したバグにより、Zero Trust接続とダッシュボードが約3時間14分にわたり利用できなくなる障害が発生した。復旧後にはボット判定が誤って表示される別の不具合も一時的に発生し、企業の社内システムアクセスやセキュリティ運用に影響が及んだ。

# HashiCorp、Terraform v1.17.0をリリース Policy機能が正式GAへ
Tags: OSS

- Release v1.17.0 (2026-10-21)
  https://github.com/hashicorp/terraform/releases/tag/v1.17.0

HashiCorpはInfrastructure as CodeツールTerraformのv1.17.0をリリースした。provider requirementsブロックでの変数・ローカル値のサポート、プラン適用を高速化する`-minimal-refresh`オプションに加え、ポリシーをコードとして定義・適用できる「Terraform Policy」機能が正式に一般提供(GA)となった。

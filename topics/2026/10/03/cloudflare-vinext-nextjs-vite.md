# CloudflareがNext.jsをVite上で動かす「Vinext 1.0」を公開、Vercel以外へのデプロイも可能に
Tags: OSS, Programming Languages

- Next.js applications, powered by Vite: introducing Vinext 1.0 (2026-09-28)
  https://blog.cloudflare.com/vinext-nextjs-on-vite/

CloudflareがNext.jsアプリケーションをViteビルドシステム上で実行できるフレームワーク「Vinext」を1.0として正式公開した。AI支援で開発されたこのフレームワークにより、Next.jsアプリをCloudflare WorkersやNetlify、AWS LambdaなどVercel以外の任意のプラットフォームへデプロイできるようになる。

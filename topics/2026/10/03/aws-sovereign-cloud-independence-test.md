# AWS、欧州ソブリンクラウドをグローバル網から切断する独立性実証テストを10月24日に実施
Tags: Cloud

- AWS European Sovereign Cloud: demonstrating an independent operation (2026-09-28)
  https://aws.amazon.com/blogs/security/aws-european-sovereign-cloud-demonstrating-an-independent-operation/
- AWS to disconnect European Sovereign Cloud from global network in independence test (2026-09-29)
  https://www.cloudcomputing-news.net/news/aws-european-sovereign-cloud-independence-test/

AWSは、EUのクラウド主権要件やドイツ連邦情報セキュリティ庁(BSI)のC3A基準を満たすことを技術的に証明するため、10月24日にAWS European Sovereign Cloudを数時間にわたりAWSグローバルネットワークのバックボーンから切断する実証実験を実施すると発表した。切断中は欧州のISPが提供する専用インターネット接続のみを使い、EU域外のインフラに依存せずサービスを継続できることを示す狙い。

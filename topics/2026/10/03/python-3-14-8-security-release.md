# Python 3.14.8リリース、9件のセキュリティ脆弱性を修正する緊急更新
Tags: Programming Languages, Security

- Python 3.14.8 (2026-09-30)
  https://www.python.org/downloads/release/python-3148/

Python 3.14系の第8回メンテナンスリリースとなるPython 3.14.8が公開された。SSLコンテキストの処理、tarfileの展開フィルタ、zipfileの展開処理、urllibの認証情報管理に関連する合計9件のセキュリティ脆弱性を修正する緊急リリースで、該当バージョンを使用する開発者には早急なアップデートが推奨される。

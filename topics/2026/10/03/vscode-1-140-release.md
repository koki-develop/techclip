# Visual Studio Code 1.140リリース、エージェント駆動開発を強化する新機能を多数追加
Tags: OSS

- Visual Studio Code 1.140 (2026-09-30)
  https://code.visualstudio.com/updates/v1_140

Visual Studio Code 1.140がリリースされた。Copilotエージェントの動作を統一する「Copilot harness」、複数フォルダをまとめて扱うマルチフォルダセッション、リモート環境のエージェントへタスクを委任する機能、複数のAIモデルが協調して作業する「HydraFusion」など、エージェント駆動型の開発体験を強化する新機能が多数追加された。

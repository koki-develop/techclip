# ConnectWiseの盗難認証情報を悪用したサプライチェーン攻撃で170超のMicrosoft 365テナントが不正アクセス被害
Tags: Security

- Hackers breach Microsoft 365 tenants via ConnectWise supply-chain attack (2026-10-17)
  https://www.bleepingcomputer.com/news/security/hackers-breach-microsoft-365-tenants-via-connectwise-supply-chain-attack/
- Hackers Use Compromised ConnectWise Credential to Sign In to 173 Microsoft 365 Tenants (2026-10-17)
  https://thehackernews.com/2026/10/hackers-use-compromised-connectwise.html
- Stolen ConnectWise 'SkyKick' credential exposed Microsoft 365 tenants (2026-10-18)
  https://www.itnews.com.au/news/stolen-connectwise-skykick-credential-exposed-microsoft-365-tenants-629721

ConnectWiseのCloud Backup(旧SkyKick)の認証情報が盗まれ、攻撃者がこれを使って少なくとも162〜173件のMicrosoft 365テナントに不正にサインインし、メールやOneDrive、Teamsチャットへのアクセス権を獲得したことが判明した。被害を受けてConnectWiseは該当サービスを停止し、原因と被害範囲の調査を進めている。

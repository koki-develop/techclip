# Magento/Adobe CommerceにCVSS10.0の「BlockStrap」脆弱性、認証不要で任意コード実行が可能
Tags: Security

- Critical BlockStrap flaw lets hackers run code on Magento servers (2026-10-16)
  https://www.bleepingcomputer.com/news/security/critical-blockstrap-flaw-lets-hackers-run-code-on-magento-servers/
- BlockStrap: Magento and Adobe Commerce RCE (CVE-2026-103849) (2026-10-15)
  https://sansec.io/research/blockstrap-magento-rce

eコマースセキュリティ企業Sansecが、Magento/Adobe Commerceのメールテンプレート処理に存在する脆弱性「BlockStrap」(CVE-2026-103849、CVSS 10.0)を公表した。メールテンプレートの二段階ディレクティブ処理の不備を悪用することで、認証なしに任意のPHPコードをリモート実行できるとされ、広く利用されるECプラットフォームでの大規模な悪用が懸念されている。

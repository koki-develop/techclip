# AWS、欧州ソブリンクラウドをグローバル網から切断する独立運用の実証実験を10月24日に実施へ

- Amazon Web Services Demonstrates European Sovereign Cloud (2026-10-13)

AWSは10月24日、ドイツ・ブランデンブルクにある欧州ソブリンクラウドをAWSグローバルネットワークのバックボーンおよび運用データ転送システムから数時間切断し、EU在住スタッフのみでEU域内のハードウェア・ソフトウェアを用いて運用を継続できるかを検証する実証実験を実施すると発表した。GDPR準拠や米CLOUD Actへの懸念に対応する狙いがあり、欧州における非米クラウド依存からの脱却を求める機運とも関連して注目されている。

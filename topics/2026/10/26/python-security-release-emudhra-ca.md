# Python 3.15.1/3.14.9/3.13.17がリリース、認証局eMudhra問題に対応しpipを緊急更新
Tags: Programming Languages, Security

- Python 3.15.1, 3.14.9, 3.13.17 (2026-10-21)
  https://blog.python.org/2026/10/python-3151-3149-31317/

eMudhra/emSignの認証局証明書に関するセキュリティ問題に対応するため、Pythonにバンドルされているpipをバージョン26.2.2(certifi 2026.10.19を含む)に更新する緊急リリースが公開された。セキュリティのみモードに入ったばかりのPython 3.13にも特例でpip更新が適用されている。

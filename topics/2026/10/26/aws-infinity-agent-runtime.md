# AWSとUC Berkeley、AIエージェントの大量同時実行に向けたランタイム「Infinity」をOSS公開
Tags: Cloud, OSS, AI

- Introducing Infinity: a runtime for extreme agent concurrency (2026-10-23)
  https://aws.amazon.com/blogs/opensource/introducing-infinity-a-runtime-for-extreme-agent-concurrency/

AWSはUC BerkeleyのHydroプロジェクトと共同開発した、大量のAIエージェントを低メモリで同時実行できるランタイム「Infinity」をApache 2.0ライセンスでオープンソース公開した。多数のエージェントを並行稼働させる際のメモリ消費とオーバーヘッドを大幅に抑え、エージェント基盤のスケーラビリティ向上を狙う。

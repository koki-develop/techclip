# Microsoft、AIエージェントを「内部脅威」として扱う監視機能「Guardian Agents」を発表
Tags: AI, Security

- Microsoft says AI agents are like insider threats as 'frontier models can't be trusted' (2026-10-19)
  https://techcrunch.com/2026/10/19/microsoft-says-ai-agents-are-like-insider-threats-as-frontier-models-cant-be-trusted/
- Securing the agentic insider (2026-10-19)
  https://blogs.microsoft.com/blog/2026/10/19/securing-the-agentic-insider/
- Microsoft: Treat AI agents as insider threats (2026-10-21)
  https://www.csoonline.com/article/4238693/microsoft-treat-ai-agents-as-insider-threats.html

Microsoftは企業内で稼働するAIエージェントを従業員と同様の特権を持つが人間のような責任を負わない「内部脅威」として扱い、継続的に監視・制御する新機能「Guardian Agents」を発表した。識別・動的リスク評価・能動的監督の3段構えで構成される防御フレームワーク「Project Perception」の一部で、セキュリティ責任者Hayete Gallo氏は「出自を問わずフロンティアモデルは信頼できない」と述べ、最も信頼できるシステムとはモデルを最も信頼できる設計ではなく、モデルを信頼しなくても機能する設計だと説明した。

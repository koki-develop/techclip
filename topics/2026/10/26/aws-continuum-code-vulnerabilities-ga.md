# AWS、コード脆弱性をAIで自動検出・修正する新セキュリティサービス「AWS Continuum」を一般提供開始
Tags: Cloud, Security

- AWS Continuum for code vulnerabilities is now generally available (2026-10-22)
  https://aws.amazon.com/blogs/aws/aws-continuum-for-code-vulnerabilities-is-now-generally-available/

AWSはコードの脆弱性をAIで自動検出・検証し、優先度付けしたうえで修正プルリクエストまで生成する新セキュリティサービス「AWS Continuum for code vulnerabilities」の一般提供(GA)を発表した。現時点では米国東部(バージニア北部)および米国西部(オレゴン)リージョンで利用可能。

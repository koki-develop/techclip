# Vite・Vitestチームが統合ツールチェーン「Vite+ 1.0」を正式リリース
Tags: OSS, Programming Languages

- Announcing Vite+ 1.0 (2026-09-28)
  https://voidzero.dev/posts/announcing-vite-plus-1-0

Vite、Vitest、Rolldown、Oxcの開発チームが、Node.jsランタイム・パッケージマネージャー・フロントエンドツールチェーンを単一のCLI「vp」に統合する「Vite+ 1.0」を正式リリースした。MITライセンスのオープンソースとして公開され、既存のVite/Vitestエコシステムとの互換性を保ちつつ開発体験の一本化を図る。週間ダウンロード数は200万に迫る勢いで採用が進んでいるという。

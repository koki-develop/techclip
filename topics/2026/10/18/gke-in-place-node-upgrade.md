# GKE、Standard CPUノードプールでインプレースアップグレードに対応
Tags: Cloud

- GKE in-place node upgrade for Standard CPU node pools (2026-10-16)
  https://docs.cloud.google.com/release-notes

Google Kubernetes Engine(GKE)のStandard CPUノードプールが、既存のCompute Engine VMをそのまま更新するインプレースアップグレードに対応した。VMを削除・再作成しないため計算容量を維持でき、アップグレード失敗やノードのスタールによるリスクを低減できる。

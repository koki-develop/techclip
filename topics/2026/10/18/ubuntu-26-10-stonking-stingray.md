# Ubuntu 26.10「Stonking Stingray」リリース、coreutilsがRust実装に完全移行
Tags: OSS

- Ubuntu 26.10 Released with GNOME 51, Linux Kernel 7.3, and Rust coreutils (2026-10-15)
  https://linuxiac.com/ubuntu-26-10-released-with-gnome-51-linux-kernel-7-3-and-rust-coreutils/
- Canonical releases Ubuntu 26.10 Stonking Stingray (2026-10-15)
  https://canonical.com/blog/canonical-releases-ubuntu-26-10-stonking-stingray
- Ubuntu 26.10 (Stonking Stingray) released (2026-10-15)
  https://www.gamingonlinux.com/2026/10/ubuntu-26-10-stonking-stingray-released/

Ubuntu 26.10「Stonking Stingray」が正式リリースされた。GNOME 51デスクトップとLinuxカーネル7.3を搭載し、coreutilsが全面的にRust実装(uutils)へ移行したのが最大の特徴。オンデバイスLLMを使った音声認識エージェント「Myna」やポスト量子署名パッケージ、新しいウィンドウタイリング、Entra ID対応パスキーログインも追加された。非LTS版で2027年7月までサポートされる。

# Anthropic、Claude Code向け「Code Review」をTeam/Enterprise向けに正式提供開始

Claude CodeのPRレビュー機能「Code Review」がリサーチプレビューを終え、Team/Enterprise向けに正式公開された。レビュー時間が約20分から6〜10分に短縮され、リポジトリごとにQuick/Standard/Deepのレビュー強度を選択可能に。Enterpriseプランではシート数に応じて最大5万ドルのクレジットが付与されるが、EUデータレジデンシー設定のGitHub Enterprise Cloud利用企業は対象外となっている。

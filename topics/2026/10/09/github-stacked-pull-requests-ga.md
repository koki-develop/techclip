# GitHub、スタック型プルリクエスト機能を全プランで正式提供開始
Tags: OSS

- Stacked pull requests generally available (2026-10-06)
  https://github.blog/changelog/2026-10-06-stacked-pull-requests-generally-available/
- GitHub stacked pull requests: gh stack and AI agent skill (2026-10-07)
  https://aicoder.com/news/news-20261007-github-stacked-pull-requests-ga-gh-stack-agents

GitHubが、1つの大きな変更を複数の小さなPRに分割して積み重ねて管理する「スタック型プルリクエスト」機能を全プランで正式提供開始した。下位のPRがリベースされても上位PRの承認状態が維持される仕組みやマージキューとの統合が強化されたほか、gh CLIにスタック操作専用コマンドが追加され、AIコーディングエージェント向けのスキルも用意された。

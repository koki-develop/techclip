# GitHub Actionsを狙う「GhostAction」サプライチェーン攻撃が再来、772リポジトリから2577件のシークレットを狙う
Tags: OSS, Security

- GhostAction Returns: 772 Repos Hit in New GitHub Actions Wave (2026-10-07)
  https://blog.gitguardian.com/ghostaction-github-actions-supply-chain-attack-returns/

攻撃者は盗んだ認証情報を使い、「github_actions_security.yml」という偽装ワークフローを772の公開GitHubリポジトリに注入する新たな「GhostAction」攻撃波を展開した。この攻撃によりSSHキーやクラウド認証情報など合計2577件のシークレットが狙われ、OSSのサプライチェーン全体への影響が懸念されている。

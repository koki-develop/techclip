# Google、Python型チェッカーをPyreflyに移行、増分ビルドを最大98%高速化
Tags: OSS, Programming Languages

- Adopting Pyrefly as the Python type checker at Google (2026-10-06)
  https://opensource.googleblog.com/2026/10/adopting-pyrefly-as-the-python-type-checker-at-google.html

GoogleがMeta開発のオープンソースPython型チェッカー「Pyrefly」を採用し、従来のPytypeから移行した。Rustによる実装と並列処理により、増分ビルドの処理時間が最大98%短縮されたという。

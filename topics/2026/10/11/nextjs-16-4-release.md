# Next.js 16.4がリリース、新規アプリでCache Componentsがデフォルト有効化
Tags: Programming Languages, OSS

- Next.js 16.4 (2026-10-06)
  https://nextjs.org/blog/next-16-4

Next.js 16.4がリリースされ、新規アプリでCache Componentsがデフォルトで有効化されたほか、Turbopackのディスクキャッシュ容量の縮小、React 19.3への対応、AIエージェント向けのアップグレード支援ツール`next upgrade --agent`などが追加された。

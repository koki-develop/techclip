# TC39、東京会合でIterator関連4提案がStage4(仕様確定)に到達
Tags: Programming Languages

- TC39 agenda for the September 2026 meeting (2026-10-01)
  https://github.com/tc39/agendas/blob/main/2026/09.md

ソニー主催で9月29日から10月1日にかけて東京で開催されたTC39(ECMAScript標準化委員会)の第116回会合で、Iterator.prototype.join()やchunks()/windows()といったイテレータ関連の新メソッドを含む4つの提案「Iterator Join」「Iterator Includes」「Iterator Chunking」「Dynamic Code Brand Checks」がStage4(仕様確定)に到達した。これにより、これらの機能は今後のECMAScript仕様に正式に組み込まれる見通しとなった。

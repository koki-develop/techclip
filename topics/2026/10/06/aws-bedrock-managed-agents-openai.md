# AWSがOpenAIのエージェント技術を活用した「Amazon Bedrock Managed Agents」をパブリックプレビュー公開
Tags: Cloud, AI

- Amazon Bedrock Managed Agents, powered by OpenAI (2026-09-29)
  https://aws.amazon.com/about-aws/whats-new/2026/09/bedrock-managed-agents-preview/
- "Data never leaves AWS": OpenAI agents move into Amazon's cloud (2026-09-29)
  https://thenextweb.com/news/openai-bedrock-managed-agents-aws-devday

AWSがOpenAIのAgents APIをAWSネイティブに統合した新サービス「Amazon Bedrock Managed Agents」をパブリックプレビューで公開した。企業はデータをAWS環境内に留めたままOpenAIのエージェント技術を利用でき、セルフホスト実行環境とAgentCore Runtimeの2つの実行オプションが用意されている。Salesforceが早期採用企業として紹介されており、クラウド大手とAI企業の提携によるエージェント基盤競争の一環として注目されている。

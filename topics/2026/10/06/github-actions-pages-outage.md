# GitHub Actions/Pagesで大規模障害、CI/CDパイプラインが広範囲で停止
Tags: Cloud

- Ausfall bei GitHub: Actions, Pages und Abrechnung gestört (2026-10-05)
  https://www.heise.de/news/Ausfall-bei-GitHub-Actions-Pages-und-Abrechnung-gestoert-11476876.html

GitHub Actionsでホストランナーへのジョブ割り当てに失敗する障害が発生し、世界中の開発者のCI/CDパイプラインが広範囲にわたって停止した。GitHub Pagesのデプロイやビリング機能にも影響が及び、コードのビルド・テスト・デプロイを自動化に依存する多くのプロジェクトで作業が滞った。

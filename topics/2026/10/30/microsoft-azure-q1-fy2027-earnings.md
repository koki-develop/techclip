# Microsoft、2027年度Q1決算でAzure売上が前年比48%増の332億ドルに
Tags: Cloud

- Microsoft Q1 2027 Earnings Call — Azure Jumps 48% (2026-10-28)
  https://finance.biggo.com/news/US_MSFT_2026-10-28
- Microsoft just shared Azure's actual revenue in dollars: $33.2 billion (2026-10-28)
  https://techcrunch.com/2026/10/28/microsoft-just-shared-azures-actual-revenue-in-dollars-33-2-billion/

Microsoftは2027年度第1四半期(2026年9月30日締め)決算を発表し、全体売上は前年比19%増の923億ドル、Azure売上は前年比48%増の332億ドルと自社予想を上回る成長を記録した。同社は今回初めてAzureの売上高を具体的なドル金額で開示し、競合のGoogle Cloud(307億ドル)をわずかに上回る規模であることが明らかになった。次四半期のAzure成長率も49〜50%を見込むとしている。

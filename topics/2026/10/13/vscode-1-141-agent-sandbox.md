# VS Code 1.141リリース、複数エージェントセッションの比較表示とサンドボックス機能を追加
Tags: OSS

- Visual Studio Code 1.141 (2026-10-07)
  https://code.visualstudio.com/updates/v1_141

VS Code 1.141では、複数のCopilotエージェントセッションをグリッド表示で比較・監視できる機能に加え、Windows・macOS・Linux上でエージェントのファイルアクセスやネットワークアクセスを制限するサンドボックス機能、GitHub Enterpriseサインインの拡充などが追加された。

# AWS、既存のHTTPフレームワークをそのままデプロイできる「Lambda Web Functions」を一般提供開始
Tags: Cloud

- Announcing AWS Lambda Web Functions for fast, consistent web app performance anywhere (2026-10-12)
  https://aws.amazon.com/blogs/aws/announcing-aws-lambda-web-functions-for-fast-consistent-web-app-performance-anywhere/
- I tried Lambda Web Functions, which became GA, in the Tokyo region (2026-10-13)
  https://dev.classmethod.jp/en/articles/aws-lambda-web-functions-ga-express/

AWSが「AWS Lambda Web Functions」の一般提供を開始した。Express、Hono、Next.jsなどのHTTPフレームワークをコード変更なしでそのままLambda上にデプロイでき、自動スケーリングとマルチリージョン配信、実際に使用したCPU時間に応じた課金に対応する。サーバーレス環境でも従来のWebアプリケーション開発体験を損なわない点が特徴。

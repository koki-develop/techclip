# Google Cloud Storageのus-central1で12時間半の障害、トラフィック最適化処理が原因
Tags: Cloud

- Cloud Storage Incident #mSFVt6PiP557bjRyYsut (2026-10-08)
  https://status.cloud.google.com/incidents/mSFVt6PiP557bjRyYsut

Google Cloud Storageのus-central1リージョンで、トラフィックソート最適化機能がバックエンドストレージノードのリソース枯渇を引き起こし、アップロードおよび書き込み処理において12時間30分にわたりレイテンシ増加とエラーが発生した。

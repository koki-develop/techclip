# GitHub、Markdownでエージェント自動化を記述する「GitHub Agentic Workflows」を正式提供開始
Tags: OSS

- GitHub Agentic Workflows generally available (2026-10-28)
  https://github.blog/changelog/2026-10-28-github-agentic-workflows-generally-available/

GitHub Nextが開発していたオープンソースプロジェクト「GitHub Agentic Workflows」が正式提供(GA)となった。開発者はMarkdownでAIエージェントによる自動化処理を記述でき、Issueのトリアージ対応やCI失敗の分析など、GitHub Actions上で動作するエージェント主導のワークフローを容易に構築できるようになった。

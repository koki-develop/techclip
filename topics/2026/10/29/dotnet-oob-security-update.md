# Microsoft、.NET 8/9/10向けに4件のCVEを修正する緊急の帯外セキュリティ更新を公開
Tags: Programming Languages, Security

- .NET October 2026 Out-of-Band Security Updates (2026-10-25)
  https://devblogs.microsoft.com/dotnet/dotnet-october-2026-oob-security-updates/
- Microsoft Releases Out-of-Band Security Updates for Brotli and .NET tarballs Vulnerability (2026-10-26)
  https://cybersecuritynews.com/microsoft-security-updates-for-brotli-and-net-tarballs-vulnerability/

Microsoftは.NET 8.0.33/9.0.22/10.0.14および.NET 11 RC3向けに、緊急の帯外(Out-of-Band)セキュリティ更新を公開した。修正されたのはBrotliデコーダのバッファオーバーフロー(CVE-2026-111497)、Linux向けtarballの所有権不備(CVE-2026-114148)、SocketAsyncEventArgsのメモリ破壊(CVE-2026-70197)、Blazor WebAssemblyデバッガのリモートコード実行(CVE-2026-102870)の4件で、早急な適用が推奨されている。

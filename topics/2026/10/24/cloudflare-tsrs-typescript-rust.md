# Cloudflare、TypeScriptコンパイラをRustに移植した「tsrs」を発表
Tags: OSS, Programming Languages

- Introducing tsrs: a Port of TypeScript to Rust (2026-10-20)
  https://blog.cloudflare.com/typescript-rust-port
- "We are not forking TypeScript": Cloudflare spearheads Rust port written by agents, for agents (2026-10-20)
  https://thenewstack.io/cloudflare-rust-typescript-tsrs/

CloudflareはVoidZeroおよびTypeScriptチームと協力し、TypeScriptコンパイラをRustに移植した「tsrs」を発表した。WebAssembly上で動作し、TypeScript 7.0比で最大8倍の高速化とメモリ使用量約70%削減を実現したとしており、将来的にはOxcツールチェーンへ統合される計画。移植作業の大部分はAIエージェントが担い、TypeScriptをフォークするものではないと強調している。

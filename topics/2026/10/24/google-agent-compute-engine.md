# Google Cloud、AIエージェント専用のクラウド基盤「Agent Compute Engine」を発表
Tags: Cloud, AI

- Introducing Agent Compute Engine and expanding agent governance (2026-10-22)
  https://cloud.google.com/blog/topics/ai-infrastructure/introducing-agent-compute-engine-and-expanded-agent-governance
- Google turns the infrastructure behind Gemini's agents into a cloud service (2026-10-22)
  https://thenewstack.io/google-agent-compute-engine/
- Google Cloud introduces Agent Compute Engine to host AI agents (2026-10-22)
  https://siliconangle.com/2026/10/22/google-cloud-introduces-agent-compute-engine-to-host-ai-agents/

Google Cloudは、Geminiのエージェント基盤を支える社内インフラを商用クラウドサービス「Agent Compute Engine」として提供開始した。各AIエージェントにTitanチップでファームウェアを検証したハードウェア分離済みのmicroVMを割り当てることで、コンテナ並みの効率性とVM並みのセキュリティを両立させる。推論コストを管理するトークン制御やモデルルーティング機能を備えた新しい「Agent Gateway」も同時に導入し、エージェントガバナンスの強化を図った。

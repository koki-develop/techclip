# AIスタートアップRecursive、大部分をAIが開発したノートPC向けコーディングモデル「Flint」を公開
Tags: AI

- Recursive launches Flint, a laptop coding model it says was largely built by AI (2026-10-21)
  https://techcrunch.com/2026/10/21/recursive-launches-flint-a-laptop-coding-model-it-says-was-largely-built-by-ai/

AIスタートアップRecursiveは、自社のAI研究システム「Eureka Machine」が開発の大部分を担ったとするノートPC向けの無料コーディングモデル「Flint」をApache 2.0ライセンスで公開した。モデル開発そのものをAIに委ねる手法の実例として注目されている。

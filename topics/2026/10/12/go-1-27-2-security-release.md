# Go言語、15件のセキュリティ修正を含むマイナーリリース1.27.2/1.26.9を公開
Tags: Programming Languages, Security

- Go 1.27.2 and 1.26.9 security release (2026-10-08)
  https://go.dev/doc/devel/release
- Go Security Update Fixes 15 Flaws in Servers and Toolchains (2026-10-08)
  https://linuxsecurity.com/news/server-security/go-security-update-15-flaws

Go言語のマイナーリリース1.27.2および1.26.9が公開された。net/http、crypto/tls、net/textproto、mime/multipartなど標準ライブラリに関する15件のセキュリティ修正が含まれており、サーバーやツールチェインを利用する開発者に更新が推奨されている。

## 概要

Microsoftは11月17日、Ignite 2026にあわせて次期サーバーOS「Windows Server 2028」のパブリックプレビューを公開した。セキュリティ強化、エンタープライズインフラの高速化、管理のスケーラビリティ、そしてAIによるハイブリッドインテリジェンスの4本柱を掲げ、オンプレミス環境でのAI活用とセキュリティ基盤の両方を同時に刷新する内容となっている。一般提供(GA)の日程はまだ発表されていないが、早期アクセスプログラムへの申し込みは既に受け付けている。

## Microsoft Foundry連携によるオンプレAI推論

最大の目玉は、クラウドサービスのMicrosoft Foundryをエンタープライズのオンプレミスインフラまで拡張し、社内環境でAI推論を実行できるようにする機能だ。Microsoftは「推論をどこで実行すべきか、クラウドから社内の管理下にあるインフラまで柔軟に選択できるようになる」としており、データ主権やレイテンシの要件からクラウド利用に制約のある企業にも対応する狙いがある。ハードウェア面では2027年前半以降にAMD Instinct MI350Pへの対応を予定し、ソフトウェア面ではWindows ML、vLLM、Llama.cppといった主要な推論ランタイムをサポートする計画が示されている。

## ポスト量子暗号とストレージ強化

セキュリティ面では、ポスト量子暗号への移行がWindows Server 2028の重要な取り組みとして位置づけられており、Intelなどのパートナーと連携して実装が進められる。これに加えて証明書の自動管理機能も導入され、将来の暗号規格移行に伴う運用負荷を軽減する。ストレージでは、ネイティブNVMe対応がデフォルトで有効化され、TCPやRDMAによる転送のサポート、ReFSでの起動機能などにより高性能ストレージ構成を容易にする。Server Coreではセキュアな既定設定が強化され、Trusted LaunchによるVM起動時の整合性保証やConfidential VM対応も新たに加わった。

## 管理機能とエンタープライズへの影響

管理面ではIntuneによる管理機能がプレビュー提供され、Windows Admin Centerの仮想化モードが一般提供に移行するなど、クラウドベースの統合管理へのシフトも進む。これらの機能は、ハイブリッドAI環境の構築を検討する企業やセキュリティ重視の組織、大規模なサーバー管理を担うエンタープライズの管理者にとって特に関係が深い。GAの時期は未定だが、今回のプレビュー公開によって企業は自社インフラでの検証を早期に始められるようになり、オンプレミスとクラウドを横断するAI活用とセキュリティ基盤整備の両立に向けた準備が進むことになりそうだ。

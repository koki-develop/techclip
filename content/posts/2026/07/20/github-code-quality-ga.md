## 概要

GitHubは2026年7月20日、コードベースの品質分析機能「Code Quality」をパブリックプレビューから正式提供（GA）へ移行した。既に1万社以上のエンタープライズ組織が試用していたこの機能は、GA移行とともに有料製品として位置づけられ、アクティブコミッター1人あたり月10ドルのサブスクリプションとして課金される。プレビュー期間中は無償で利用できていたが、今後は継続利用に費用が発生することになる。不要な組織は7月20日の課金開始前に、組織設定からCode Qualityを無効化できるとされている。

## 料金体系

今回のGA移行では、3つの要素からなる料金体系が示された。まず基本となるのが、アクティブコミッターあたり月10ドルの定額サブスクリプションで、Code Qualityが有効化されたリポジトリへのアクセス、検出結果の表示、スコアリング、品質ゲートといった中核機能が含まれる。これに加えて、Copilotによるコードレビューやレビュー支援検出、Copilot Autofixといった生成AIを活用した機能は従量課金の対象となる。さらに、CodeQLを用いた保守性・信頼性の決定論的な静的解析はGitHub Actions上で実行されるため、Actionsの実行分数を消費する仕組みだ。つまり利用状況によっては、基本料金に加えてAI機能の利用量やActionsの実行時間分のコストが上乗せされる。

## 機能面の拡張

GA版では組織全体への展開に対応し、組織レベルでの品質状況を俯瞰できるダッシュボードが用意された。またルールセットを通じてコードカバレッジ基準を強制できるほか、リポジトリおよび組織単位での品質スコアの算出、検出結果を管理するためのAPIも提供される。これにより、個々のリポジトリだけでなく組織横断でコード品質のガバナンスを行えるようになった点が、プレビュー版からの大きな進化と言える。

## 対象プラットフォームと今後

Code QualityはGitHub Enterprise CloudおよびGitHub Teamプランで利用可能だが、オンプレミス向けのGitHub Enterprise Serverには提供されない。クラウド版を前提とした機能拡充であり、AIによるコード検出・自動修正とActions基盤の静的解析を組み合わせることで、コード品質管理をGitHub上で完結させる狙いがうかがえる。有料化によって、これまで無償で試していた組織は費用対効果を見極めた上での継続利用可否の判断を迫られることになりそうだ。
